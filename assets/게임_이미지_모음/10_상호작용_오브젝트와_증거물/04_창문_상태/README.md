# 04. 창문 상태 세트

빅토리아풍 창문 4종의 낮·개폐·저녁·파손 상태입니다.

- 창문 종류: 흰색 미닫이창, 참나무 여닫이창, 상점 진열창, 석재 지하실창
- 각 창문 상태: 낮 닫힘, 반쯤 열림, 완전 열림, 저녁 점등, 파손·차단
- `windows/`: 게임용 64×64 투명 PNG 20개
- `lighting-overlays/`: 저녁 창문 빛 3프레임씩 총 12개
- `*-open-close-preview.gif`: 창문별 열림 확인 GIF
- `evening-window-light-sample.png`: 저녁 배치 예시
- `manifest.json`: 상태와 조명 애니메이션 설정

창문 본체는 벽·고정 가구 레이어에 배치하고, 저녁 조명 오버레이는 최상단 조명 레이어에 둡니다. 파손·판자로 막힌 창문은 열리지 않도록 처리하며, 열린 창문은 사건에 따라 엿듣기나 외부 관찰 상호작용 지점으로 사용할 수 있습니다.

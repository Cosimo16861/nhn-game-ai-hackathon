# L1 → L2 컷신 제작 계획

> 상태: 사용자 승인 완료(2026-08-10)
> 게임 연결: 하지 않음
> 기준 화면: 640×384, C0B와 같은 336×84 대사창, 전체 화면 재생

## 1. 제작 범위와 묶음

L1에는 부모 퀘스트가 둘이므로 실제 플레이에서는 다음 두 묶음이 별도로 재생된다.

| 트리거 | 묶음 순서 | 컷신 | 담당 다음 퀘스트 |
| --- | :--: | --- | --- |
| Q1A 미화된 초상 완료 | 1/2 | `C2C_RAIN_BEHIND_THE_DOOR` 《문 뒤의 빗물》 | Q2C 닫힌 방 |
| Q1A 미화된 초상 완료 | 2/2 | `C2A_HOLTS_MEMORY` 《홀트가 기억한 얼굴》 | Q2A 기억되지 않은 얼굴 |
| Q1B 선술집 벽 완료 | 1/1 | `C2B_MIST_IS_MISSING` 《안개를 찾습니다》 | Q2B 고양이 전단 |

Q1A 묶음은 응접실 → 서쪽 복도 → 응접실 → 학교 순서로 이동한다. 먼저 하녀 베스의
긴급한 누수 보고를 따라 현장을 확인하고, 돌아와 초상의 덧칠을 추궁한 뒤 홀트의 학교로
이동한다. 이 순서가 저택과 학교를 왕복하지 않는 가장 자연스러운 동선이다.

Q1B 묶음은 선술집 안에서 끝난다. 다른 부모에서 나온 컷신이므로 Q1A 묶음 뒤에 자동으로
붙지 않는다. 검토 페이지도 실제 재생 단위를 보존해 두 URL로 제공한다.

## 2. 목적지별 증언 계약

### C2C → Q2C

- 출처 1: 하녀 베스의 직접 보고
- 출처 2: 서쪽 복도 젖은 벽의 현장 관찰
- 출처 3: 엘리너가 기억하는 에드먼드의 글씨 습관
- 반드시 전달할 사실:
  - 비가 올 때마다 서쪽 복도 벽으로 물이 흐른다.
  - 벽에는 배 한 척과 크기가 다른 사람 셋의 크레용 흔적이 남아 있다.
  - 에드먼드는 가족 그림 아래에 늘 `우리`라고 썼다.
  - 이미 번지는 중이라 지금 종이에 옮기고 복원하지 않으면 사라진다.
- 아직 공개하지 않음: 세 사람이 누구인지, 그림이 법적 증거라는 주장, 복원 완성 모습

### C2A → Q2A

- 출처 1: Q1A 복원 과정에서 플레이어가 발견한 관자놀이의 두 겹 물감
- 출처 2: 엘리너의 미화 의뢰 고백
- 출처 3: 옛 가정교사 홀트의 직접 증언
- 반드시 전달할 사실:
  - 기존 초상의 부드러운 턱과 좌우 같은 눈썹은 화가가 미화한 결과다.
  - 실제 에드먼드의 턱은 어머니를 닮아 각졌다.
  - 웃을 때 에드먼드의 왼쪽 눈썹만 올라갔다.
  - 관자놀이에 나무에서 떨어져 생긴 작은 흉터가 있었다.
  - 머리는 짙었고, 이 증언으로 미화되지 않은 얼굴을 복원해야 카버와 비교할 수 있다.
- 아직 공개하지 않음: 카버와의 실제 불일치 결론, 봉인, 문신, 줄리언의 역할

### C2B → Q2B

- 출처 1: 복원된 12년 전 벽 층
- 출처 2: 선술집 주인 코라의 직접 증언
- 반드시 전달할 사실:
  - 벽에서 나온 얼굴은 카버가 아니라 오래전 죽은 선원 페리다.
  - 실패가 아니라 “카버가 그 벽 층에는 없었다”는 부정 결과다.
  - 코라의 고양이 안개가 사흘째 보이지 않는다.
  - 안개는 옅은 회색이고, 한쪽 귀만 희며, 목에 붉은 리본을 맨다.
  - 다른 회색 고양이와 구별되는 그림 전단이 필요하다.
- 아직 공개하지 않음: 고양이의 현재 위치, 창고, 젖은 일지, 뱅크스

## 3. 시각·연출 계획

| 컷신 | 장소 변화 | 등장인물 | 카메라·효과 |
| --- | --- | --- | --- |
| C2C | 응접실 → 서쪽 복도 | 플레이어, 엘리너, 베스 | 이젤 증거 확대, 베스의 급한 진입, 번개, 물방울, 복도 와이드, 벽 흔적 정지 확대 |
| C2A | 응접실 → 학교 | 플레이어, 엘리너, 홀트 | 덧칠 확대, 엘리너 정면 고백, 우천 페이드, 학교 공간 와이드, 홀트 기억 클로즈업, 턱·눈썹·흉터 표시 |
| C2B | 선술집 | 플레이어, 코라 | 벽화 공개, 코라의 놀람·웃음, 난로 불빛, 생활 소음, 고양이 기억 삽입, 붉은 리본 색 강조 |

장소 배경은 네 키(`asherton-parlor`, `asherton-west-hall`, `school`, `tavern`)를 사용한다.
같은 저택 안에서도 응접실은 따뜻한 창가 빛과 초상 중심, 서쪽 복도는 찬 빛과 누수 중심으로
팔레트와 움직임을 명확히 나눈다.

## 4. 제작·검토 절차

1. 목적지별 증언 계약과 스포일러 금지 정보를 먼저 잠근다.
2. 새 장소 배경을 생성하고 기존 도트 팔레트에 맞춰 640×384로 후처리한다.
3. 기존 NPC 정체성 시트에서 엘리너·베스·홀트·코라의 표정을 크롭한다.
4. Q1A·Q1B 실제 목표 자산은 복원 완료 삽입컷으로 재사용한다.
5. Q1A 묶음 2편과 Q1B 묶음 1편을 실제 플레이와 같은 전체 화면으로 구현한다.
6. 별도 피드백 에이전트가 이야기·시각·재생을 검토하고, 수정 후 같은 에이전트에게 다시
   전달하는 과정을 총 3회 수행한다.
7. 사용자 승인 전에는 게임 진행 그래프와 해금 로직에 연결하지 않는다.

# L2 → L3 컷신 검토 기록

> 상태: 사용자 검토 대기
> 기준: `271ffba` + 병렬 계획 `0ee2b32`
> 게임 연결: 하지 않음
> 검토 서버: 포트 `8130` 실행 유지

## 1. 검토 URL과 재생 순서

- Q2A 완료 묶음: `http://localhost:8130/dev/cutscenes/cutscene-review-l2-l3.html?bundle=q2a`
  - 1/2 `C3A_CARVERS_CREST` 《카버가 그린 네 줄》 — 67.4초
  - 2/2 `C3B_FRESH_ANCHOR` 《소매 아래의 닻》 — 19.9초
  - 장면 전환 0.65초 포함 약 88.0초, 경찰서에서 자동 연속 재생
- Q2B 완료 묶음: `http://localhost:8130/dev/cutscenes/cutscene-review-l2-l3.html?bundle=q2b`
  - 1/1 `C3C_FOLLOW_THE_FLYER` 《전단이 찾은 창고》 — 28.8초
- Q2C 완료 closing, Q2A 미완료 fixture:
  - `http://localhost:8130/dev/cutscenes/cutscene-review-l2-l3.html?bundle=q2c&q2a=incomplete`
  - 1/1 `C2C_OPEN_DOOR_CLOSING` 《열린 문간》 — 32.8초
- Q2C 완료 closing, Q2A 완료 fixture:
  - `http://localhost:8130/dev/cutscenes/cutscene-review-l2-l3.html?bundle=q2c&q2a=complete`
  - 1/1 `C2C_OPEN_DOOR_CLOSING` 《열린 문간》 — 31.9초

모든 URL은 `SPACE`로 문장을 완성하거나 다음 비트로 진행하고, `ESC`로 현재 편만 건너뛰며,
`R`로 현재 부모 묶음의 첫 편부터 다시 재생한다. 화면에는 이 세 조작만 표시한다.

## 2. 제작 결과

- 컷신 4편, 부모 묶음 3개, Q2C 조건 fixture 2개
- 논리 화면 640×384, 5:3 전체 화면, 대사창 `x=152, y=278, w=336, h=84`
- 텍스트 레이어 1920×1152, 최대 3줄과 한글 끝 글자 보존 검사
- 배경 3종:
  - 승인 경찰서 자산을 로컬 재양자화한 경찰서
  - 새로 생성한 해질녘 부두·창문 없는 창고 외부
  - 새로 생성한 열린 아이 방 문간
- 정체성 잠금 초상 7종: 카버 3표정, 줄리언 3표정, 부두 인부 1표정
- 승인 자산 직접 재사용: 플레이어, 리드, 엘리너, 홀트, 코라
- 삽입컷 5종: Q2A 복원 얼굴, 완성 고양이 전단, 편지·갈라진 밀랍, 시각 정본 손목의 닻,
  종이에 옮긴 크레용 그림
- 주요 효과: 얼굴 동일 배율 비교와 세 특징 강조, 줄리언 난입, 초승달과 네 파도 획의 순차
  칠판 드로잉, 소매 걷기와 손목 확대, 잉크·피부 펄스, 게시 전단 유지, 등불 동선·상자 높이·
  젖은 바닥 반사 도식, 열린 문 상태와 머리색 fixture 강조

## 3. 이미지 생성 및 후처리

내장 이미지 생성 도구로 환경 원화 2종을 각각 생성했다. 최종 프롬프트는
`assets/cutscenes/l2-l3/source/PROMPTS.md`, 생성 원본은 같은 `source/` 폴더,
640×384 후처리 결과는 `backgrounds/`에 보존했다.

- 부두 원화: 창문 없는 창고, 단일 등불, 높이가 다른 상자, 젖은 바닥 반사가 명확한 시안 채택
- 아이 방 원화: 열린 문, 비어 있는 방, 작은 침대와 장난감 배가 명확한 시안 채택
- 생성 이미지 금지 항목: 인물, 글자, UI, 초승달·파도 문양, 봉인, 닻 문신
- 정확한 네 줄, 닻, 전단, 크레용 그림은 결정적 퀘스트 자산 또는 런타임 픽셀로 제작
- 진품 세 줄 이미지는 생성 원본·후처리 자산·런타임 어디에도 포함하지 않음

자산 재생성 및 규격 검사는 Pillow가 포함된 번들 Python으로 수행했다.

```sh
/opt/homebrew/Caskroom/miniforge/base/bin/python3 scripts/prepare-l2-l3-cutscene-assets.py
```

결과: 배경 3 + 초상 7 + 삽입컷 5 = 15개 자산. 모든 배경은 640×384 RGB, 삽입컷은
336×216 RGB, 초상은 높이 320px RGBA이며 `portrait-crop-v1` 소스 SHA256 잠금을 통과했다.

## 4. 증언·복원 당위·스포일러 검사

- Q3A: 에드먼드의 아버지가 남기고 엘리너가 갈라진 봉인 밀랍과 함께 보관한 편지를 출처로 제시하고, 두 불완전한
  눌림을 맞춰 원래 문양을 복원한 뒤 카버의 네 줄 그림과 대조한다고 명시했다.
- Q3B: 카버가 직접 걷어 보인 손목을 출처로 닻 도안·선명한 잉크·붉은 피부를 관찰하고,
  날짜를 단정하지 않은 채 현재 모습을 조서에 보존한다고 명시했다.
- Q3C: 완성 전단, 회색 털·한쪽 흰 귀·붉은 리본을 모두 본 인부의 직접 증언, 창문 없는
  창고·단일 등불·상자 높이·젖은 바닥을 이어 고양이 틈을 찾는 당위를 명시했다.
- Q2C: 새 노드를 열지 않는다. 미완료 fixture는 홀트의 이미 들은 증언에 머리색을 보태고,
  완료 fixture는 일치만 확인하며 완료 조사를 다시 안내하지 않는다.
- 금지 정보 통과: 진품 세 줄, 줄리언이 카버를 훈련했다는 결론, 정확한 시술 날짜,
  최근 문신 완료 결론, 젖은 종이 내용, 뱅크스, 검은 마차, 아셔튼·마차 연결을 선공개하지 않는다.

## 5. 동일 피드백 에이전트 3회 반복

### 1차 — 미승인 후 수정

1. 인부 대사에 한쪽 흰 귀를 추가해 코라의 동일성 확인과 직접 증언 출처를 연결했다.
2. 첫 경찰서 와이드에 플레이어·리드·홀트·Q2A 복원 결과·카버를 함께 배치했다.
3. 확대 비교의 두 얼굴을 같은 178px 크롭 높이로 맞추고 각진 턱·올라간 왼눈썹·관자놀이
   흉터의 이미 복원된 특징을 픽셀 표시로 보강했다.
4. Q2C 머리색 강조 좌표를 그림 속 아이에게 이동했다.
5. 전단이 붙은 뒤 인부와 코라 비트까지 부두 기둥에 남도록 시각 인과를 보강했다.
6. Q3A 목적을 네 줄 그림과의 대조까지 명시하고 번들 Python 실행 절차를 기록했다.

### 2차 — 미승인 후 수정

1. 원본 크레용 그림에서 아이가 오른쪽의 가장 작은 인물임을 다시 확인하고 머리 강조를 그 위치로 옮겼다.
2. `chalkFour` 진입 때 초승달 완성 상태를 유지했다.
3. 네 파도 획을 390ms 간격, 각 300ms 길이로 나누고 2050ms 시각 입력 잠금을 적용했다.

### 3차 — 조건부 미승인 후 보정 승인

1. 시작 전 파도도 `progress=0` 경로의 절반이 보이던 문제를 발견했다.
2. 미래 획은 완전히 건너뛰고, 현재 획만 보이는 길이까지 픽셀 폴리라인으로 늘어나게 수정했다.
3. 동일 에이전트의 3차 종료 확인에서 순차 드로잉·비중첩·문법 검사를 최종 승인했다.

최종 피드백 결과: 추가 수정 요구 없음. 이야기·금지 스포일러·fixture·연속 재생·화면·입력·
저장 무변경 계약 승인.

## 6. 전체 최종 QA 1차 반영

1. Q2A 학교 완료 뒤 홀트를 모시고 카버를 경찰서로 불렀다는 첫 연결 대사를 추가해 이동·집결을 명료화했다.
2. 줄리언 최초 등장 직후 리드가 그를 `줄리언 아셔튼`, 엘리너의 조카, 지난 12년 재산 관리인으로 소개한다.
   줄리언은 이어 `숙모님`이라고 부르지만 마차·배후·훈련과 연결되는 정보는 말하지 않는다.
3. C3B의 카버 대사를 `열여덟 살 때 제가 새긴 닻`이라는 사칭자의 1인칭 주장으로 고쳤다.
4. 봉인 출처를 `에드먼드의 아버지가 남긴 편지`와 `엘리너가 함께 보관한 갈라진 봉인 밀랍`으로 고정했다.
5. 카버 얼굴 위에 팔을 덧그리던 `sleeve` 사각형 합성을 제거하고 첫 비트부터 중앙 손목 증거 패널을 사용한다.
6. 평면 다각형 손목 자산을 폐기했다. L3→L4의 `fresh-anchor-record.png`를 로컬 참조본으로 복사해
   동일 팔·소매·닻 형태를 유지했으며, SHA256
   `e748d2a1d006d79d49894929958897c7204b932955683c8b54f549eda411d0bd`로 잠갔다.
   `anchorPulse`는 이미지를 덮지 않고 붉은 피부 외곽만 투명 선으로 강조한다.
7. 편지·전단·아이 그림·손목 증거의 흰 캡션 뒤에 82% 불투명 암색 바를 추가해 밝은 종이 위 대비를 높였다.
8. 유지 계약: C3A→C3B 자동 순서, 진품 세 줄·독립 가지 스포일러 금지, `ESC`/`R`, 336×84 대사창은 변경하지 않았다.
9. 포트 8130의 실제 640×384 논리 캔버스를 1280×720 브라우저 프레임으로 검사했다.
   이동·집결 첫 비트와 줄리언 소개는 각각 2줄, 중앙 손목 공개는 얼굴 비가림, pulse는 비채움 외곽선,
   전단·아이 그림 캡션은 암색 바 위 표시를 확인했다. 콘솔 오류·경고는 0건이었다.

- 전체 QA 2차 반영: 이동 주체를 `학교에서 홀트 선생을 모셔 왔고`로 명확히 하고, 편지 출처를 `에드먼드의 아버지`로 교정했다.

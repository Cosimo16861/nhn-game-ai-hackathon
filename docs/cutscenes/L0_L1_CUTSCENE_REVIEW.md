# L0 → L1 컷신 제작·검토 기록

> 상태: 고해상도 questimage 증언 계약으로 재작성(2026-08-10) · 재검토 필요
> 게임 연결: 하지 않음
> 검토 화면: `dev/cutscenes/cutscene-review-l0-l1.html`

## 1. 제작 단위

Q0 완료 뒤 L1에 `Q1A_IDEALIZED`와 `Q1B_TAVERN_WALL` 두 퀘스트가 열리므로, 한 편에
두 당위를 몰아넣지 않고 다음 두 컷신을 이어 재생하도록 분리했다.

| 순서 | 컷신 | 담당 다음 퀘스트 | 자동 재생 길이 |
| :--: | --- | --- | ---: |
| 1 | `C1A_RETURNED_HEIR` 《돌아온 상속자》 | Q1A 미화된 초상 | 약 40.7초 |
| 2 | `C1B_TWELVE_YEARS_UNDER` 《벽 아래의 열두 해》 | Q1B 선술집 벽 | 약 35.7초 |

두 컷신은 하나의 묶음으로만 연속 재생한다. `SPACE`는 문장 완성 후 다음 비트로 이동하고,
`ESC`는 현재 편만 끝내 다음 편으로 넘어간다. `R`은 어느 시점에서든 묶음 전체를 첫 편부터
다시 재생한다. 개별 컷신 선택 기능은 제공하지 않는다.

## 2. 증언·당위 계약

### C1A → Q1A

- 출처: 리드 경위가 전달한 엘리너 아셔튼의 쪽지
- 남은 유일한 열여덟 살 초상이다.
- 습기로 색이 거의 빠져 검은 선만 남았다.
- 엘리너의 메모에는 짙은 머리, 청록 코트, 화면 왼쪽 창가 빛이 남아 있다.
- 복원해야 카버와 비교할 과거 얼굴이 생긴다.

아직 공개하지 않는 것: 관자놀이 흉터, 초상이 미화되었다는 결론, 카버와의 실제 차이.

### C1B → Q1B

- 출처: 선술집 주인 코라의 서면 진술
- 벽에는 20년 동안 얼굴 위에 얼굴이 덧그려졌다.
- 약 12년 전 아래층에 사람 얼굴 하나가 남아 있다.
- 회벽·숯가루·후대 낙서가 겹쳐 현재는 식별할 수 없다.
- 그 층을 복원해야 카버가 당시 도시에 있었는지 대조할 수 있다.
- 결과가 카버라는 보장은 없다는 조사 한계를 먼저 말한다.

아직 공개하지 않는 것: 아래층 얼굴이 페리라는 사실, 카버의 과거, 본가·방계 문장.

## 3. 화면 규격

- 640×384 도트 캔버스
- 브라우저 화면을 가득 채우는 5:3 컷신 화면과 검은 레터박스
- C0B와 같은 `x=152, y=278, 336×84` 대사창
- 같은 플레이어·리드 초상 재사용
- 경찰서 배경 1장을 두 편에서 재사용
- 정확한 한글 제목·출처·신문 제목·검거 도장은 런타임 텍스트로 합성
- 생성 이미지에 읽히는 글자나 결정적 사건 정보는 넣지 않음
- 외부 제목, 재생·조작·현재 컷신 패널을 표시하지 않음
- 좌상단에는 `SPACE`, `ESC 현재 컷신 스킵`, `R 묶음 다시 보기` 키 안내만 표시

## 4. 자체 검토

### 1차 — 이야기·증언

원본 `C1_THE_CASE`는 Q1A의 초상 훼손은 설명했지만, Q1B가 왜 “벽 복원” 퀘스트인지와
작업대에 표시할 코라의 증언 출처가 없었다. 두 컷신으로 분리하고 코라의 서면 진술을 추가했다.
Q1B 결과가 카버일 것처럼 단정하지 않도록 리드가 조사 한계를 명시하게 수정했다.

결과: 두 다음 퀘스트 모두 출처·대상·훼손 상태·복원 목적을 컷신 안에서 확보한다.

### 2차 — 시각·스포일러

첫 선술집 벽 생성본은 중앙 얼굴이 너무 완성되어 Q1B 결과를 앞질러 보였다. 후대 회벽과
낙서로 65~75%를 다시 가린 변형을 생성하고 최종 자산으로 채택했다. 초상은 눈과 관자놀이를
박락으로 가려 Q2A의 흉터를 노출하지 않았다. 배경·초상·대사창은 C0B와 나란히 비교했다.

결과: 도트 통일, 출처 가시성, 스포일러 통제 통과.

### 3차 — 재생·조작

로컬 브라우저에서 묶음 연속 재생, 현재 편 스킵, 첫 편 스킵 뒤 두 번째 편 자동 진입을
확인했다. 콘솔 오류는 없었다. 대사 타이핑 중 문장부호만 다음 줄에 남는 경우를 발견해 짧은
마지막 줄을 재분배하는 줄바꿈 보정을 추가했다. 이후 사용자 피드백에 따라 검토용 바깥
대시보드를 제거하고 실제 플레이 화면과 같은 전체 화면 구성으로 수정했다.

결과: 사용자 검토 화면의 기능 검증 통과. 실제 퀘스트 완료·해금 로직에는 연결하지 않았다.

## 5. 사용자 검토 항목

- 두 편이 선택 화면 없이 이어지는 하나의 묶음 컷신으로 느껴지는가
- Q1A와 Q1B 각각의 복원 당위가 충분히 분리되어 기억되는가
- 경찰서 배경·인물·대사창이 C0B와 같은 게임으로 보이는가
- 훼손 초상과 선술집 벽이 정답을 미리 보여주지 않는가
- 대사 길이와 자동 진행 호흡이 적절한가

사용자 승인은 완료되었으며, 전체 컷신 검토가 끝날 때까지 게임 진행 그래프, Q0 완료 처리,
L1 해금에는 삽입하지 않는다.

## 6. 사용자 피드백 반영

### 신문 기사 구체화 — 2026-08-10

첫 검토본의 신문은 제목 아래가 선과 사각형뿐이라 실제 기사 내용이 전달되지 않았다. 다음
요소를 도트 삽화와 런타임 한글 텍스트로 다시 구성했다.

- 제호 `안개항 일보`, 호수와 날짜
- 세이렌 호 침몰 실종자 에드먼드와 생존을 주장한 토마스 카버를 연결하는 부제
- 폭풍 속 세이렌 호 도트 삽화와 설명
- `시신 없는 실종`, `가문은 확인 중` 단신
- 엘리너의 사망 신고 거부와 경찰의 신원 확인 착수

얼굴은 기사에 넣지 않아 카버와 에드먼드의 외형을 복원 전에 선공개하지 않았다. 실제 화면
크기에서 기사와 대사창을 함께 확인하고, 좌상단 키 안내와 겹치지 않도록 신문을 아래로 옮겼다.

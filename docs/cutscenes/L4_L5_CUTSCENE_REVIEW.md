# L4 → L5 컷신 검토 기록

> 상태: 전체 컷신 최종 QA 1차 반영 완료, 사용자 재검토 대기
> 기준: `271ffba`, 병렬 계획 확정 `0ee2b32`
> 게임 연결: 하지 않음
> 전용 서버: `http://127.0.0.1:8132`

## 1. 사용자 검토 화면과 재생 순서

| 부모 fixture | 검토 URL | 고정 재생 순서 | 다음 노드 |
| --- | --- | --- | --- |
| Q4A 완료 | `dev/cutscenes/cutscene-review-l4-l5.html?bundle=q4a` | 1/1 `C5A_CARRIAGE_WITNESS` 《넉 달과 검은 마차》 | Q5A 안개 낀 부두 |
| Q4B 완료 | `dev/cutscenes/cutscene-review-l4-l5.html?bundle=q4b` | 1/1 `C5B_SIREN_WITNESS` 《남겨야 할 그 밤》 | Q5B 세이렌 호의 밤 |
| Q4C 완료, Q5A 미완료 | `dev/cutscenes/cutscene-review-l4-l5.html?bundle=q4c&q5a=0` | 1/1 `C4C_PAINTER_CLOSING` 《사가는 얼굴》 | 없음 |
| Q4C 완료, Q5A 완료 | `dev/cutscenes/cutscene-review-l4-l5.html?bundle=q4c&q5a=1` | 같은 closing의 중립 복귀 문구 fixture | 없음 |

총 장면 수는 3편이다. 세 부모는 서로 독립된 묶음이며 선택기 없이 각 URL에서 정해진 한 편만
재생한다. `SPACE`는 문장 완성/다음, `ESC`는 현재 컷신 스킵, `R`은 현재 묶음 처음부터 다시
보기다. 실제 게임 상태와 `localStorage`는 읽거나 쓰지 않는다.

## 2. 제작 결과

- Q4A 장부 판독을 관리 서명 → 비정상 지출 → `T.C.` 넉 달 지급 순으로 연출했다.
- `T.C.`를 토마스 카버로 추론하되 정상 고용 지출 반론과 직접 만남 증거의 필요를 남겼다.
- 뱅크스의 정육점 증언, 일주일 동안 밤마다 온 검은 마차, 달+물결 같은 흐릿한 문 표식을
  Q5A 입력으로 전달했다. 파도 수와 마차 소유자는 발화하지 않는다.
- Q5A 진입 컷신은 가스등 → 마차 → 식별 불가 실루엣 → 정박선 → 젖은 바닥 반사까지만
  순서대로 고정한다. 문짝 확대는 초승달과 수를 셀 수 없는 불규칙 잔흔만 보여 주며 런타임은
  추가 선을 그리지 않는다. 마지막은 작업대에서 이어 보겠다는 미래형 인계다.
- Q4B 복원 일지는 자정 → 검은 마차 → 가스등 두 번째 기둥 옆 → 토마스 탑승 → 사흘째 같은
  자리 순으로 읽는다. 장부와 다른 젖고 찢어진 작은 항해일지 자산을 사용한다.
- Q5B 입력은 뱅크스 직접 증언으로 선체 기울기·폭풍·난간·두 손·어머니 호출을 모두 확보한다.
  에드먼드는 구조하거나 영웅처럼 선 사람이 아니라 두려워 매달린 열여덟 살로 묘사한다.
- Q4C closing은 램이 젊은 자화상의 정체를 처음 밝히고, 굽은 코·두꺼운 오른눈썹·네모난 턱을
  현재 얼굴과 대조한다. `q5a=0/1`에 따라 사건 복귀/중립 복귀 문구만 바뀐다.
- 화면은 640×384, 텍스트는 1920×1152, 대사창은 x=152 y=278 w=336 h=84로 고정했다.

## 3. 이미지 생성 및 후처리

imagegen 스킬의 기본 내장 도구로 인물이 없는 환경 원화 3종을 각각 생성했다.

1. 경찰서 야간 기록 책상
2. 안개 낀 자정 부두
3. 비 뒤의 광장 화가 작업대

정확한 프롬프트는 `assets/cutscenes/l4-l5/source/PROMPTS.md`에 생성 전에 기록했다. 원본은
`assets/cutscenes/l4-l5/source/`, 실제 검토 배경은 중앙 5:3 크롭 → 640×384 NEAREST 축소 →
제한 팔레트 양자화 후 `backgrounds/`에 저장했다. 인물은 새로 생성하지 않고 정본 표정 시트의
SHA256을 검사한 뒤 `portrait-crop-v1`으로 뱅크스와 램을 준비했다. 뱅크스는 노년 남성 원본
`11-homeless-portraits.png`를 사용한다. 세이렌 기억은 L5→L6와 같은 구도의 출처 고정본을
소유 `source/`에 복사해 해시를 잠근 뒤 안개·미완성 마스크와 손·난간 1.8배 크롭으로만
후처리했다. 증거 삽입컷과 단계 프레임은 재현 가능한
`scripts/prepare-l4-l5-cutscene-assets.py`가 만든다.

## 4. 동일 피드백 에이전트 3회 반복

### 1차 — 미승인 후 수정

1. Q5A가 단일 합성판과 대사 진행만으로 문짝 게이트를 열던 문제를 발견했다. 가스등·마차·
   실루엣·정박선·젖은 반사를 더하는 5개 진행 프레임과 완료 잠금을 추가했다.
2. 문짝 PNG와 반투명 마스크 아래에서 호의 수가 미리 보이던 문제를 발견했다. PNG에서 호를
   완전히 제거하고 잠금 해제 뒤 런타임이 하나씩만 그리도록 바꿨다.
3. Q4B가 작은 항해일지 대신 Q4A 대형 장부를 재사용하던 시각 연속성 문제를 고쳤다.
4. 램의 젊은 자화상과 현재 얼굴이 같은 calm 프레임이던 문제를 정본 high 프레임과 회화·연령
   후처리로 분리했다.

### 2차 — 승인

- 1차 네 문제의 코드, 실제 PNG, manifest 해결을 확인했다.
- 장부·일지·Q5A·Q5B·closing의 이야기 계약과 금지 정보 회귀에서 새 문제가 없었다.
- JS/Python 구문, 자산 경로·규격, fixture와 조작 계약을 통과했다.

### 3차 — 최종 승인

- 총괄 브라우저의 수정본 증거를 포함해 재검토했다.
- Q5A 게이트 첫 프레임은 초승달만 있고 호는 0개, 3.2초 뒤 끊긴 호 4개가 순차 완료됐다.
- Q5B 폭풍·난간·두 손 화면, Q4C `q5a=0/1`, `R`/`ESC`, 콘솔 warn/error 0을 확인했다.
- 파도 수 사전 대사 금지, 마차 소유자 비공개, Q5B 필수 입력, 실제 게임 비연결을 모두 통과했다.
- 치명·중요 문제 0건으로 최종 승인했다.

## 7. 전체 최종 QA 1차 반영

이 절은 앞선 동일 피드백 에이전트 3차 승인 뒤 실시된 전체 컷신 최종 QA의 1차 수정 결과다.
앞 절의 ‘게이트 0→4’ 검토 이력은 당시 버전의 기록이며 현재 런타임에는 남아 있지 않다.

### P0 공개 순서 수정

1. `gateRevealCount`, `q5aLayoutComplete`, `gateComplete`와 파도 선 순차 드로잉을 모두 제거했다.
   C5A 문짝은 초승달과 수를 셀 수 없는 불규칙·미확정 잔흔만 보여 준다.
2. 마지막 플레이어 대사를 “문짝의 끊긴 흔적은 작업대에서 이어 보겠습니다.”로 바꿔 네 줄
   발견을 Q5A 작업대 이후로 미뤘다.
3. 화면의 `Q5A 내부 발견 게이트` 메타 캡션을 제거하고
   `문짝 확대 · 안개 속에 남은 흔적`이라는 세계관 캡션으로 교체했다.

### 스토리·연속성 수정

1. 장부에 같은 줄리언 관리 서명 아래 십이 년 동안 재산이 비정상 지출로 빠져나갔음을
   명시했다. 동기나 범행 확정은 하지 않았다.
2. 경찰서에서 부두로 페이드한 뒤 플레이어가 뱅크스를 세이렌 호 생존 선원으로 소개하고
   토마스 카버를 아는지 묻는 비트를 추가했다.
3. C5B도 “뱅크스 씨, 세이렌 호 생존 선원께서 맡긴 일지를 복원했습니다. 돌려드립니다.”로
   시작하고 일지 판독으로 이어진다.
4. 뱅크스 초상을 여성 `07-gravekeeper` 시트에서 노년 남성
   `11-homeless-portraits.png` calm/high/tense로 교체했다. manifest에는 원본 경로·SHA256과
   `elderly male survivor-sailor` 정체성을 기록했다.
5. 거대 직선 비와 평면 실루엣을 제거했다. 출처 고정 `siren-night-memory-reference.png`에서
   만든 안개 낀 기억 중간본과 약 1.8배 손·난간 크롭을 사용하고, 첫 손 뒤 두 번째 손을 순차
   강조한다. 이는 Q5B 복원 완료본이 아니라 가장자리와 기억 일부가 가려진 입력 장면이다.
6. 젊은 램은 짙은 머리, 정리된 눈밑, 청록 조끼와 단정한 목깃으로 후처리하고 다음 비트에서
   회색 머리·지친 현재 얼굴과 병치했다.
7. Q5A 완료 closing의 `남은 그림`을
   “증거판에 남은 일이 있다면 마지막 연결까지 마치시오.”로 바꿨다.
8. 장부와 작은 항해일지에 종이 섬유, 수선, 젖은 테두리와 번진 잉크 아래층을 추가했다.
   모든 증거 캡션 뒤에 불투명한 어두운 띠를 넣어 640×384 대비를 높였다.

## 8. 전체 최종 QA 2차 반영

- `carriage-door-gate.png`에서 4행/4호로 셀 수 있던 청회색 호 구조를 완전히 제거했다.
- 문짝 잔흔은 정확히 여섯 개의 비정형 꺾인 조각으로 다시 생성한다. 조각은 높이·방향·길이가
  모두 다르고 서로 교차하므로 네 개 평행 파도나 완성 호에 대응할 수 없다.
- 런타임은 이 정지 자산 위에 추가 선을 그리지 않으며, 실제 Q5A용 네 줄 자산은 만들지 않는다.
- 장부 대사는 “십이 년 동안 재산이 비정상 지출로 빠져나갔습니다.”로 자연화했다.
- 자산 재생성, `node --check`, 문짝 생성 코드의 단일 초승달 외 `arc` 부재와 최종 PNG 정적
  시각 검사를 통과했다.

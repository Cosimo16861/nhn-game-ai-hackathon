# 침대·의자 상태 세트

사람이 포함되지 않은 게임용 투명 PNG 오브젝트입니다. 32×32 기본 타일 맵에서 바닥 중앙(`bottom-center`)을 기준으로 배치합니다.

## 구성

- 가정용 목재 침대: 정돈, 흐트러짐, 조사, 숨겨진 수납공간, 파손
- 진료소 철제 침대: 정돈, 사용 흔적, 조사, 숨겨진 수납공간, 파손
- 참나무 의자: 기본, 뒤로 뺌, 방향 전환, 넘어짐, 파손
- 붉은 안락의자: 기본, 이동, 쿠션 들기, 숨겨진 틈, 파손

`objects/`에는 20개의 개별 투명 PNG가 있습니다. 침대는 64×96, 목재 의자는 48×64, 안락의자는 64×64입니다.

## 게임 적용

- `manifest.json`의 `interaction_anchor`를 조사 위치 기준으로 사용합니다.
- `sit_enabled`가 `true`인 의자 상태에만 앉기 동작을 허용합니다.
- `movable`이 `true`인 상태는 밀기 또는 위치 변경 퍼즐에 사용할 수 있습니다.
- `search_reveal`이 `true`인 상태에서 숨겨진 증거를 별도 오브젝트로 표시합니다.
- 넘어지거나 파손된 의자는 앉을 수 없으며 충돌 영역은 유지합니다.

미리보기 GIF는 상태 비교용이며 실제 게임에서는 상호작용 이벤트에 맞춰 개별 PNG를 교체하면 됩니다.

# C0 인트로 컷신 검토본

## 목적

기존 설명 카드형 인트로를 폐기하고, 승인된 최신 컷신과 동일한 640×384 도트 화면·336×84 대사 상자·3배 한글 레이어로 재구성한다. 인트로는 플레이어의 직업과 그림 복원의 책임을 설명한 뒤 `C0B_THE_JOB`으로 바로 이어진다.

## 장면 순서

1. 비 내리는 플레이어 사무실 — 헤이번에는 사진기가 없다는 세계관 규칙
2. 연필과 미완성 얼굴 — 기억이 증언으로 전달된다는 원리
3. 종이 위 얼굴 복원 — 플레이어 직업 소개
4. 개·이사 간 딸·죽은 남편의 의뢰 기록 — 평소 의뢰의 범위
5. 완성된 세 초상 — 얼굴을 종이에 붙잡는 역할
6. 경찰 기록 — 경찰도 복원화를 의뢰한다는 전환
7. 수배 초상과 다른 피의자 — 오복원이 무고한 사람을 해칠 수 있다는 위험
8. 닫힌 문과 세 번의 노크 — 경찰 방문 후 `C0B_THE_JOB` 자동 재생

## 디자인·입력 계약

- 배경, 인물, 삽입 이미지 모두 도트 렌더링 및 최근 컷신 팔레트를 사용한다.
- 대사 상자는 `{ x:152, y:278, w:336, h:84 }`로 고정한다.
- `SPACE`: 현재 문장 완성 후 다음 비트, `ESC`: 현재 컷신 스킵, `R`: 인트로 처음부터.
- 별도 제목·재생·현재 컷신 선택 패널 없이 화면을 컷신이 채운다.

## 검증 결과

- 세 JavaScript 파일 문법 검사 통과.
- 실제 브라우저에서 640×384 재생, 대사 줄바꿈, 세 초상 순차 강조, 마지막 노크 장면 확인.
- 마지막 문을 입체 패널·목재 결·황동 손잡이가 포함된 전용 도트 배경으로 교체하고 노크 흔들림·문틀 강조를 재검증.
- `SPACE`, `R`, `ESC` 동작 확인.
- 게임 시작 화면에서 인트로를 스킵했을 때 승인된 `C0B_THE_JOB`으로 즉시 전환됨을 확인.
- 콘솔 경고 및 오류 없음.

# 《안개항의 상속자》 고해상도 그림 복원 퀘스트 정본

> 상태: **2026-08-10 전면 개정 정본**
> 대상: `Q0_MONTAGE`부터 `Q5B_SIREN`까지 복원 퀘스트 14개
> 대체: 64×64·128×128 후보, 픽셀 단위 필수 마스크, 강한 하드 게이트 중심 명세

## 0. 변경 불가 계약

1. 모든 복원 퀘스트는 `assets/questimage/`의 이미지 쌍만 사용한다.
2. 각 쌍의 `완성이미지.png`는 내부 정답, `윤곽선.png`는 플레이 시작 화면이다.
3. 두 이미지는 모두 **1254×1254 원본 해상도 그대로** 불러온다. 64·128·256 논리 격자로 축소하지 않는다.
4. 이미지와 과거 증언이 충돌하면 이미지를 재생성하지 않고 컷신 대사와 작업대 포스트잇을 이미지에 맞춘다.
5. 검은 폐곡선은 잠긴 경계다. 플레이어는 경계 안의 같은 면을 영역 채우기로 칠하고 큰 붓으로 보정한다.
6. 통과는 느슨한 이미지 유사도 하나로 판단한다. 필수 특징별 즉시 실패 조건은 두지 않는다.
7. CLIP은 보조 점수다. 모델이 없거나 신뢰도가 낮아도 제출과 통과를 막지 않는다.

런타임 자산 계약의 기계 판독 정본은 `src/data/questimage-quests.js`다. 본 문서와 경로·증언이
다르면 그 파일을 함께 고쳐 한 커밋에서 동기화한다.

## 2. 컷신·포스트잇 재작성 정본

과거 대본의 정보가 새 그림에 보이지 않으면 그림을 고치지 않는다. 아래 문구가 작업대
포스트잇과 진입 컷신의 사실 계약이다. 완료 컷신은 표의 `완료 뒤 공개`만 새로 말할 수 있다.

- 진입 증언: “회색 모자를 아주 깊게 눌러써서 눈이 전혀 보이지 않았어요.”

## 3. 1254×1254 복원 조작 계약

### 3.1 캔버스

- 내부 캔버스는 항상 1254×1254다.
- 화면에는 420~760 CSS 픽셀 범위로 축소해 보여 주되 포인터 좌표는 원본 좌표로 환산한다.
- 확대 범위는 60~160%다. 확대해도 내부 픽셀을 재표본화하지 않는다.
- 완성본과 플레이 결과의 점수 비교도 1254 원본 공간에서 수행한다.

### 3.2 폐곡선

- `윤곽선.png`의 휘도 205 이하 픽셀은 잠긴 경계로 본다.
- 나머지 픽셀은 4방향 연결 요소로 한 번만 라벨링한다.
- 채우기 도구는 클릭한 연결 요소 전체를 같은 팔레트색으로 칠한다.
- 붓·지우개도 누르기 시작한 연결 요소 밖으로 넘어가지 않는다. 선을 가로질러 다른 면을
  오염시키는 조작 실수를 막는다.
- 경계가 실제로 닫히지 않는 자산은 이미지 교체보다 임계값·미세 틈 닫기 전처리를 먼저 검토한다.

### 3.3 도구

| 도구 | 기본값·크기 | 목적 |
| --- | --- | --- |
| 영역 채우기 | 기본 선택 | 대부분의 닫힌 면을 한 번에 칠함 |
| 붓 | 지름 16·36·72px | 작은 면, 중간 면, 넓은 명암 보정 |
| 지우개 | 현재 붓 지름 | 선택한 폐곡선 안에서 흰 종이로 되돌림 |
| 확대·축소 | 20% 단계 | 작은 얼굴·문양 면 확인 |
| 실행 취소 | 테스트 5회, 제작 목표 20회 | 1254² 전체 스냅샷 메모리를 제한 |

1px 붓, 픽셀 격자, 64/128용 연필 도구는 사용하지 않는다.

### 3.4 팔레트

- 각 퀘스트는 완성본에서 뽑은 6~8개의 대표색만 보여 준다.
- 목표 이미지의 미세 그라데이션을 정확히 재현하도록 요구하지 않는다.
- 같은 폐곡선 안에 대표색 하나를 칠하는 것이 정상 답안이다.
- 대표색과 목표 픽셀의 차이는 연속적인 색 거리로 계산하므로 근접색도 부분 점수를 받는다.

## 4. 완화된 유사도 계약

### 4.1 기본 점수

| 항목 | CLIP 사용 가능 | CLIP 사용 불가 |
| --- | ---: | ---: |
| 지각 색 유사도 | 70% | 82% |
| 채색률 | 15% | 18% |
| CLIP 의미 유사도 | 15% | 자동 재분배 |

- 최초 통과선은 전 퀘스트 **60점**이다.
- 색 거리는 대표색 차이를 관대하게 받아들이는 연속 함수로 계산한다.
- 검은 윤곽선은 채점 대상에서 제외한다.
- CLIP은 완성본 대비 복원본의 전체 인상·구역 의미를 확인하는 보조 신호다.
- CLIP 모델 다운로드 실패, 오프라인, 신뢰 구역 0개는 실패 사유가 아니다.
- 필수 특징별 70% 정확도, 파도 수·귀 수 즉시 실패 같은 하드 게이트는 두지 않는다.
- 빈 캔버스는 낮은 색 점수와 0에 가까운 채색률로 자연스럽게 실패한다.

### 4.2 플레이어 피드백

플레이어에게 숫자는 노출하지 않는다. 테스트 페이지에서만 보정용 숫자를 접힌 QA 패널에
표시한다.

| 내부 상태 | 문구 |
| --- | --- |
| 통과 | `증거로 사용할 수 있을 만큼 복원됐다.` |
| 8점 이내 | `거의 완성됐다.` |
| 22점 이내 | `전체 인상은 잡히고 있다.` |
| 그 이하 | `증언 메모를 다시 살펴보자.` |

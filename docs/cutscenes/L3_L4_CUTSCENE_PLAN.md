# L3 → L4 컷신 제작 계획

> 기준: `271ffba`, 병렬 계획 `0ee2b32`
> 상태: 내부 제작·QA 완료, 사용자 승인 대기
> 게임 연결: 하지 않음
> 검토 화면: 640×384, 대사창 `x=152, y=278, w=336, h=84`

  문서뿐이다.
- [x] 실제 게임 진행, 저장, 해금, `localStorage`, 공통 CSS와 다른 레이어 컷신은 수정하지 않는다.
- [x] 검토 쿼리는 부모 묶음과 `Q3A` 조건부 fixture 선택에만 쓴다.
- [x] 같은 부모의 여러 편은 개별 선택 없이 고정 순서로 이어 재생한다.

## 2. 실제 재생 묶음

| 부모 | 순서 | 컷신 | 다음 노드 |

| Q3A 완료 | 1/2 | `C4A_LEDGER_TRAIL` 《세 줄이 남긴 장부》 | Q4A 번진 장부 |

`ESC`로 C4A만 넘겨도 C4C가 이어진다.

## 3. 장면 계약 체크리스트

### C4A_LEDGER_TRAIL → Q4A

- [x] Q3A 결과 초승달+파도 세 줄 봉인과 카버 칠판의 네 줄을 같은 배율로 나란히 둔다.
- [x] 플레이어가 밀랍 조각과 편지 눌림의 결합 결과가 세 줄임을 말한다.
- [x] 홀트가 매주 보던 진품도 세 줄이었다고 직접 출처를 보강한다.
- [x] 리드는 네 줄을 단순 창작으로 단정하지 않고 “다른 것을 보고 배웠다면?”까지만 묻는다.
- [x] 사람을 한동안 먹이고 재웠다면 계속된 지출이 남는다는 추론으로 장부에 전환한다.
- [x] 리드가 아셔튼 가 12년 재산 관리 장부를 가져오고, 침수로 붙고 번진 상태를 말한다.
- [x] 플레이어가 관리 서명 열·지출 열·반복 지급으로 보이는 훼손 행의 남은 획을 이어
  복원하겠다고 명시한다.
- [x] 장부 화면에는 판독 가능한 `T.C.`, 줄리언 서명, 넉 달, 마차, 방계, 범인 결론이 없다.

대사 의미 앵커:

- 플레이어: “밀랍 조각과 편지 눌림이 같은 모양을 만들었습니다. 파도는 세 줄입니다.”
- 리드: “칠판에는 네 줄이오. 지어낸 게 아니라 다른 것을 보고 배운 거라면?”
- 플레이어: “사람은 숨겨도 계속된 지출은 숨기기 어렵습니다.”
- 리드: “관리 장부요. 침수돼 서명과 지급행이 번졌소.”
- 플레이어: “서명 열과 지출 열, 반복된 지급행의 남은 획을 이어 보겠습니다.”

### C4C_SQUARE_CHALLENGE → Q4C

- [x] 경찰서를 나오는 이동 페이드 뒤 광장으로 전환한다.
- [x] 램이 군중 앞에서 사건 그림쟁이에게 공개 도전한다.
- [x] 이젤에는 두꺼운 덧칠 아래 오래된 젊은 남자 얼굴 윤곽만 보인다.
- [x] 램은 정체를 말하지 않고 “이것도 못 맞추면 간판을 내리라”고 한다.
- [x] 현장 확대에는 굽은 코, 유독 두꺼운 오른눈썹, 네모난 턱의 남은 붓질이 모두 보인다.
- [x] 플레이어가 그 세 붓질을 따라 덧칠 전 얼굴을 복원하겠다고 한다.
- [x] 젊은 램이라는 정체, 사건 인물 연결, 엔딩 정보는 공개하지 않는다.

### C3B_TOO_NEW_CLOSING

- [x] 손목 그림을 증거 모드로 보여 주고 기존 닻 도안·선명한 잉크·붉은 피부를 유지한다.
- [x] 오래된 문신과 맞지 않아 최근 문신이라는 강한 심증이 든다고 관찰한다.
- [x] 리드는 그림만으로 정확한 날짜를 법정에서 확정할 수 없다고 선을 긋는다.
- [x] `main=q3a-pending`이면 엘리너의 편지와 밀랍 봉인 실물을 확인하라고 상기한다.
- [x] `main=q3a-complete`이면 조서에 붙이고 남은 열린 원으로 돌아가자는 중립 문구를 쓴다.
- [x] 새 노드를 열지 않고 줄리언 지시·정확한 시술일을 말하지 않는다.

### C4B_CAT_FOUND_PAPERS → Q4B

- [x] Q3C에서 확보한 높이가 다른 상자와 젖은 바닥의 등불 동선을 따라 안개를 찾는다.
- [x] 회색 몸·흰 귀 하나·붉은 리본인 같은 고양이가 상자 틈에서 나온다.
- [x] 고양이가 있던 틈에서 젖고 찢어진 종이 뭉치를 발견한다.
- [x] 코라는 기름 먹인 표지와 매일 쓰는 습관을 근거로 뱅크스의 작은 항해일지라 식별한다.
- [x] 코라는 뱅크스가 세이렌 호에서 건져 온 물건이라 했고 돌려줘야 한다고 말한다.
- [x] 글 내용은 읽지 않고 종이 결·찢긴 모서리·남은 잉크 획부터 맞춘다.
- [x] 자정, 검은 마차, 두 번째 기둥, 토마스, 마차 주인, 파도 수는 말하거나 그리지 않는다.

## 4. 자산·연출 계획

| 종류 | 자산 | 제작 방식 | 640×384 사용 |
| --- | --- | --- | --- |
| 배경 | 경찰서 저녁 | 승인된 기존 경찰서 환경을 로컬 자산으로 후처리 | C4A, C3B |
| 배경 | 항구 광장 해질녘 | 이미지 생성 후 96색 NEAREST 후처리 | C4C |
| 배경 | 창문 없는 창고 내부 | 이미지 생성 후 80색 NEAREST 후처리 | C4B |
| 초상 | 플레이어·리드·홀트·코라 | 승인된 초상 파일을 로컬 복사 | 해당 대화 |
| 초상 | 램 | 잠긴 정본 시트의 0·1·3 프레임, `portrait-crop-v1` | C4C |
| 삽입 | 세 줄 봉인/네 줄 칠판 비교 | Q3A 정답+공용 심볼, 동일 배율 카드 | C4A |
| 삽입 | 판독 전 침수 장부 | Q4A 초기 자산을 추가 마스킹, 식별 문자열 없음 | C4A |
| 삽입 | 닻 손목 그림 | Q3B 정답 자산, 붉은 피부 강조 | C3B |
| 삽입 | 덧칠 얼굴 | Q4C 초기 자산+세 특징 런타임 강조 | C4C |
| 삽입 | 젖고 찢어진 일지 | Q4B 초기 자산을 파편 카드로 구성 | C4B |
| 삽입 | 안개 | Q2B 정답 자산 재사용 | C4B |

연출은 경찰서 램프 흔들림, 증거 카드 확대, 봉인 세/네 줄 순차 강조, 침수 물결, 광장 군중
실루엣과 이동 페이드, 이젤 덧칠의 세 특징 펄스, 창고 등불 흔들림·젖은 바닥 반사·고양이
눈 깜빡임·종이 물방울로 구분한다. 모든 핵심 단서는 하단 106px 대사창 뒤에 놓지 않는다.

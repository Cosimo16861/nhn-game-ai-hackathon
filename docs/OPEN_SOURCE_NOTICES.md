# 오픈소스 및 AI 모델 사용 기록

## TensorFlow.js

- 프로젝트: TensorFlow.js
- 버전: 4.22.0
- 용도: 브라우저 내 신경망 추론
- 라이선스: Apache License 2.0
- 출처: https://github.com/tensorflow/tfjs
- 배포: https://cdn.jsdelivr.net/npm/@tensorflow/tfjs@4.22.0/dist/tf.min.js

## TensorFlow.js MobileNet

- 프로젝트: TensorFlow.js Models — MobileNet
- 패키지 버전: 2.1.1
- 모델 설정: MobileNetV2, alpha 0.5
- 용도: 원본·가림 상태·복원 이미지의 특징 임베딩 추출 및 AI 인식 회복도 계산
- 라이선스: Apache License 2.0
- 출처: https://github.com/tensorflow/tfjs-models/tree/master/mobilenet
- 배포: https://cdn.jsdelivr.net/npm/@tensorflow-models/mobilenet@2.1.1/dist/mobilenet.min.js

AI 인식 회복도는 가림 상태 대비 복원 후 의미 유사도의 변화량을 나타내는 선택적
참고 지표이며 게임의 종합 점수에는 포함하지 않는다.

# 발자국·바퀴 자국 증거 세트

각 증거를 추리 게임의 네 사용 위치에 맞게 분리한 투명 PNG 세트입니다.

## 증거 종류

- 작업화 발자국: 격자형 뒤꿈치와 직사각형 앞굽
- 굽 있는 신발 자국: 작은 사각 굽과 뾰족한 앞코
- 손수레 쌍바퀴 자국: 평행한 좁은 두 줄과 반복되는 철테 홈
- 마차 바퀴 자국: 넓고 깊은 한 줄과 수리된 철테의 끊김

## 증거별 파일

- `map.png`: 맵에 놓는 기본 흔적
- `map-smudged.png`: 부분적으로 지워진 변형
- `closeup.png`: 확대 조사 화면
- `notebook-icon.png`: 사건 수첩 아이콘
- `discovered-highlight.png`: 발견·선택 강조 상태

## 게임 적용

- 맵 흔적에는 충돌을 적용하지 않고 조사 상호작용만 둡니다.
- 발견 전에는 일반 맵 이미지를 사용하고, 커서 접근 또는 조사 모드에서 강조 이미지를 잠깐 표시합니다.
- 확대 조사에서는 밑창 홈, 굽 모양, 바퀴 간격과 수리 흔적을 비교 단서로 사용합니다.
- 수집 후에는 맵 흔적을 숨기고 `notebook-icon.png`를 사건 수첩에 등록합니다.

# L4 → L5 컷신 제작 계획

> 상태: 독립 검토본 제작 중
> 기준: `271ffba`, 병렬 계획 확정 `0ee2b32`
> 게임 연결: 하지 않음
> 검토 화면: 640×384, 대사창 x=152 y=278 w=336 h=84, 텍스트 1920×1152

## 1. 소유 범위와 묶음

이 작업은 `assets/cutscenes/l4-l5/**`, `dev/cutscenes/cutscene-review-l4-l5.html`,
`dev/cutscenes/cutscene-review-l4-l5.js`, `scripts/prepare-l4-l5-cutscene-assets.py`, 이 계획과 검토 기록만
수정한다. 공통 재생기, 퀘스트 그래프, 저장·진행·해금 및 `localStorage`에는 연결하지 않는다.

| 부모 fixture | 순서 | ID/가제 | 다음 노드 |
| --- | :--: | --- | --- |
| Q4A 완료 | 1/1 | `C5A_CARRIAGE_WITNESS` 《넉 달과 검은 마차》 | Q5A 안개 낀 부두 |
| Q4B 완료 | 1/1 | `C5B_SIREN_WITNESS` 《남겨야 할 그 밤》 | Q5B 세이렌 호의 밤 |
| Q4C 완료 | 1/1 | `C4C_PAINTER_CLOSING` 《사가는 얼굴》 | 없음 |

검토 입력은 `?bundle=q4a`, `?bundle=q4b`, `?bundle=q4c&q5a=0|1`만 사용한다. 각 부모 묶음은
고정 순서로 재생하며 개별 장면 선택 UI를 두지 않는다. `SPACE`는 문장 완성/다음,
`ESC`는 현재 편만 스킵, `R`은 현재 부모 묶음 처음부터 다시 보기다.

## 2. 장면 계약 체크리스트

### C5A_CARRIAGE_WITNESS — Q4A → Q5A

- [ ] 경찰서 장부 확대에서 관리 서명 → 비정상 지출 → `T.C.` 넉 달 지급 순으로 읽는다.
- [ ] 관리 서명이 줄리언 아셔튼임을 장부 출처로 판독한다.
- [ ] `T.C.`를 토마스 카버로 추론하되, 정상 고용 지출이라는 반론 가능성을 남긴다.
- [ ] 두 사람이 직접 만났다는 별도 증거가 필요하다고 명시한다.
- [ ] 부두에서 뱅크스가 카버는 선원이 아니라 정육점에서 일하던 사람이라고 직접 증언한다.
- [ ] 카버가 시내로 올라가기 전 일주일 동안 밤마다 검은 마차가 가스등 밑에 왔다고 말한다.
- [ ] 문에는 `초승달과 물결 같은 표식`만 보았고 안개 때문에 수와 세부는 모른다고 선을 긋는다.
- [ ] 가스등·마차·식별 불가 카버 실루엣·배·젖은 돌바닥·문 표식을 Q5A 입력으로 넘긴다.
- [ ] 마차 소유자, 방계, 줄리언과 마차의 직접 연결, 파도 수를 공개하지 않는다.

Q5A 작업대 인계 시각화(전체 최종 QA 1차 잠금):

1. 컷신의 기억 도식에서는 가스등·마차·식별 불가 실루엣·정박선·젖은 돌바닥만 차례로
   고정한다.
2. 문짝 확대는 초승달과 수를 셀 수 없는 불규칙·미확정 잔흔만 보여 준다.
3. 파도 수를 텍스트·그림·채점 표식 어디에도 표시하지 않고, 완성 선을 그리지 않는다.
4. 컷신은 “문짝의 끊긴 흔적은 작업대에서 이어 보겠습니다”라는 미래형 인계로 끝낸다.
5. 네 줄 발견과 판정은 Q5A 작업대 내부에서만 일어나며 이 진입 컷신은 시연하지 않는다.

### C5B_SIREN_WITNESS — Q4B → Q5B

- [ ] 복원 일지를 `자정` → `검은 마차` → `가스등 두 번째 기둥 옆` → `토마스가 탔다` →
  `사흘째 같은 자리` 순으로 읽는다.
- [ ] 뱅크스는 마차 주인을 몰랐고 안개 속 문짝만 봤다고 말한다.
- [ ] 뱅크스가 일지를 돌려받고 세이렌 호 침몰 기억을 그림으로 남기기로 결심한다.
- [ ] 선체가 폭풍 속에서 크게 기울었다는 직접 증언을 받는다.
- [ ] 난간이 보였고 에드먼드는 두 손으로 난간을 붙들어 미끄러지지 않으려 매달렸다고 말한다.
- [ ] 에드먼드가 어머니를 불렀다고 말한다.
- [ ] 구조하거나 영웅적으로 선 자세가 아니었음을 분명히 한다.
- [ ] 플레이어가 선체 기울기·폭풍·난간·두 손 자세를 그려 증언을 남기겠다고 한다.
- [ ] 아셔튼/줄리언 배후, 마차 문양과 파도 수, 얼굴 식별 세부, 사망 신고서, 엘리너의 최종
  반응을 공개하지 않는다.

### C4C_PAINTER_CLOSING — Q4C closing

- [ ] 램이 복원된 젊은 얼굴을 자기 자화상이라고 처음 밝힌다.
- [ ] 젊은 얼굴과 현재 램 모두 굽은 코·두꺼운 오른눈썹·네모난 턱을 유지한다.
- [ ] “사람들은 자기가 기억하고 싶은 얼굴만 산다”는 주제 문장을 유지한다.
- [ ] `q5a=0`이면 사건으로 돌아가라고 상기한다.
- [ ] `q5a=1`이면 남은 열린 원으로 돌아가는 중립 문구를 쓴다.
- [ ] 범인이나 결정적 증거, 새 퀘스트를 주지 않는다.

## 3. 이미지·후처리 계획

정확한 생성 프롬프트는 `assets/cutscenes/l4-l5/source/PROMPTS.md`에 먼저 기록한다. 내장 이미지
생성 도구로 인물이 없는 16:9 원화를 만든 뒤 중앙 5:3 크롭, 640×384 NEAREST 축소, 제한
팔레트 양자화로 승인본 도트 밀도에 맞춘다.

| 자산 | 용도 | 공개 통제 |
| --- | --- | --- |
| 경찰서 야간 배경 | 장부 판독 | 장부 글자는 런타임 삽입컷에서만 표시 |
| 안개 낀 부두 배경 | 뱅크스 증언과 Q5A 입력 | 마차·인물·문양을 배경 원화에 넣지 않음 |
| 광장 화가 작업대 배경 | 램 closing | 자화상 얼굴은 정본 램 초상을 가공한 삽입컷으로만 표시 |

인물은 새로 생성하지 않는다. 플레이어·리드는 C0B 승인본을 참조한다. 뱅크스는 노년 남성인
`11-homeless-portraits.png`, 램은 `10-drunkard-portraits.png` 정본 4프레임 시트에서
`portrait-crop-v1`(가로 4등분 → 프레임 → 알파 bbox → 높이 320px NEAREST)로 준비한다.
뱅크스는 세이렌 호 생존 노선원으로 다루며 술 취한 희화화를 하지 않는다.

결정적 삽입컷은 코드/후처리로 만든다.

- `restored-ledger.png`: 관리 서명, 비정상 지출, `T.C.` 4개월을 순차 강조할 수 있는 장부.
- `carriage-layout-1..5.png`: 가스등 → 검은 마차 → 식별 불가 실루엣 → 정박선 → 젖은
  돌바닥을 한 단계씩 더하는 진행 프레임. 확대 전 문짝 표식은 수를 셀 수 없는 단일 흐림이다.
- `carriage-door-gate.png`: 초승달과 수를 셀 수 없는 불규칙 잔흔만 있는 문짝 확대. 런타임은
  추가 선을 그리지 않으며 Q5A 내부 발견을 앞당기지 않는다.
- `restored-banks-journal.png`: 기름 먹인 작은 표지, 젖음과 찢김이 남은 전용 항해일지.
- `siren-memory.png`, `siren-hands-memory.png`: L5→L6 정본과 같은 구도의 출처 고정 픽셀아트를
  안개·미완성 마스크로 가린 기억 중간본. 손·난간 크롭은 약 1.8배 확대하고 양손을 순차 강조한다.
- `ram-self-portrait.png`: 정본 램 초상으로 만든 젊은 자화상과 굽은 코·두꺼운 오른눈썹·네모난 턱.

## 4. 연출·검토·QA

- 장부 확대: 물번짐 위에 복원 획이 `관리 서명 → 지출 열 → T.C. 4개월` 순으로 나타난다.
- 부두: 안개 층, 가스등 깜빡임, 젖은 바닥 반사, 기억 잔상 배치 후 문짝 내부 발견 게이트.
- 세이렌 기억: 번개, 기울어진 수평선, 파도, 난간과 두 손 자세를 오래 유지한다.
- 램 closing: 복원 자화상과 현재 초상을 같은 배율로 대조한다.
- 같은 피드백 에이전트가 이야기 논리·증언 출처·금지 정보·시각 연속성·조작을 3회 검토하고,
  매 회 수정 후 같은 에이전트에게 재검토를 요청한다.
- 문법 검사, 이미지 규격/알파 검사, 한글 3줄/끝 글자 보존, 묶음 재생·ESC·R, fixture 분기를
  검사한다.
- 사용자 승인 전 실제 게임 진행·저장·해금에는 연결하지 않는다.

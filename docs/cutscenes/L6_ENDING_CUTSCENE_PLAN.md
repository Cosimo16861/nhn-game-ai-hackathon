## `CE_ENDING` 장면·대사 앵커

### 1. 등록부의 마차 소유자 최초 확정 — 경찰서

1. Q6 증거벽과 마지막 붉은 실을 보여 준다.
2. 리드가 등록부의 해당 행을 펼쳐 보인다.
3. 런타임 오버레이가 `JULIAN ASHERTON`, `12 YEARS`, `FOUR-WAVE DOOR`를 차례로 밝힌다.
4. 리드: “해당 마차의 등록 소유자는 줄리언 아셔튼. 그는 십이 년째 같은 문짝 문양을 유지했소.”

등록부를 열기 전에는 어떤 자막·이미지도 줄리언을 마차 소유자로 표시하지 않는다.

### 2. 대질 — 경찰서

1. 줄리언은 “그림은 화가의 주관”이라고 공격한다.
2. 리드는 진품 봉인 세 줄, 등록된 마차 네 줄, 카버가 직접 그린 네 줄을
   같은 배율로 나란히 놓고 독립 출처 세 개를 명시한다.
   - 봉인 출처는 “에드먼드의 아버지가 남기고 엘리너가 보관한 편지와 밀랍 조각”으로
     고정하며, 엘리너가 작성한 편지처럼 표현하지 않는다.
3. 카버: “줄리언이 종이에 그려 줬습니다. 백 번은 그리게 했습니다.”
4. 리드는 카버의 백 번 연습 자백과 장부의 `T.C.` 넉 달 지급이 같은 준비 기간을
   가리킨다고 결합하며, 지급만으로 훈련 기간을 단정하지 않는다.
5. `q3b` fixture일 때만 카버: “문신도 넉 달 전에 줄리언이 시켰습니다.”
6. 리드는 초기 과잉 비난이 “가장 먼저 알고 있었다”는 정황이라고 정리한다.
7. 같은 관리 서명 아래 12년간 이어진 비정상 재산 유출과 장부 감사 위험을 확인한다.
8. 확보한 장부·카버의 사칭 자백·등록부만으로, 줄리언이 가짜 상속인 카버에게 장부 승인과
   재산 처분을 맡겨 횡령을 덮으려 했다는 계획을 결론 낸다. 새 증거는 추가하지 않는다.
9. 리드가 카버는 사칭·공모 혐의로, 줄리언은 공모·횡령 혐의로 구금하라고 명령한다.

### 3. 저택 — 엘리너

1. 카버가 에드먼드가 아니었음을 짧게 전한다.
2. Q2A 복원 초상을 건네고 엘리너가 각진 턱·올라간 왼눈썹·관자놀이 흉터를 기억으로 확인한다.
3. 엘리너: “내가 보고 싶었던 얼굴이 아니라, 그 아이의 얼굴을 돌려주셨군요.”

### 4. 조건부 후일담

- `q2c`: 서쪽 복도 문이 열려 있고 크레용 그림 옆에 진짜 초상이 걸린다.
- `q3b`: 대질 문신 자백 한 줄에만 반영한다.
- `q3c`: 선술집 창가에서 안개가 졸고 코라가 창을 닦는다.
- `q4c`: 램이 광장에서 복원 초상을 베껴 팔고 리드가 쫓아낸다.
- `q5b`: 세이렌 호 그림을 전달한다. 에드먼드가 두 손으로 난간을 잡고 어머니를
  불렀던 두려운 열여덟 살이었음을 들은 뒤, 엘리너가 사망 신고서에 서명한다.

### 5. 마지막 사무소

1. 오프닝과 같은 사무소 구도로 돌아간다.
2. 본선 증거 카드와 붉은 실을 한 개씩 밝힌다.
3. 창밖 안개가 걷히고 새벽 빛이 든다.
4. 플레이어: “기억은 원하는 얼굴을 남긴다. 그래서 남은 획을 하나씩 그렸다.”
5. 플레이어: “진실은 한 장의 그림이 아니라, 서로 다른 사람이 남긴 선 사이에 있었다.”
6. 게임 제목 `THE LAST PORTRAIT` 표시.

저택, 서쪽 복도, 선술집, 광장, Q5B 저택, 마지막 사무소의 각 첫 비트에는 검은 화면 위

## 자산 계획과 프롬프트 선기록

정확한 프롬프트는
`assets/cutscenes/l6-ending/source/PROMPTS.md`에 제작 전 고정한다.

- 생성 배경: 등록부가 펼쳐진 경찰서, 아셔튼 저택 응접실, 낮의 선술집 창가,
  아침 광장, 안개가 걷히는 플레이어 사무소.
- 인물: 정본 4프레임 표정 시트만 `portrait-crop-v1`로 후처리. 얼굴을 새로 생성하지 않는다.

  계열은 정답이 없는 중립 plate로 만든 뒤 런타임 픽셀 오버레이만 정확한 사실을 표시한다.
- 런타임 효과: 빗물·먼지·안개 해제·창 닦기·원근 군중·폭풍 번개·붉은 실·증거

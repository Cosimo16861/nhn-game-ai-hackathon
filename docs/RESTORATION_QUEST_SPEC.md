# 《안개항의 상속자》 14개 복원 퀘스트 확정 명세

> 상태: **이미지 생성 전 정본**
> 기준일: 2026-08-09
> 범위: Q0~Q5B의 목표 이미지, 증언 메모, 캔버스 크기, 채점 영역, 통과 조건, 컷신 연결
> 제외: 이미지 생성, 마스크 제작, 퀘스트 데이터 구현, 수치 보정 작업

## 0. 문서 역할

이 문서는 14개 복원 퀘스트마다 다음 계약을 한곳에 고정한다.

```text
진입 컷신 → 작업대 메모·남은 흔적 → 복원 목표 → 숨은 채점 → 완료 컷신
```

이야기 내용은 아래 순서의 정본을 따른다.

1. `docs/QUEST_BRANCH.md` — 노드, 부모, 해금, 가지 규칙
2. `docs/STORY_OUTLINE.md` — 사건의 진실과 퀘스트 결과
3. `docs/script/07_CUTSCENES.md` — 실제 대사와 공개 시점
4. 이 문서 — 목표 이미지 구성, 메모, 크기, 채점 계약
5. `docs/ASSET_SPEC.md` — 파일·폴더·공통 아트 규칙

복원 퀘스트의 세부 사항이 다른 문서와 충돌하면 1~3번의 이야기를 바꾸지 않는 범위에서
이 문서의 목표·메모·크기·채점 계약을 우선한다. 이후 목표 이미지, 선화, 마스크,
`manifest.json`, 퀘스트 데이터는 반드시 이 문서에서 파생한다.

## 1. 전체 크기 배정

사용 가능한 캔버스는 **64×64, 128×128, 256×256**뿐이다. 여기서 “랜덤”은 실행할
때마다 크기가 바뀐다는 뜻이 아니라, 세 크기가 플레이 순서에 불규칙하게 섞이도록 **제작
시 노드별로 고정 배정**한다는 뜻이다. 목표·선화·마스크·저장 데이터가 크기에 의존하므로
런타임 무작위 크기는 사용하지 않는다.

| 레이어 | 퀘스트 | 크기 | 배정 의도 |
| :--: | --- | ---: | --- |
| L0 | `Q0_MONTAGE` | 64×64 | 튜토리얼 최소 단위 |
| L1 | `Q1A_IDEALIZED` | 256×256 | 본선 대형 초상 복원 |
|  | `Q1B_TAVERN_WALL` | 128×128 | 벽의 층과 얼굴을 함께 읽음 |
| L2 | `Q2A_TRUE_FACE` | 256×256 | 결정적 얼굴 비교 |
|  | `Q2B_CAT` | 64×64 | 짧고 명확한 전단 |
|  | `Q2C_CHILD_ROOM` | 128×128 | 크레용 그림과 문자 한 글자층 |
| L3 | `Q3A_SEAL` | 128×128 | 작은 문양의 정밀 조립 |
|  | `Q3B_TATTOO` | 64×64 | 손목과 닻만 기록 |
|  | `Q3C_WAREHOUSE` | 256×256 | 넓은 창고를 등불로 탐색 |
| L4 | `Q4A_LEDGER` | 256×256 | 장부 구조와 결정 행을 읽을 해상도 확보 |
|  | `Q4B_LOGBOOK` | 128×128 | 찢어진 기록과 다섯 정보 조립 |
|  | `Q4C_SQUARE_BET` | 64×64 | 짧고 명확한 광장 내기 |
| L5 | `Q5A_DOCK` | 256×256 | **마지막 필수 복원**, 클라이맥스 현장 |
|  | `Q5B_SIREN` | 128×128 | 선택 가지의 기억 장면 |

- 복원 노드가 둘 이상인 L1~L5에서는 같은 레이어 안의 크기가 겹치지 않는다.
- `Q5A_DOCK`은 엔딩으로 이어지는 마지막 **본선 필수 복원**이며 256×256으로 고정한다.
  `Q5B_SIREN`은 선택 가지라 플레이 순서상 Q5A 뒤에 남을 수 있지만, 종점 Q6은 복원
  퀘스트가 아니다.
- 분포는 64가 4개, 128이 5개, 256이 5개다.

현재 `src/data/quest-graph.js`와 일부 기존 퀘스트 모듈에는 이전 16·96·128 배정이 남아
있다. 이번 단계에서는 명세만 확정하므로 코드는 바꾸지 않는다. 복원 구현 단계의 첫 작업은
이 표로 `gridSize`와 저장 데이터 버전을 동기화하는 것이다.

## 2. 메모와 목표를 연결하는 규칙

### 2.1 작업대에 놓을 수 있는 정보

메모 항목은 세 종류로 제한한다.

- **증언**: 플레이어가 진입 컷신 또는 퀘스트 도입에서 실제로 들은 말
- **현장 관찰**: 남은 안료, 눌림 자국, 찢어진 가장자리처럼 플레이어가 직접 볼 수 있는 것
- **조건부 보조**: 가지를 완료했을 때만 추가되는 도움. 통과 필수 조건이 되지 않음

한 항목은 짧은 인용 또는 한 문장 관찰로 쓴다. 화면에서는 항목 2~3개를 두 장의 포스트잇에
묶어도 되지만, 항목의 화자·문구·공개 조건은 바꾸지 않는다.

### 2.2 메모가 정답을 먼저 말하지 않는 장치

다음은 메모로 직접 알려 주지 않고, 선화·잔존 안료·조각 맞춤·기억 잔상에서 플레이어가
발견한다.

- Q1A의 관자놀이 덧칠과 초상의 미화
- Q1B 아래층 얼굴이 페리라는 사실
- Q3A 진품 봉인의 파도 수
- Q4A의 복원된 장부 내용
- Q4B의 복원된 항해일지 내용
- Q4C 그림 속 인물이 램이라는 사실
- Q5A 마차 문양의 파도 수

특히 Q3A와 Q5A에서 `세 줄`, `네 줄`은 포스트잇에 쓰지 않는다. Q3A는 밀랍 조각과
편지 눌림을 합쳤을 때, Q5A는 마차 영역을 복원하며 끊긴 기억 잔상이 이어질 때 비로소
수를 셀 수 있어야 한다.

### 2.3 정확한 글자와 문양

`우리`, `T.C.`, 장부·일지 문구, 3줄·4줄 문장은 생성 이미지에 맡기지 않는다. 정본
픽셀 레이어를 수동 제작해 목표·선화·컷신·증거판이 같은 파일을 사용한다.

### 2.4 초기 표시·잠금·복원·채점 제외 영역 — 확정

영역은 다음 뜻으로 사용한다.

- **초기 표시**: 작업대 진입 직후 보이는 완성 조각, 희미한 선, 잔존 안료, 위치 앵커
- **잠금**: 처음부터 완성되어 있고 수정할 수 없는 종이·배경·일반 구조
- **복원**: 플레이어가 실제로 칠하거나 맞추며 채점되는 영역
- **채점 제외**: 분위기 장식, 조건부 보조 정보, 생성 원본의 임의 세부처럼 통과에 쓰지 않는 영역

`복원 비율`은 전체 캔버스에서 복원 마스크가 차지해야 하는 범위다. 아래 범위를 넘겨
자유화 비중을 키우지 않는다. 3.2절의 채색률은 **전체 캔버스가 아니라 이 복원 마스크
안에서만** 계산한다.

| --- | --- | --- | --- | --- | ---: |

#### 난이도 안전장치

- Q4A·Q4B에서 플레이어가 한글을 자유화로 쓰게 하지 않는다. Q4A는 끊긴 정본 획을
  채우고, Q4B는 정본 문자가 들어간 조각을 맞춘다.
- Q3A·Q5A의 파도는 완전한 빈칸에 그리지 않는다. 끊긴 홈을 이어 플레이어가 수를
  발견하게 한다.
- Q5A·Q5B의 “빈 캔버스 배치형”은 실제로 **유도선이 있는 기억 재구성형**이다. 주요
  물체는 넓은 위치 앵커에 스냅되고, 픽셀 단위 자유 배치 오차로 실패시키지 않는다.
- 배경·장식이 미완성이어도 필수 단서가 맞으면 통과할 수 있다. 반대로 필수 단서가
  빠지면 배경 완성도가 높아도 통과하지 않는다.
- 정확한 문자·문양 레이어는 생성 원본을 보정하는 정본이며, 생성 원본 자체의 오류를
  플레이어 난이도로 전가하지 않는다.

## 3. 숨은 채점과 통과 계약

### 3.1 공통 계산

각 퀘스트는 의미 영역별 마스크를 가진다. 한 영역의 유사도 점수는 아래 네 축의 가중합이고,
전체 점수는 영역 점수에 이 문서의 영역 비중을 곱한 값이다.

| 프로필 | 색 | 경계 | 구조·명암 | 팔레트 | 적용 |
| --- | ---: | ---: | ---: | ---: | --- |
| `P` 인물·동물 | 40% | 25% | 25% | 10% | Q0, Q1A, Q1B, Q2A, Q2B, Q3B, Q4C |
| `D` 문서·문양 | 25% | 35% | 35% | 5% | Q2C, Q3A, Q4A, Q4B |
| `S` 현장 | 30% | 25% | 35% | 10% | Q5A, Q5B |
| `X` 탐색 | 20% | 20% | 50% | 10% | Q3C |

통과는 다음 조건을 **모두** 만족해야 한다.

1. 전체 점수가 퀘스트의 `전체` 이상이다.
2. 모든 필수 영역이 `영역` 이상이다.
3. 모든 필수 영역의 채색률이 `채색률` 이상이다.
4. 퀘스트별 하드 게이트를 모두 만족한다.

조건부 보조 영역은 안내와 피드백에만 쓰며 전체 점수와 하드 게이트에 넣지 않는다.
숫자·정답 오버레이는 플레이어에게 공개하지 않는다.

### 3.2 노드별 수치

| 퀘스트 | 프로필 | 전체 | 영역 | 채색률 |
| --- | :--: | ---: | ---: | ---: |
| Q0 | P | 80 | 65 | 80% |
| Q1A | P | 78 | 65 | 78% |
| Q1B | P | 76 | 65 | 75% |
| Q2A | P | 82 | 70 | 82% |
| Q2B | P | 80 | 70 | 80% |
| Q2C | D | 78 | 65 | 75% |
| Q3A | D | 84 | 72 | 82% |
| Q3B | P | 80 | 68 | 78% |
| Q3C | X | 76 | 62 | 70% |
| Q4A | D | 82 | 70 | 80% |
| Q4B | D | 80 | 68 | 78% |
| Q4C | P | 78 | 65 | 75% |
| Q5A | S | 84 | 72 | 82% |
| Q5B | S | 80 | 68 | 78% |

이 값은 구현 시작값이 아니라 **명세값**이다. 후속 보정 단계에서 정답·합리적 변형·명백한
오답 fixture가 이 계약과 충돌하는 것이 입증될 때만 문서와 데이터를 함께 변경한다. 파도
수, 인원 수, 흰 귀 수 같은 서사 하드 게이트는 난이도 보정으로 완화하지 않는다.

## 4. 퀘스트별 확정 명세

영역 뒤 괄호는 전체 점수에서의 비중이다. 합계는 퀘스트마다 100%다.

### Q0_MONTAGE · 골목의 손

- **연결**: `C0B_THE_JOB` → Q0 → `C1_THE_CASE`
- **크기·방식**: 64×64 · 부분 채색형
- **메모**
  - 마르타: “챙이 넓은 회색 모자였어요. 눈이 안 보일 만큼요.”
  - 마르타: “왼쪽 뺨에, 여기쯤에 점이 있었어요.”

  오르는 카버의 식별 불가 실루엣, 오른쪽 정박선, 앞쪽 젖은 돌바닥과 낮은 상자. 마차 문에는
  초승달과 파도 정확히 네 줄이 있다.
- **영역**: 전체 배치(20), 검은 마차(20), 가스등·정차 위치(15), 카버 실루엣(10),
  배·젖은 바닥(10), 마차 문양(25)
- **하드 게이트**: 마차가 가스등 아래 있어야 하고, 카버 실루엣과 정박선이 있어야 하며,
  문양은 초승달 하나와 파도 정확히 네 줄이어야 한다. 다섯 번째·세 번째 파도 수는 실패다.
- **기억 잔상 규칙**: 포스트잇은 파도 수를 말하지 않는다. 마차 영역을 채울수록 문의
  끊긴 호 네 개가 순차적으로 선화 잔상으로 이어지고, 플레이어가 마지막에 직접 센다.
- **조건부 보조 규칙**: Q3C·Q4B 메모는 목표를 더 쉽게 찾게 할 뿐 새 필수 영역을 만들지 않는다.
- **완료 연결**: C6은 이 결과의 문을 확대하고 Q3A의 3줄 봉인과 비교한다. 마차 주인 이름,
  줄리언의 얼굴, 아셔튼 표기는 금지한다.

# L5 → L6 컷신 검토 기록

> 상태: 제작 완료 · 사용자 검토 대기
> 게임 연결: 하지 않음
> 기준: `271ffba`, 병렬 계획 확정 `0ee2b32`
> 전용 서버: `http://localhost:8133`

## 1. 사용자 검토 URL과 재생 단위

- Q5A 완료 → Q6: `http://localhost:8133/dev/cutscenes/cutscene-review-l5-l6.html?bundle=q5a`
  - 1/1 `C6_EVIDENCE_WALL` 《세 줄과 네 줄》
  - 자동 재생 약 51.7초
- Q5B 완료 closing, Q5A 미완료 fixture:
  `http://localhost:8133/dev/cutscenes/cutscene-review-l5-l6.html?bundle=q5b&q5a=incomplete`
  - 1/1 `C5B_THAT_NIGHT_CLOSING` 《그 밤》
  - 자동 재생 약 36.4초
- Q5B 완료 closing, Q5A 완료 fixture:
  `http://localhost:8133/dev/cutscenes/cutscene-review-l5-l6.html?bundle=q5b&q5a=complete`
  - 본문은 동일하고 마지막 복귀 문구만 중립 문구로 교체

각 부모 묶음은 한 편이다. 개별 선택 UI 없이 자동 재생하며 `SPACE`는 문장 완성/다음,
`ESC`는 현재 편 스킵, `R`은 현재 부모 묶음의 처음부터 다시 보기다.

## 2. 제작 결과

- 신규 생성 배경 2종: 야간 경찰서 증거 비교실, 새벽 전 사무소 증거 벽
- 신규 생성 삽입컷 1종: 기울어진 세이렌 호에서 난간을 두 손으로 붙잡은 에드먼드의 기억
- 신규 준비 초상 3종: 뱅크스 calm/high/tense
- 재사용 승인 초상: 플레이어, 리드, 홀트
- 런타임 증거 도형: Q5A 마차 문 네 줄, Q3A 진품 봉인 세 줄
- Q6 벽 본선 6장: 수배화, 미화 초상, 복원 얼굴, 진품 봉인, 장부, 마차 기억
- Q6 미완성 마지막 실: 진품 봉인 → 마차 기억
- 효과: 네 줄 순차 공개, 동일 배율 비교, 카드 등장, 먼지·비·램프 맥동, 열린 실 강조,
  폭풍 정지·온색 기억 페이드, 두 손 픽셀 하이라이트

정확한 이미지 생성 프롬프트는 `assets/cutscenes/l5-l6/source/PROMPTS.md`에 생성 전에
기록했다. 내장 이미지 생성 도구로 원본 3장을 만들고 source에 보존한 뒤,
`scripts/prepare-l5-l6-cutscene-assets.py`가 5:3 중앙 크롭, 640×384 NEAREST 리사이즈와
80/96색 양자화를 수행한다. 생성 이미지에는 읽히는 이름·문장·문양을 넣지 않았고 정확한
세 줄·네 줄과 카드 라벨은 런타임에서 합성했다.

## 3. 이야기·증언·스포일러 검사

### C6_EVIDENCE_WALL

- Q5A에서 복원한 뱅크스의 마차 기억을 출처로 네 줄을 직접 센다.
- Q3A의 편지 눌림+밀랍 조각과 홀트의 직접 확인을 출처로 진품 세 줄을 병치한다.
- C3A에서 카버가 직접 그린 칠판 네 줄을 세 번째 독립 출처로 놓는다.
- 결론은 `카버가 진품이 아니라 마차 문에서 네 줄을 배웠다`까지다.
- 소유자는 등록부로 확인하되 아직 이름을 단정하지 않는다.
- `방계 문장`, 마차 소유자 이름, 마차 소유자=줄리언은 대사·그림 모두 노출하지 않는다.
- Q6은 복원이 아니라 본선 6장의 관계를 마지막 실로 증명하는 작업으로 예고한다.

### C5B_THAT_NIGHT_CLOSING

- 기울어진 선체·난간·두 손 자세를 오래 보여 주고 뱅크스가 각도와 자세를 확인한다.
- 에드먼드는 영웅이 아니라 두려운 열여덟 살이며 어머니를 끝까지 불렀다.
- 엘리너에게 말하지 못한 이유는 그녀가 듣고 싶은 이야기가 아니었기 때문이다.
- 새 노드·사건 해결 증거는 주지 않는다.
- Q5A 미완료/완료 fixture는 마지막 사건 복귀/중립 문구만 다르다.
- 두 fixture 모두 줄리언·아셔튼·카버 정체·봉인·마차 문양·장부를 언급하지 않는다.

## 4. 동일 피드백 에이전트 3회 검토

### 1차 — 지적 후 수정

P0는 없었다. 다음 P1/P2 네 건을 수정했다.

1. 증거 벽에서 정본 Q1A `미화 초상`이 빠지고 `카버 칠판`이 들어간 문제를 수정해 Q6 본선
   6장과 동일하게 만들고 실 좌표를 재배치했다.
2. 세이렌 인물의 몸이 대사창에 가리고 두 손이 어두운 문제를 고쳐 이미지를 위로 이동하고
   암전을 줄였으며 두 손에 결정론적 픽셀 하이라이트를 더했다.
3. 상단 중앙의 `Q5A/Q5B 복원 결과` 메타 캡션을 제거해 컷신 제목/검토 메타 금지 계약을
   지켰다.
4. 네 번째 파도가 나타나기 전 SPACE로 진행할 수 있던 여지를 없애려고 첫 비트 시각 잠금을
   900ms에서 1750ms로 늘렸다. 네 줄 공개는 약 1680ms에 끝난다.

### 2차 — 승인 가능

- 1차 P1/P2 네 건 해소, 잔여 P0/P1/P2 없음.
- Q6 본선 6장과 미완성 `진품 봉인→마차 기억` 실 확인.
- 세이렌 두 손·낮춘 자세가 대사창 위에서 읽히며 상단 메타 캡션이 사라짐.
- 이야기·최초 공개·Q5B 독립성·화면/조작 계약 통과.

### 3차 — 최종 승인

- P0/P1/P2 없음, 1차 수정 뒤 회귀 없음.
- 7절 대사 앵커, Q6 입력, Q5B fixture 독립성, 자산 규격, 게임 미연결과 소유 경계 통과.
- 최종 판정: 승인.

## 7. 전체 최종 QA 1차 반영

전체 컷신 교차 QA의 L5→L6 지적 다섯 건을 다음처럼 반영했다.

1. `그림을 전부`라는 표현을 `사건을 입증하는 여섯 장`으로 바꿔 가지 완료가 아니라 본선
   Q0→Q5A 여섯 장만으로 Q6과 엔딩에 진입한다는 뜻을 명확히 했다.
2. 빈 카드 프레임을 제거하고 `EV_WANTED`, `EV_IDEALIZED`, `EV_TRUE_FACE`, `EV_SEAL_3`,
   `EV_LEDGER_TC`, `EV_CARRIAGE_4`의 실제 336×216 이미지를 각 카드에 렌더한다. 원본은
   `assets/cutscenes/l5-l6/source/evidence/`, 런타임 사본은 `assets/cutscenes/l5-l6/evidence/`
   아래에 물리 보관해 다른 Worktree 경로에 의존하지 않는다. evidenceWall 계열 인물 초상은
   좌하단으로 축소해 어떤 비트에서도 여섯 장을 가리지 않게 했다.
3. 뱅크스 초상 원본을 L4→L5와 같은 공용 `11-homeless-portraits.png` 0/1/3 프레임으로
   교체했다. SHA256은
   `9b370567ccfc3debe86faf56e73b43c43760cae7aba817a0ceda4d471395c880`이며 크롭 규칙은
   `portrait-crop-v1`을 유지한다.
4. 첫 세 줄 비교의 진품 봉인 강조 원을 문양 중심으로 줄이고, 세 줄 문양 자체에 밝기 펄스를
   적용했다.
5. Q5B의 Q5A 완료 문구를 `증거판에 남은 일이 있다면 마지막 연결까지 끝내시오`로 바꿔
   이미 끝난 그림을 다시 요구하지 않도록 했다.

QA 후 `node --check`, 준비 스크립트 실행, manifest 자산 누락 검사를 통과했다. 640×384 실제
프레임에서 여섯 썸네일이 evidenceWall·evidenceWallHolt·openThread에 걸쳐 가려지지 않고
식별되는지 확인했고, 축소된 봉인 강조 원과 세 줄 밝기 펄스, 새 뱅크스 초상, Q5B 두 fixture,
SPACE/ESC/R, 콘솔 warning/error 없음도 다시 확인했다.

## 8. 전체 QA 2차 반영

C6 첫 대사의 `뱅크스의 기억에서 복원한 마차 문`을 `Q5A에서 복원한 마차 문`으로 바꿨다.
네 줄은 뱅크스가 완성된 수를 직접 기억해 증언한 것이 아니라, Q5A 문짝 확대에서 흐릿한 네
획을 플레이어가 이어 발견한 결과라는 출처 계약을 명확히 했다. 마차 네 줄·진품 세 줄 비교,
마차 소유자 이름 금지와 본선 여섯 장 계약은 그대로 유지한다.

### 2차 시각 P1 후속

축소 카드에서 완료 증거의 핵심이 흐려지던 문제를 런타임 오버레이로 보완했다. 진품 봉인에는
초승달과 파도 정확히 3줄, 마차에는 초승달과 파도 정확히 4줄을 다시 그린다. 장부에는 이미
복원된 `T.C.`와 `4 MO`를 표시한다. 미화 초상은 `미화`, 복원 얼굴은 턱 윤곽·관자놀이 흉터
표식과 `각진 턱 · 흉터`를 함께 표시해 같은 축소 배율에서도 구분한다. 이는 새 증언이나 새
증거가 아니라 Q1A·Q2A·Q3A·Q4A·Q5A에서 이미 완료한 본선 결과의 가독성 보강이다.

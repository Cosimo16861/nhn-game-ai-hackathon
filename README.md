# 픽셀 리콜

불완전한 목격담을 단서로 가려진 사건 이미지를 색칠해 복원하는 브라우저
게임이다. 색상·윤곽선·주변 구조·팔레트 점수와 CLIP 사건 단서 일치도를
결합해 하나의 최종 점수를 계산한다.

## 실행 방법

Node.js가 설치된 프로젝트 폴더에서 다음 명령을 실행한다.

```powershell
node scripts/dev-server.cjs
```

브라우저에서 `http://127.0.0.1:8000/index.html`을 연다. 다른 포트를
사용하려면 `node scripts/dev-server.cjs 8080`처럼 포트 번호를 추가한다.

CLIP 모델은 복원을 시작한 뒤 처음 한 번 내려받으므로 인터넷 연결이 필요하다.
`file://`로 `index.html`을 직접 열면 원격 모듈이나 WASM 로딩이 제한될 수
있으므로 로컬 HTTP 서버 또는 GitHub Pages를 사용해야 한다.

## 게임 진행

1. 대형 사건을 선택하고 `선택한 사건 수사하기`를 누른다.
2. 해제된 세부 사건을 선택해 조사를 시작한다.
3. 사건 이미지 조각과 팔레트를 확인하고 `복원 시작하기`를 누른다.
4. 세 목격담을 바탕으로 4×4 구역 중 불규칙하게 손상된 세 부분을 색칠한다.
5. `현재 상태 채점하기`를 눌러 최종 점수를 확인한다.
6. 사건별 통과 점수 이상이면 수사에 성공한다.

## 기본 점수 구성

- 색상 유사도 40%
- 윤곽선 24%
- 주변 구조 12%
- 팔레트 4%
- CLIP 사건 단서 일치 20%

CLIP이 원본에서 문장을 충분히 구별하지 못한 구역은 의미 점수에서 제외되며,
제외된 비중은 시각 복원 점수로 자동 재배분된다.

오픈소스와 모델 출처는
[`docs/OPEN_SOURCE_NOTICES.md`](./docs/OPEN_SOURCE_NOTICES.md)에 기록되어 있다.

## 대형 사건 개발 구조

새 사건 콘텐츠는 하나의 전체 이미지와 최대 네 개의 2×2 세부 사건으로 구성한다.
`ChapterImageSlicer`가 세부 사건 좌표를 분석용 정사각형 이미지로 변환한다.
박물관 사건은 네 개의 연속 세부 사건으로 구성되며 처음에는 1단계만 열린다.
현재 해제 상태는 화면을 열 때 1단계로 초기화되며, 클리어 결과 저장과 다음 단계
자동 해제는 후속 개발 단계에서 연결한다.

각 세부 사건은 지정된 4×4 구역 세 곳 안에 불규칙한 가림 형태를 만든다.
가림 모양은 사건 이미지에 따라 일정하게 재현되며, 128×128 색칠판 마스크를
256×256 분석판에 정확히 2배 확장해 두 해상도의 채점 범위를 일치시킨다.
손상 영역의 A·B·C 표시는 같은 색의 단서 카드와 연결되며, 해당 영역을
일정 부분 이상 복원하면 이미지 위 표시는 자동으로 사라진다.

## 난이도 규칙

- 쉬움: 손상 범위가 작고 A·B·C 표시가 오래 유지된다.
- 보통: 표준 손상 범위와 표시 시간을 사용한다.
- 어려움: 손상 범위가 넓고 A·B·C 표시가 빠르게 사라진다.

힌트는 쉬움 3회, 보통 2회, 어려움 1회 제공한다. 제작자가 작성한 수사
방향부터 시작해 가장 넓은 손상 영역과 주요 색상을 단계적으로 알려준다.
사용한 힌트는 1회당 최종 점수에서 2점이 차감되며 결과 화면에 사용 횟수와
감점이 별도로 표시된다.

단계 데이터의 `passingScore`가 난이도별 통과 기준을 결정하며, 현재 박물관
세부 사건은 진행 순서에 따라 55점, 60점, 65점, 70점을 사용한다.

색칠 화면은 드래그 브러시, 연결 영역 채우기, 지우개, 실행 취소와
100%·150%·200% 확대 기능을 제공한다. 채우기 작업도 한 번의 실행 취소
단위로 저장된다.

색칠 화면 상단 HUD에는 현재 세부 사건 번호, 난이도, 통과 점수, 경과 시간과
실시간 복원 진행률이 표시된다.

최종 점수가 단계별 `passingScore` 이상이면 세부 사건을 클리어하고 다음
단계를 즉시 해제한다. 결과 화면의 버튼으로 해제된 세부 사건 지도로 이동할 수
있으며, 현재 실행 중에는 기존 클리어 상태가 유지된다.

세부 사건 지도에는 2×2 전체 그림 조립판이 표시된다. 클리어한 세부 사건의
조각만 원본 장면으로 공개되고, 네 단계를 모두 클리어하면 하나의 연속된 전체
사건 그림이 완성된다.

전체 그림이 완성되면 사건별 최종 추리 문제가 열린다. 복원된 네 조각을
종합해 객관식 결론을 선택하며, 정답을 맞혀야 대형 사건이 최종 해결 상태가
된다. 오답일 때는 조각과 목격담을 다시 검토한 뒤 재도전할 수 있다.

클리어 점수는 단계별 별점으로 변환된다. 통과하면 1별, 통과 기준보다 15점
이상이면 2별, 25점 이상이면 3별을 획득하며 최고 점수와 최고 별점만 유지한다.
해제 단계, 클리어 기록, 별점과 최종 추리 결과는 브라우저 `localStorage`에
저장되어 다시 접속해도 이어서 플레이할 수 있다.

## 조작과 접근성

- 마우스·터치: 브러시로 드래그하거나 채우기 도구를 사용한다.
- 키보드: 색칠판에 초점을 둔 뒤 방향키로 이동하고 Enter 또는 Space로 칠한다.
- 화면 전환 시 현재 게임 화면으로 키보드 초점이 이동한다.
- 건너뛰기 링크, 명확한 포커스 표시, 모션 감소와 고대비 환경을 지원한다.
- 모바일에서는 주요 버튼과 색상 선택 영역을 최소 44×44px로 제공한다.

# questimage 고해상도 복원 전환 계획

> 기준일: 2026-08-10
> 현재 단계: Q1A 격리 프로토타입

## 목표

`output/questimage`의 14개 완성본·윤곽선 쌍을 1254×1254 그대로 사용한다. 기존 본 게임은
Q1A 프로토타입 검증이 끝날 때까지 건드리지 않는다.

## 의사결정

- 이미지 재생성보다 증언과 포스트잇을 이미지에 맞추는 것을 우선한다.
- 그림은 폐곡선 면을 팔레트색으로 채우는 컬러링 작업이다.
- 주 도구는 영역 채우기, 보조 도구는 16·36·72px 붓과 지우개다.
- 점수는 색 70% + 채색률 15% + CLIP 15%다.
- CLIP이 없으면 색 82% + 채색률 18%로 자동 전환한다.
- 최초 통과선은 60점이며 특징별 하드 실패는 없다.

## 단계별 작업

### A. 계약 전환 — 완료

- `src/data/questimage-quests.js`에 14개 자산 경로·팔레트·증언을 고정한다.
- `docs/RESTORATION_QUEST_SPEC.md`를 고해상도 정본으로 교체한다.
- 옛 64/128 후보 문서는 비정본으로 표시한다.

### B. Q1A 격리 프로토타입 — 현재 단계

- `questimage-q1a-test.html`은 본 게임 진행·저장과 분리한다.
- 1254² 윤곽선에서 폐곡선 연결 요소를 한 번 계산한다.
- 영역 채우기와 16·36·72px 붓을 제공한다.
- 색·채색률 점수를 항상 계산하고 CLIP은 선택적으로 계산한다.
- QA 전용 완성본 적용 버튼으로 통과 경로를 재현한다.

### C. 보정

- 빈 캔버스는 실패해야 한다.
- 완성본은 CLIP 없이도 통과해야 한다.
- 대표 팔레트로 큰 면을 채운 합리적 답안도 통과해야 한다.
- 색 하나로 전체를 채운 답안은 실패해야 한다.
- 제출과 붓 입력이 일반 노트북에서 눈에 띄게 멈추지 않아야 한다.

### D. 13개 추가 검증

- 같은 테스트 진입점에서 퀘스트 ID만 바꿔 14개를 순회한다.
- 자산별 선 임계값과 팔레트만 보정한다.
- 컷신 대사와 포스트잇이 `questimage-quests.js`의 사실을 벗어나지 않는지 검수한다.

### E. 실제 게임 연결

- 기존 Q0 전용 `WorkbenchQuestConfig`를 14개 공통 등록으로 교체한다.
- `index.html`과 `board.html`은 공통 레지스트리만 로드한다.
- 컷신 삽입 이미지와 증거판 썸네일도 `questimage` 완성본으로 교체한다.
- 저장 데이터에는 1254² 래스터 전체가 아니라 영역별 선택색과 붓 패치만 기록한다.

## 완료 조건

- 28개 경로가 모두 존재하고 1254×1254다.
- 14개 모두 완성본·윤곽선 외 다른 복원 이미지를 참조하지 않는다.
- Q1A 브라우저 테스트에서 수동 채우기, 큰 붓, 되돌리기, 초기화, 제출이 동작한다.
- CLIP 실패가 제출을 막지 않는다.
- 실제 게임 연결 전까지 기존 `index.html?workbench=Q0_MONTAGE` 동작은 유지된다.

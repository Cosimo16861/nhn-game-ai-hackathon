# 15. 표지판과 가로등

영국풍 마을에 사용하는 투명 배경 표지판 10종과 가스 조명 10종입니다.

- `objects/`: 완성 오브젝트 PNG 20개
- `lighting-overlays/`: 점등 오브젝트 7종의 3프레임 조명 오버레이
- `signs-lamps-spritesheet-5x4.png`: 전체 스프라이트 시트
- `day-placement-sample.png`: 낮 배치 예시
- `evening-lit-sample.png`: 저녁 점등 예시
- `manifest.json`: 크기, 충돌, 점등과 렌더링 정보

표지판 면은 비워 두었습니다. 장소명과 사건 안내는 별도 텍스트 레이어로 넣어 번역이나 내용 변경이 가능하게 하세요. 가로등 본체는 오브젝트 레이어에, 노란 조명은 최상단 조명 레이어에 둡니다. 조명 오버레이 3프레임은 140ms 간격으로 반복하면 가스불이 미세하게 흔들리는 느낌을 줄 수 있습니다.

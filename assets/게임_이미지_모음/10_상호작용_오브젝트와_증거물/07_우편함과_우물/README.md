# 우편함·우물 상태 세트

사람이 포함되지 않은 투명 PNG 상호작용 오브젝트입니다. 32×32 타일 맵에서 바닥 중앙(`bottom-center`)을 기준으로 배치합니다.

## 구성

- 붉은 주철 우편함: 닫힘, 편지 투입, 수거함 열림, 단서 소포, 파손
- 녹색 벽걸이 우편함: 닫힘, 빈 상자 열림, 편지 있음, 숨겨진 열쇠, 파손
- 지붕 있는 석조 우물: 대기, 양동이 내리기, 완전히 내림, 단서 회수, 파손
- 오래된 벽돌 우물: 대기, 양동이 내리기, 물 회수, 숨겨진 통 발견, 파손
- 물결 효과 3프레임

## 게임 적용

- 개별 오브젝트 20개는 `objects/`에 있습니다.
- 우물 물결은 `effects/`의 3프레임을 반복 재생합니다.
- `manifest.json`에서 우편 투입·수거, 우물 손잡이 사용, 물 획득, 단서 공개 가능 여부를 확인합니다.
- 파손 상태에서는 상호작용을 막고 수리 사건이나 우회 퍼즐에 연결할 수 있습니다.
- 미리보기 GIF는 상태 비교용이며 실제 게임에서는 사건 진행에 따라 개별 PNG를 교체합니다.

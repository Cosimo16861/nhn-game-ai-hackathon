## 0. 결론 — 실제로 필요한 이미지셋

컷신마다 완성 일러스트 한 장을 만드는 방식은 쓰지 않는다. 같은 경찰서가 5개 컷신과
엔딩에 반복되고, 같은 봉인·마차 문양이 이야기 전체를 관통하기 때문이다.

최종 컷신 화면은 아래 네 레이어의 합성으로 만든다.

```text
장소 배경
  + 장면 상태 오버레이(비·안개·열린 문·조명)
  + 인물 초상(calm / tense / high)
  + 사건 삽입 컷(초상·봉인·장부·마차·일지 등)
  + PixelScreen 대사·정확한 글자·인장 선
```

### 확정 제작량

| 이미지셋 | 최종 파일 수 | 생성 원칙 |
| --- | ---: | --- |
| 컷신 장소 배경 | **8키** | `office`는 코드 재사용, 나머지 7키는 기존 자산 보정 또는 신규 제작 |
| 특수 기억 배경 | **1장** | `siren-night` — 세이렌 호가 기울던 밤 |
| 배경 상태 오버레이 | **7종 내외** | 비, 안개, 열린 문, 젖은 벽, 창고 암부, 해결 후 햇빛 등 |
| 인물 초상 | **11명 / 26표정** | 대본에 실제 등장하는 표정만 제작 |
| 사건·소품 삽입 이미지 | **18개 베이스** | 확대·크롭·조명 변형으로 약 30개 숏 구성 |
| 후일담 전용 상태 컷 | **5종** | 완료 플래그에 따라 삽입, 기존 배경과 소품을 최대한 재조합 |
| 정확한 문자·문양 | **이미지 생성 제외** | 코드 또는 수동 픽셀로 제작. 생성 이미지에 글자를 맡기지 않음 |

`GAME_DESIGN.md`의 “배경 8종” 다음에는 10개 키가 나열돼 있다. 그중 `school`과
`asherton-keepsake`는 복원 작업대에는 필요하지만 `07_CUTSCENES.md`의 컷신 장소로는
사용되지 않는다. 따라서 **컷신 전용 배경은 8키**, 컷신+작업대 전체는 10키다.

## 1. 절대 바꾸면 안 되는 시각 정보

### 1.1 세 줄과 네 줄은 생성 AI에 맡기지 않는다

이 게임의 추리는 아래 세 이미지를 비교하는 것으로 완성된다.

| 대상 | 반드시 보이는 형태 | 최초 공개 |
| --- | --- | --- |
| 카버의 백묵 인장 | 초승달 + 파도 **네 줄** | `C3A` |
| 본가의 진품 봉인 | 초승달 + 파도 **세 줄** | `Q3A` 결과 / `C4A` |
| 줄리언의 마차 문양 | 초승달 + 파도 **네 줄** | `Q5A` 결과 / `C6` |

파도 수가 한 줄이라도 틀리거나 컷마다 굴곡이 바뀌면 추리가 무너진다. 따라서 다음은
생성 이미지 안에 직접 그리게 하지 않는다.

- 본가 인장 3줄
- 방계 문장 4줄
- 카버가 칠판에 그린 4줄
- 마차 문에 붙는 4줄
- 봉인 ↔ 마차 비교 컷

먼저 하나의 **정본 픽셀 도형**을 코드 또는 수동 픽셀로 만들고, 모든 컷이 그 정본을
확대·회전·색상 변경해서 사용한다. 생성 이미지는 칠판, 밀랍 조각, 마차 문 같은
바탕 재질까지만 담당한다.

### 1.2 정확한 문자는 후처리한다

다음 문자는 스토리 증거이므로 이미지 생성 모델에 맡기지 않는다.

- 「검거」 도장
- 「아셔튼 가의 상속자, 12년 만에 귀환?」
- 「지우지 말 것 — R」
- 장부의 `T.C.` 지급 줄
- 항해일지의 「자정 / 두 번째 기둥 옆 / 사흘째」
- 크레용 그림의 「우리」
- 마차 등록부의 「줄리언 아셔튼」
- 사망 신고서

종이·잉크·도장 질감은 이미지로 만들 수 있지만 글자는 `PixelScreen.text()` 또는
수동 픽셀 레이어로 합성한다.

### 1.3 스포일러 가시성 규칙

- `C5A`에서 뱅크스가 기억하는 마차는 **문양이 식별되지 않는 안개 버전**만 보여준다.
- 마차의 네 줄은 플레이어가 `Q5A`를 복원한 뒤 `C6`에서 처음 명확하게 보여준다.
- `C6`에서는 마차 주인의 이름을 이미지에도 넣지 않는다. 이름은 `Q6` 뒤
  `CE_ENDING`의 등록부에서 처음 공개한다.
- 줄리언의 초상은 `C3A`에서 잠깐 만족한 표정만 보여야 한다. 악역처럼 과장된 조명,
  웃음, 그림자는 금지한다.
- 가지 배경과 소품에는 파도 수, 줄리언의 이니셜, 아셔튼 이름을 숨겨 넣지 않는다.
- `C6B`의 에드먼드는 영웅 포즈가 아니라 난간에 매달린 두려운 열여덟 살로 그린다.

### 최종 규격

| 종류 | 규격 | 배경 |
| --- | --- | --- |
| 장소 배경 | 640×384 PNG, 불투명 | 전체 프레임 |
| 상태 오버레이 | 640×384 RGBA PNG | 투명 |
| 초상 | 64×64 RGBA PNG | 투명, 화면에서는 96×96 정수배에 가깝게 표시 |
| 큰 삽입 컷 | 최대 384×216 RGBA/불투명 PNG | 대화창 위 안전 영역에 배치 |
| 소품 | 32~192px RGBA PNG | 정수 좌표 배치 |
| 문양 정본 | 32×32 또는 64×64 RGBA PNG | 1px 외곽선, nearest-neighbor |

공통 화면은 640×384다. 하단 112px는 대화창, 좌하단과 우상단은 초상 자리이므로
배경의 중요한 단서는 **중앙 x=150~490, y=30~235** 안에 둔다. 생성 원본은 더 크게
만들어도 최종 크롭과 리사이즈는 반드시 정수 좌표로 한다.

### 아트 기준

- 19세기 후반풍 가상 항구 도시, 저채도 갈색·청록·테라코타·크림
- 외곽선은 순수 검정이 아닌 `#2E241E` 계열
- 왼쪽 위 광원, 오른쪽 아래 그림자
- 재질은 하이라이트/기본/그림자/깊은 그림자의 4단계
- 배경과 소품은 의도하지 않은 블러·반투명 에어브러시·부드러운 안티앨리어싱 금지
- 한 이미지 안에 텍스트, 워터마크, 로고를 생성하지 않는다
- 배경에는 대화 인물을 포함하지 않는다. 인물은 초상 레이어에서만 표현한다

### 배경 생성 우선순위

1. `police-station` — 가장 많이 재사용되고 핵심 추리 컷 대부분이 여기서 일어난다.
2. `dock` — 마차 반전과 보조 목격담의 공간 배치가 모두 여기서 결정된다.
3. `asherton-parlor` — 엘리너의 감정선 시작과 끝을 같은 장소로 묶는다.
4. `office` 상태 오버레이 — 시작의 안개와 마지막의 맑은 창을 대칭시킨다.
5. `asherton-west-hall` — 닫힌 문/열린 문 변주가 후일담 보상이다.
6. `tavern`, `dock-warehouse`, `town-square` — 기존 자산을 우선 보정한다.
7. `siren-night` — 독립 특수 일러스트로 마지막에 제작한다.

### 배경 제작 시 추가로 해결할 것

`C4A_WET_LEDGER`는 메타데이터상 `police-station`이지만 마지막에 광장으로 이동한다.
따라서 컷신 데이터는 비트마다 `background: "town-square"`를 지정할 수 있어야 한다.
`CE_ENDING`도 경찰서 → 저택 → 후일담 장소 → 사무소로 이동한다. `place` 하나만 가진
현재 스키마로는 부족하므로, 이미지 생성 전에 **비트 또는 숏 단위 배경 전환 필드**를
확정해야 한다.

## 4. 인물 초상 세트

`07_CUTSCENES.md`에서 실제로 사용된 `who + face` 조합은 **11명 26종**이다.
기획서의 11×3=33 또는 축소 29는 상한선일 뿐 실제 최소 수량이 아니다.

| 인물 | calm | tense | high | 합계 | 기존 자산 후보 / 조치 |
| --- | :--: | :--: | :--: | :--: | --- |
| 플레이어 | ○ | ○ | — | 2 | 플레이어 콘셉트를 기준으로 신규 크롭·리터치 |
| 리드 | ○ | ○ | ○ | 3 | `01-police-portraits` 직접 활용 가능 |
| 엘리너 | ○ | ○ | ○ | 3 | `19-resident-widow`를 정체성 기준으로 재작업 |
| 홀트 | — | ○ | — | 1 | `04-teacher-portraits` 후보 |
| 카버 | ○ | ○ | ○ | 3 | `18-resident-carpenter` 또는 `13-dockworker` 기반 |
| 줄리언 | ○ | ○ | ○ | 3 | `02-doctor`/`16-resident-scholar` 기반, 단정한 상류층 |
| 뱅크스 | ○ | ○ | ○ | 3 | `10-drunkard`/`07-gravekeeper` 기반, 늙은 선원으로 수정 |
| 코라 | ○ | ○ | ○ | 3 | `05-merchant` 기반 |
| 베스 | — | ○ | — | 1 | `14-laundress` 또는 `03-nurse` 기반 |
| 램 | ○ | ○ | ○ | 3 | `10-drunkard`/`18-carpenter`와 겹치지 않게 신규 변형 |
| 부두 인부 | ○ | — | — | 1 | `13-dockworker` 직접 활용 가능 |
| **합계** |  |  |  | **26** |  |

마르타는 등장인물 표에는 있지만 현재 컷신 대본에서 말하지 않는다. 튜토리얼의 증언
카드에는 필요할 수 있어도 **컷신 초상 수량에서는 제외**한다. 반대로 `C3B`의 부두 인부는
등장인물 표에 없지만 한 줄을 말하므로 1표정이 필요하다.

### 초상 생성 절차

1. 인물마다 `calm`을 정체성 원본으로 먼저 확정한다.
2. `tense`와 `high`는 독립 생성하지 않고 `calm`을 참조한 표정 편집으로 만든다.
3. 얼굴형, 눈·코 위치, 머리 모양, 의상 색은 표정 사이에서 1픽셀 이상 흔들리지 않게 한다.
4. 64×64 축소 후 눈·입·눈썹을 수동 정리한다.
5. 초상 바깥 4px 안전 여백과 투명 모서리를 확인한다.
6. 말하지 않는 인물의 감광은 별도 이미지를 만들지 않고 런타임 필터로 처리한다.

### 표정 해석

- `calm`: 무표정이 아니라 “말을 이어 갈 수 있는 평상 상태”
- `tense`: 분노 한 종류가 아니라 긴장·불쾌·슬픔·의심을 포함. 인물별 눈썹과 입만 조정
- `high`: 놀람·고조. 모두 입을 크게 벌린 같은 표정으로 만들지 않는다
- 엘리너 `high`: 놀람보다 감정이 무너지는 순간
- 줄리언 `high`: 통제력을 잃은 방어
- 뱅크스 `high`: 기억을 말하기로 결심한 상태
- 카버 `high`: 공격성보다 두려움과 억울함이 함께 보여야 한다

### 한 컷신에서 필요한 숏 수

대사 한 비트마다 새 이미지를 만들지 않는다. 기본은 컷신당 2~4숏이다.

- **설정 숏**: 장소 전체 + 인물 초상
- **증거 숏**: 소품 또는 복원 결과 확대
- **반응 숏**: 표정 전환, 배경은 그대로
- **전환 숏**: 문 열림·장소 이동·기억 장면처럼 대본에 명시된 경우만

`C3A`는 예외적으로 5숏(초상 비교 → 줄리언 입장 → 칠판 4줄 → 엘리너 반응 → 문신),
`CE_ENDING`은 8~12숏을 허용한다. 나머지는 4숏을 넘기지 않는다.

## 8. 생성 프롬프트 설계 원칙

배경, 초상, 소품은 서로 다른 프롬프트 템플릿을 쓴다. 특정 게임·작가의 화풍을 직접
요청하지 않고 현재 프로젝트의 팔레트와 픽셀 규격으로 설명한다.

### 배경 템플릿

```text
용도: 640×384 픽셀 어드벤처 컷신 배경
장소: <장소와 시대적 기능>
구도: 3/4 탑다운, 중앙 사건 삽입 영역을 비우고 하단 대화창 안전 영역 확보
시대: 사진기가 보급되기 전 19세기 후반풍 가상 항구 도시
팔레트: 저채도 청록, 갈색, 테라코타, 크림
광원: 왼쪽 위, 4단계 명암, 오른쪽 아래 그림자
스타일: 명확한 픽셀 군집, 단단한 재질, 읽기 쉬운 실루엣
제약: 인물 없음, 글자 없음, 로고 없음, 워터마크 없음, 블러·부드러운 그라데이션 없음
```

### 초상 템플릿

```text
용도: 64×64 투명 배경 대화 초상
인물 정체성: <나이, 직업, 얼굴형, 머리, 의상, 대표색>
표정: <calm / tense / high의 인물별 해석>
구도: 어깨 위 3/4 시점, 얼굴 중앙, 4px 안전 여백
스타일: 기존 NPC 초상과 같은 굵은 픽셀 군집, 갈색 외곽선
불변 요소: calm 원본의 얼굴형·눈·코·머리·의상 유지
제약: 글자 없음, 배경 없음, 액세서리 추가 금지, 다른 인물과 혼합 금지
```

### 사건 소품 템플릿

```text
용도: 컷신 삽입용 픽셀 소품
대상: <종이/칠판/밀랍/마차/일지>
구도: 정면 또는 약한 3/4, 후처리 문자·문양을 올릴 빈 면 확보
재질: 4단계 명암, 1px 갈색 외곽선
제약: 글자와 상징을 생성하지 말 것, 화면을 가득 채우지 말 것, 워터마크 없음
```

모든 생성 기록에는 최종 프롬프트, 입력 참조, 생성 도구, 생성일, 후처리 내역을 남긴다.

### 1단계 — 논리 자산을 먼저 잠근다

- 방계 4줄 정본 도형

- C0, C0B, C1

오프닝이 튜토리얼로 정확히 이어지는지 먼저 검증한다.

## 11. 구현 데이터에 필요한 이미지 필드

현재 `place` 하나만으로는 `C4A`와 `CE_ENDING`을 표현할 수 없다. 컷신 데이터에 아래
시각 필드를 두는 것을 권장한다.

```js
{
  id: "C3A_THE_SEAL_HE_DREW",
  place: "police-station",
  beats: [
    {
      who: "carver",
      face: "calm",
      text: "우리 가문의 인장입니다.",
      visual: {
        background: "police-station",
        insert: "chalkboard-empty",
        overlay: "crest-branch-four-waves",
        camera: "insert-close"
      }
    }
  ]
}
```

권장 키:

- `background`: 장소 전환
- `state`: 같은 배경의 비/안개/문 열림 상태
- `insert`: 사건 소품 또는 실제 복원 결과
- `overlay`: 정확한 문양·텍스트·빛
- `camera`: `wide` / `speaker` / `insert-close` / `compare`
- `transition`: `cut` / `fade` / `flash`

대본의 장면은 숏 단위로 툭툭 끊기는 구조이므로, 이미지 자체를 많이 만드는 대신 이 필드로
같은 베이스를 재조합하는 편이 언더테일식 리듬과 제작 범위에 모두 맞는다.

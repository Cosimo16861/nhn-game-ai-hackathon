# 컷신 대본 — 퀘스트 가지 판

> 구조는 `docs/QUEST_BRANCH.md`, 이야기는 `docs/STORY_OUTLINE.md`.
> **00~06번 대본은 폐기됐다.** 대화 선택지 시스템이 사라졌기 때문이다.
> 다만 그 대사들은 이 대본의 원본으로 재활용했으므로 삭제하지 않는다.

## 읽는 법

- 컷신에는 **선택지가 없다.** 전부 자동 진행된다
- `who` 표정: `calm` 평상 / `tense` 긴장·불쾌 / `high` 놀람·고조
- `▸` 는 연출 지시. `【 】` 는 자동 수집되는 증언·증거 카드
- `→` 는 해금되는 노드
- 대사 한 줄은 한글 24~28자 × 최대 3줄을 넘기지 않는다
- **컷신 번호는 「자기가 여는 레이어」를 뜻한다.** `C3A`는 L2 노드가 끝난 뒤 재생돼
  L3을 연다. 그래서 `C6_EVIDENCE_WALL`은 L5 노드(`Q5A`)의 컷신이고 L6을 연다

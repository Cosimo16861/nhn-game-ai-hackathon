# 12. 지붕 타일

32×32 픽셀 기준의 탑다운 지붕 조립 세트입니다. 회색 슬레이트 10종과 붉은 점토기와 10종으로 구성됩니다.

- `roof-tileset-5x4-32px.png`: 게임용 5×4 아틀라스
- `tiles-32px/`: 개별 PNG 20개
- `slate-roof-sample.png`, `clay-roof-sample.png`: 조립 예시
- `roof-preview-6x.png`: 투명 영역 확인용 확대 미리보기
- `manifest.json`: 순서, 레이어, 충돌 설정
- `source/`: 생성 원본과 투명 처리 원본

지붕은 건물 벽·바닥보다 위, 플레이어보다 앞에 그리는 `roof-overlay` 레이어에 둡니다. 건물 안에 들어가거나 지붕 뒤에 가려질 때는 지붕을 숨기거나 불투명도 약 35%로 낮추세요. 이동 충돌은 지붕 그림이 아니라 별도의 건물 바닥 경계로 설정합니다.

## 2. 항목별 상세 기준

### 1) 플레이 가능한 빌드 및 소스 코드 (GitHub)

심사자가 **직접 플레이할 수 있는 형태**로 제출. 아래 중 **한 가지 이상** 제공:

- **웹 빌드**: GitHub Pages 등으로 배포 → 링크 클릭만으로 브라우저에서 바로 플레이
- **모바일 앱**: APK 파일 또는 테스트 배포 링크 (예: TestFlight, Google Play 내부 테스트 등)

**제약 조건**
- [ ] 별도 유료 라이선스 없이 심사자가 실행 가능해야 함
- [ ] 보안상 **PC 실행 파일(.exe 등) 직접 제출 불가**
- [ ] 게임 **전체 소스 코드**를 동일 저장소에 포함하고 **커밋 기록 유지**
- [ ] 저장소는 **공개(public) 제출 권장** — 부득이 비공개 시 심사 계정 초대
  - 심사 계정: **dl_gameai_reviewer@nhn.com**

> ✅ 우리 팀 현황: public 저장소 `Cosimo16861/nhn-game-ai-hackathon` 생성 완료.
> 웹 게임(`index.html`)이므로 GitHub Pages 배포로 요건 충족 예정.

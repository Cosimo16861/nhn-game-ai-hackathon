# 03 나무 바닥 타일

- 기준 크기: `32×32px`
- 배열: `5열 × 4행`, 총 20종
- 배경: 바닥을 완전히 채우는 불투명 PNG
- 구성: 가로 마루 5종, 세로 마루 5종, 헤링본·쪽매·넓은 판자·좁은 판자·어두운 관공서용 바닥, 긁힘·물얼룩·균열·수리·심한 마모 상태

게임에는 `wood-floor-tileset-5x4-32px.png`를 32×32 타일로 불러오면 됩니다. `wood-floor-room-sample-2x.png`에서 반복 배치 예시를 확인할 수 있습니다.

나무 바닥은 최하단 바닥 레이어이므로 투명하지 않습니다. 벽, 가구, 플레이어와 전경 가구는 이 위에 순서대로 배치합니다.

## 1. 로그라인 & 컨셉 정당화

**로그라인**
사진기가 없던 시대. 배와 함께 사라졌던 명문가의 상속자가 10여 년 만에 살아 돌아왔다고 주장하는 남자가 나타난다. 유산과 가문의 명운이 "그가 진짜인가"에 걸렸지만, 경찰은 사람의 신원을 판별할 수단이 없다. 그래서 그들은 증언만으로 얼굴과 현장을 그려 진실을 복원하는 사설 탐정 — 플레이어를 부른다.

**"왜 그림으로 복원하는가"에 대한 답 (핵심 메커닉의 서사적 정당화)**
- 이 시대에는 사진·머그샷이 없다. 용의자와 현장을 기록할 유일한 수단은 **목격자의 기억 + 그것을 그리는 손**이다.
- 플레이어는 그 일을 전문으로 하는 **복원 전문가형 탐정**이다. 직접 범인을 "찍어 맞히는" 사람이 아니라, **완성한 그림으로 진실을 드러내 경찰의 체포를 가능케 하는 조력자**다.
- → 무제.txt의 미해결 질문 "플레이어는 대체 누구인가?"에 대한 확정 답.

## 2. 핵심 게임 루프

```
장소 이동 → 증인과 실시간 대화(LLM 탐문으로 증언 수집) → 사무소에서 그림 복원(핵심 퍼즐) →
채점·복원물이 용의자를 좁힘 → 다음 단서 해금 → (반복 ×3) →
최종 국면: 완성한 증거 제시 → 경찰이 배후를 체포 (B 엔딩)
```

- **핵심 스킬은 "그리기(복원)"** 하나로 일관한다.
- **증언 수집은 대화형 증인(LLM)과의 실시간 탐문**으로 이뤄진다. 플레이어가 자유롭게 질문하고, 그 답을 토대로 그림을 복원한다. (→ §7 대화형 증인 시스템)
- 복원물이 곧 증거이며, 퀘스트를 클리어할수록 용의자가 좁혀진다.
- 플레이어는 블라인드 추리를 하지 않는다. **복원 = 지목**이다.

## 3. 세계관 & 등장인물 (전부 가상)

**배경**: 안개 낀 항구 도시 **헤이번(Haven)**. 대략 19세기 후반 분위기(사진 이전, 마차·가스등·부둣가). 실존 인물·지명은 사용하지 않는다.

| 인물 | 역할 | 서사 기능 |
|------|------|-----------|
| **플레이어 (탐정)** | 헤이번의 자문 탐정, 복원 전문가 | 조작·복원 주체 |
| **리드 경위 (Inspector Reed)** | 사건을 의뢰하는 경찰 | 창구·조수·최종 체포 |
| **엘리너 아셔튼 부인** | 사라진 상속자의 노모 | 아들 생환을 믿음, 얼굴 증언 |
| **에드먼드 아셔튼** | 10여 년 전 세이렌 호 침몰로 실종된 진짜 상속자 | 복원 대상(얼굴·표식) |
| **"토마스 카버"** | 자신이 에드먼드라 주장하는 남자 | 사칭범(부둣가 정육 출신 정황) |
| **줄리언 아셔튼** | 상속 서열 2순위 조카 | **B 엔딩의 배후** |
| **미스 홀트** | 에드먼드의 옛 가정교사 | 얼굴·습관 최우선 증인 |
| **선원 뱅크스** | 세이렌 호 생존 선원 | 그날 밤 항구 현장 증인 |

## 4. 스토리 구조 (3막 + B 엔딩: 이중 반전)

### 1막 — 의뢰와 얼굴
리드 경위가 사건을 가져온다. 카버가 저택에 들어와 상속을 요구 중이다. 노부인은 "내 아들"이라 하고, 조카 줄리언은 "사기꾼"이라 한다. 플레이어는 진위를 가릴 것을 의뢰받는다.
→ **퀘스트 1(몽타주/얼굴)**.

### 2막 — 표식과 필적
얼굴만으로는 부족하다. 진짜 에드먼드에게는 결정적 표식(왼쪽 손목 닻 문신), 유창한 외국어, 특유의 봉인 인장이 있었다.
→ **퀘스트 2(사물/증거)**. 위조 정황과 함께 "누군가 카버에게 정보를 흘렸다"는 냄새를 맡는다.

### 3막 — 그날 밤의 항구
진실의 마지막 조각은 세이렌 호가 떠나던 그날 밤의 부두에 있다.
→ **퀘스트 3(현장)**. 복원된 현장에 **배후만 남길 수 있는 단서**가 드러난다.

### 결말 — B 엔딩 (이중 반전)
카버는 사칭범이 맞다. 그러나 그를 세운 **배후는 유산을 노린 조카 줄리언**이었다. 세 복원물이 하나로 수렴해 배후를 가리키고, 리드 경위가 체포한다.

## 5. 퀘스트별 상세 설계 (핵심)

각 퀘스트 = **대화형 탐문(증언 수집) → 캔버스 복원(채점) → 복원물이 용의자를 좁힘**.
증인은 LLM으로 구동되어, 플레이어의 질문에 실시간으로 답한다(→ §7).

### 퀘스트 1 · 사라진 얼굴 (몽타주)
- **수집**: 미스 홀트, 노부인과 대화하며 상반된 얼굴 기억을 캐묻는다.
- **복원**: 손상된 초상 마스크 위에 에드먼드의 진짜 얼굴을 복원한다.
- **채점**: 색상·윤곽·구조·팔레트 + CLIP 의미 일치.
- **좁힘**: 복원된 얼굴이 카버와 어긋남 → *"카버 = 진짜 상속자" 탈락*. 새 질문: 그럼 누가 세웠나?

### 퀘스트 2 · 지워지지 않는 증거 (사물)
- **수집**: 유품 상자의 편지·인장, 문신을 본 증인의 진술.
- **복원**: 봉인 인장 문양 / 문신 도안 / 서명을 복원한다.
- **좁힘**: 카버의 것과 대조 → 위조 정황 + **내부자가 정보를 흘린 흔적** → 용의자가 저택 내부인으로 좁혀짐.

### 퀘스트 3 · 마지막 항해 (현장)
- **수집**: 선원 뱅크스의 그날 밤 진술.
- **복원**: 출항 당일 밤 부두 현장을 복원한다.
- **좁힘**: 복원된 현장 속에 **줄리언과 연결되는 시각 단서**(예: 특정 인장이 찍힌 마차·문양)가 드러남 → 배후가 시각적으로 특정됨.

### 최종 국면 · 증거 제시 (복원 = 지목)
- 블라인드 추리 없음. 플레이어는 **자기가 복원한 결과물 중 결정적 증거를 제시**한다.
- 기존 `deduction-manager.js`를 "범인 맞히기"가 아니라 **"증거 제시·확정"** 용도로 재사용.
- 실패해도 다시 제시할 수 있는 낮은 스트레스 절차. 확정 시 경위가 배후를 체포하며 사건 종료.

## 6. 월드 구조 (작고 경계가 확실한 자유 이동 맵)

안개항 헤이번의 한 구역. 핵심 장소 5곳으로 압축:

1. **탐정 사무소** — 시작점, 복원 캔버스 작업.
2. **경찰서** — 리드 경위, 사건 브리핑.
3. **아셔튼 대저택** — 노부인·카버·줄리언.
4. **부둣가 선술집** — 선원 뱅크스.
5. **옛 가정교사의 집** — 미스 홀트.

- 이동은 자유롭되 **상호작용 지점과 이동 범위를 명확히 표시**한다(하이라이트/표지판).
- 진행에 따라 장소가 단계적으로 해금된다(초반엔 사무소·경찰서·저택만 열림).

## 7. 대화형 증인 시스템 (컨셉)

증인 NPC를 **LLM API에 연결해 실시간 대화형 탐문**으로 만든다. 이 게임의 AI 정체성을 강화하는 핵심 요소다. *(구체 기술 설계 — 프록시 구성, system prompt 템플릿, 폴백 흐름, API 연결·모델·비용 — 은 별도 문서에서 다룬다.)*

**개념**
- 플레이어가 증인에게 자유롭게 질문("눈매는 어땠나요?", "그날 밤 누가 있었나요?")하면, 증인이 캐릭터를 연기하며 실시간으로 답한다.
- 그 답을 단서로 삼아 사무소에서 그림을 복원한다. → 탐문과 그리기가 하나의 흐름으로 이어진다.

**설계 원칙 (컨셉 수준)**
- **정답 기반 그라운딩**: 각 증인은 "정답 이미지의 사실 + 이 증인이 아는 범위 + 모르는 것"의 경계 안에서만 답한다. 모르는 건 사람처럼 "잘 기억나지 않는다"고 답한다 → 채점 가능성 유지, 모순 정보 방지.
- **점진적 공개 = 경제와 연동**: 기본 증언은 모호하고, **보수를 지불하면 증인이 더 구체적으로 진술**한다(§8 경제, 무제.txt "돈으로 설명 구매"와 일치).
- **가드레일**: "정확한 픽셀/좌표를 불러줘" 같은 우회 질문에는 증인이 사람처럼 애매하게 답하도록 제한한다.
- **항상 플레이 가능**: LLM이 없거나 응답 실패 시에도 **미리 준비된 증언(폴백)** 으로 게임이 끊기지 않는다. → 심사자가 키 없이도 플레이 가능해야 한다는 제출 요건 충족.

**제약 (설계 시 반영 필요, 상세는 후속 기술 문서)**
- 정적 호스팅(GitHub Pages)이라 백엔드가 없음 → **API 키를 브라우저/저장소에 노출하면 안 됨**(public 저장소 커밋 금지).
- 공개 링크이므로 **레이트 리밋/사용량 상한**으로 남용·비용을 통제.
- 지연·오류 시 **우아한 저하(graceful degradation)**.

## 8. 진행 · 경제 · 힌트

- **보수(의뢰비)**: 퀘스트 진행으로 획득.
- **힌트 구매**: 보수로 더 구체적인 증언/설명을 산다 — 기존 `hint-manager.js` 재사용. **대화형 증인의 "점진적 공개"와 직접 연동**(돈을 낼수록 증인이 더 구체적으로 진술). 후반부일수록 힌트가 비싸고, 대신 더 구체적이다(무제.txt 반영).
- **해금**: 단일 사건이므로 "다음 세계 해금"은 **선택적 장소(추가 증인) 해금**으로 가볍게 치환.
- **저장**: 진행·복원 결과를 `localStorage`에 저장(기존 구조 활용).

## 9. AI 활용 & 검증된 기술 재사용 매핑

### 3중 AI 구조 (제출물 4번의 핵심 소재)
1. **생성 AI** — 얼굴·현장·사물 에셋 이미지 생성 → 픽셀화(§11 에셋 방식).
2. **CLIP** — 복원물의 의미 일치 채점.
3. **LLM** — 대화형 증인 실시간 탐문(§7).

각 도구·프롬프트·구조를 기록해 "AI 활용 기술 문서"의 근거로 삼는다.

### 검증된 기술 재사용
현재 루트 스크립트는 게임의 핵심 기술 검증(PoC)이며, 실제 게임은 이 위에 서사·월드를 얹는다.

| 게임 요소 | 재사용 스크립트 |
|-----------|-----------------|
| 얼굴/현장/사물 복원 캔버스 | `pixel-editor.js`, `editor-manager.js` |
| 손상 마스크(뚫린 영역) | `mask-generator.js` |
| 유사도 채점(색상·윤곽·구조·팔레트) | `scoring.js`, `score-manager.js` |
| 의미 일치(CLIP) | `clip-analyzer.js`, `clip-*.js` |
| 사건 조각/이미지 슬라이스 | `chapter-image-slicer.js`, `pixelizer.js` |
| 최종 증거 제시(용도 변경) | `deduction-manager.js` |
| 힌트·난이도 | `hint-manager.js`, `difficulty-rules.js` |
| 진행·해금·별점 | `stage-progress-manager.js`, `assembly-manager.js` |

**신규 개발 필요**: 탑다운 월드 이동·장소·NPC 시스템, **대화형 증인(LLM) 연동 + 폴백**, 스토리/컷씬 진행, 증언→퍼즐 연결 흐름.

## 10. 2인 팀 개발 범위 (MVP 우선순위)

**반드시(제출 필수 최소):**
- [ ] 5장소 자유 이동 월드 + NPC 상호작용
- [ ] 3개 복원 퀘스트(얼굴·증거·현장) 각 1개씩 동작
- [ ] 대화형 증인 탐문 → 복원 캔버스 연결 흐름 (**+ 폴백 증언**으로 항상 플레이 가능)
- [ ] 최종 증거 제시 → B 엔딩 컷씬
- [ ] GitHub Pages 배포 + 저장(localStorage)

**있으면 좋음(시간 남으면):**
- [ ] LLM 증인 품질·그라운딩 고도화 + 힌트 경제 연동 밸런싱
- [ ] 인트로/컷씬 연출, Skip 버튼
- [ ] 사운드·연출 폴리시

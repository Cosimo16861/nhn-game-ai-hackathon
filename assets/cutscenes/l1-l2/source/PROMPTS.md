# L1 → L2 이미지 생성 프롬프트 기록

모든 생성은 내장 이미지 생성 도구를 사용한다. 생성 원본은 `source/`에 보존하고,
게임 검토 페이지는 도트 후처리한 `backgrounds/` 자산만 사용한다. 생성 이미지에는 읽을 수
있는 글자, 인물, 정답 단서를 넣지 않는다.

## 공통 기준

- use case: historical-scene
- 1890년대 안개항을 배경으로 한 고딕 미스터리 픽셀 어드벤처 컷신
- 640×384, 고의적인 저해상도 도트 군집, 제한된 갈색·청록·회청 팔레트
- L0→L1 경찰서 배경과 같은 픽셀 밀도·외곽선·재질 묘사
- 인물 없음, 글자 없음, 워터마크 없음
- 하단 106px는 대사창 영역이므로 핵심 단서 없음
- 중앙 상단에 인물 초상과 증거 삽입컷을 배치할 여백 확보

## asherton-parlor

부유하지만 애도에 멈춘 아셔튼 저택 응접실. 화면 왼쪽의 비 오는 큰 창, 중앙의 빈 이젤,
짙은 녹색 벨벳 소파, 닫힌 서랍장, 식은 차가 놓인 작은 탁자. 차가운 창빛과 따뜻한 벽난로
빛이 갈라지며, 12년 동안 방의 배치가 거의 바뀌지 않은 느낌.

## asherton-west-hall

오랫동안 닫힌 저택 서쪽 복도. 오른쪽 끝의 잠긴 아이 방 문, 비가 스며 부풀고 벗겨진 벽지,
바닥의 물받이 양동이와 작은 물웅덩이, 왼쪽 높은 창으로 들어오는 번개빛. 젖은 벽 중앙에는
무엇인지 판독할 수 없는 희미한 크레용 색 흔적만 있고 완성 그림이나 글자는 없음.

## school

방과 후 비어 있는 1890년대 작은 학교 교실. 칠판, 낡은 교사용 책상, 줄지은 빈 학생 책상,
창밖의 빗물, 먼지 낀 햇빛, 한 자리만 오래된 이름표 흔적과 긁힌 자국. 따뜻한 황갈색 목재와
회청색 창빛. 칠판과 종이에 읽을 수 있는 글자는 없음.

## tavern

부둣가 선술집의 저녁. 왼쪽의 오래된 낙서·회벽 층, 중앙의 카운터와 빈 의자, 오른쪽의
작은 벽난로, 붉은 리본이 걸린 빈 고양이 바구니. 생활감 있는 병과 머그, 젖은 외투가 있으나
손님과 주인은 없음. 따뜻한 호박색 불빛과 창가의 차가운 안개빛이 대비됨.

## 생성·선정 기록

- 내장 이미지 생성 도구로 네 장소의 원본을 생성했다.
- 응접실과 서쪽 복도의 첫 시안에는 의도하지 않은 대사 UI가 포함되어, UI와 글자를 모두
  제거하고 가려진 바닥·벽을 같은 픽셀 화풍으로 연장하는 편집 생성을 거쳤다.
- 학교와 선술집은 처음부터 순수 환경 플레이트로 생성했다.
- 선정 원본은 이 폴더의 `*-generated.png`, 후처리된 640×384 RGB 결과는
  `../backgrounds/*.png`에 저장했다.

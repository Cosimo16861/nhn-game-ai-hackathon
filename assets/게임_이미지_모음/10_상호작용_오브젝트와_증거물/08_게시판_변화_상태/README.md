# 게시판 변화 상태 세트

사람이 없는 투명 PNG 상호작용 오브젝트입니다. 32×32 타일 맵에서 바닥 중앙(`bottom-center`)을 기준으로 배치합니다.

## 구성

- 마을 광장 게시판: 빈 상태, 일반 공고, 사건 발생, 해결 후, 훼손
- 경찰서 수사 게시판: 빈 상태, 일반 업무, 수사 중, 해결 후, 증거 훼손
- 상점·시장 게시판: 빈 상태, 일반 광고, 분실물 사건, 해결 후, 풍우 손상
- 역·우편소 게시판: 빈 상태, 시간표, 운행 사건, 갱신 완료, 파손
- 새 공고 표시 3프레임, 중요 단서 핀, 해결 표시 인장

## 게임 적용

- 개별 게시판 20개는 `objects/`에 있습니다.
- 알림과 사건 강조 표시는 `overlays/`를 게시판 위에 겹칩니다.
- 종이 위 표시는 실제 문장이 아닌 추상적인 픽셀 선이므로, 읽는 내용은 대화창이나 확대 조사 UI에서 표시합니다.
- `manifest.json`의 `readable`, `has_new_case`, `case_resolved`, `usable` 값으로 상호작용을 제어합니다.
- 미리보기 GIF는 상태 비교용이며 게임에서는 사건 진행에 따라 개별 PNG를 교체합니다.

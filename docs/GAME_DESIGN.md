## 0. 개정 요약 — 무엇이 폐기됐는가

시간 제약으로 다음을 범위에서 **완전히 제외**한다.

| 폐기 | 대체 |
| --- | --- |
| 타일맵 월드, 4개 야외 구역, 캐릭터 이동, 미니맵 | **증거판 한 화면**(퀘스트 가지 맵) |
| NPC 자유 대화, 반복 질문, 스몰 토크 | 없음 |
| 고정 선택지 대화, 막마다 한 번의 핵심 판단 | **비인터랙티브 컷신**(선택지 0) |
| 대화 선택으로 증언·증거 수집 | 컷신 종료 시 **자동 수집** |
| 엔딩 A / 엔딩 B 분기 | **단일 엔딩** + 후일담 변주 |
| 주변 NPC 9~12명, 야외 순찰 NPC | 컷신 조연 5명 |

게임은 **그림 복원 플레이 하나에 집중한다.** 스토리는 퀘스트와 퀘스트 사이에
자동 재생되는 컷신으로 전개되고, 플레이어의 유일한 결정은
**다음에 어느 그림을 복원할 것인가**다.

## 1. 확정된 제작 원칙

- 전체 이야기는 `STORY_OUTLINE.md`, 진행 구조는 `QUEST_BRANCH.md`를 따른다.
- **엔딩은 하나다.** 완료한 가지에 따라 후일담 컷만 추가된다.
- LLM 연결과 자유 입력 대화는 사용하지 않는다. 모든 대사는 사전 작성한다.
- **컷신에는 선택지가 없다.** 메인 스토리 전개에 플레이어는 개입하지 않는다.
- 분기는 대화가 아니라 **퀘스트 가지**로만 존재한다.
- 복원 점수와 통과 기준의 정확한 숫자는 플레이어에게 공개하지 않는다.
- 내부 점수에 따라 증언형 힌트, 시각·음향 신호와 정성적 피드백을 제공한다.
- 전투, 시간제한과 일반적인 게임오버는 없다.
- 낮은 복원 결과가 진행을 영구적으로 막지 않는다. 통과할 때까지 재제출한다.
- 가지 퀘스트는 **결정적 증거를 주지 않는다.** 엔딩까지 이어지는 루트는 하나다.
  다만 본선 복원의 **보조 목격담**은 줄 수 있다(`QUEST_BRANCH.md` 2.2절).
- 복원 작업대와 진행 화면은 게임 세계 안의 물건처럼 보여야 한다(디에게틱).

## 2. 게임 개요

| 항목 | 내용 |
| --- | --- |
| 제목 | 《안개항의 상속자》 |
| 영문명 | The Heir of Haven |
| 핵심 콘셉트 | 사진 기술이 보편화되기 전, 증언을 그림으로 복원해 사건의 진실을 밝힌다. |
| 배경 | 안개 낀 항구 도시 헤이번, 19세기 후반풍 가상 세계 |

`Q5A_DOCK`(마차 문양 네 줄)은 **플레이어가 직접 칠한 두 그림의 대조가 범인을 지목**하는
구조로 짜여 있다. 자세한 것은 `STORY_OUTLINE.md` 2.1절.

## 3. 핵심 게임 흐름

```text
컷신 (자동 · 힌트와 증거 획득)
→ 증거판으로 복귀 · 새 원이 압정에 꽂힌다
→ 열린 원 중 하나를 고른다
→ 작업대에서 그림 복원
→ 숨은 유사도 판정과 정성적 피드백
→ 통과
→ 다음 컷신
```

`Q5A_DOCK`을 통과하면 종점 `Q6_FINALE`이 열린다. 가지만 플레이해서는 도달할 수 없다.

### 시간과 실패

- 누적 플레이 시간은 표시하되 성공·엔딩 조건에는 쓰지 않는다.
- 복원 제출 횟수에는 제한이 없다. 낮은 점수를 받으면 현재 그림을 유지한 채 수정한다.
- 놓칠 수 있는 증거는 없다. 증거는 컷신 종료 시 자동 수집된다.

## 4. 이야기

전문은 `STORY_OUTLINE.md`. 여기에는 개정으로 **바뀐 설정**만 적는다.

### 4.1 전제 (변경 없음)

12년 전 아셔튼 가문의 외아들 에드먼드가 세이렌 호와 함께 사라졌다. 시신은 없었고,
어머니 엘리너는 사망 신고를 거부했다. 어느 날 토마스 카버가 자신이 에드먼드라 주장하며
나타난다. 재산 관리인 줄리언은 공개적으로 그를 사기꾼이라 비난한다.
경찰은 신원 확인 수단이 없어 복원 전문가인 플레이어에게 사건을 맡긴다.

### 4.2 진실 — **개정됨**

줄리언은 12년간 재산을 빼돌렸고, 감사를 피하려 카버를 가짜 상속자로 만들었다.
여기까지는 이전과 같다. 아래가 새로 확정된 부분이며 **되돌리면 추리가 무너진다.**

- 아셔튼 **본가** 인장 = 초승달 아래 파도 **세 줄**. 엘리너가 12년째 보관 중이다
- 줄리언은 **방계**다. 그의 마차·문구류에는 방계 문장인 파도 **네 줄**이 새겨져 있다
- 줄리언은 본가 인장 실물을 본 적이 없다. 카버에게 자기 마차 문의 문양을 가르쳤다

이전 판의 「불완전한 모사를 보고 가르쳤다」는 설명은 폐기한다.
재산 관리인이 자기 가문 인장을 틀리게 아는 이유가 설명되지 않았기 때문이다.

### 4.3 진행 구조

`QUEST_BRANCH.md` 1장의 노드 표를 정본으로 한다. 요약하면:

```
Q0 골목의 손 → Q1A 미화된 초상 → Q2A 기억되지 않은 얼굴 → Q3A 봉인의 세 줄
   → Q4A 번진 장부 → Q5A 안개 낀 부두 → Q6 증거의 방
```

가지 8개: 선술집 체인 5개(`Q1B→Q2B→Q3C→Q4B→Q5B`)와 곁가지 3개
(`Q2C` 닫힌 방 · `Q3B` 문신 · `Q4C` 광장의 내기).

### 4.4 엔딩

**단일 엔딩 — 안개 너머의 진실.** 카버와 줄리언이 체포되고 엘리너가 아들의 부재를
받아들인다. 완료한 가지에 따라 후일담 컷이 삽입된다(`quest-graph.js`의 `EPILOGUE_CUTS`).

엔딩 후에는 증거판으로 돌아가 남은 가지를 플레이할 수 있고, `Q6`을 다시 들어가면
후일담이 갱신된다. 이전 판의 「놓친 분기부터 다시 수사」 로직은 폐기한다
(놓칠 수 있는 분기가 없다).

## 6. 컷신 시스템

대화 시스템을 대체한다. 상세 스펙은 `QUEST_BRANCH.md` 4장.

### 6.1 화면

- 배경: 장소 일러스트 1장(정지, 매우 느린 패럴랙스 허용)
- 플레이어 초상은 왼쪽 아래, 상대 초상은 오른쪽 위
- 초상 원본 64×64, 화면에서 약 96×96으로 확대
- 표정 3종: `calm` 평상 / `tense` 긴장·불쾌 / `high` 놀람·고조
- 대화창 약 448×112, 최대 3줄, 한 줄 한글 24~28자
- 말하지 않는 쪽 초상은 채도·명도를 낮춘다

### 6.2 진행

- **선택지 없음. 자동 진행.** 비트마다 표시 시간(`ms`)이 정해져 있다
- 클릭/스페이스: 타이핑 즉시 완료 → 한 번 더 누르면 다음 비트
- ESC: 전체 스킵. **그 컷신을 한 번 끝까지 본 뒤에만** 활성화한다
- 종료 → 증언·증거 카드가 쌓이는 짧은 연출 → 증거판 복귀

### 6.3 자동 수집

`grants`는 컷신 **종료 시점에 일괄 적용**한다. 중간 스킵해도 동일하게 들어간다.
플레이어가 증거를 놓치는 경우는 존재하지 않는다.

### 6.4 단서·증언 카드

- 카드에는 증언자, 요약, 전체 내용, 관련 인물과 관련 복원 퀘스트를 기록한다
- 복원 화면 왼쪽 패널에 **목격담 그대로** 표시한다. 설계 용어를 쓰지 않는다
  - ✗ `◆ 왼눈썹 비대칭`
  - ○ 「웃을 때요, 왼쪽 눈썹만 유독 위로 올라갔습니다.」 — 홀트
- 아직 얻지 않은 단서는 목록에 미리 노출하지 않는다

## 7. 화면 구성 — 월드를 대체하는 것

월드 탐색이 사라졌으므로 게임에는 **화면이 셋뿐**이다.

| 화면 | 역할 | 상태 |
| --- | --- | --- |
| **증거판** | 퀘스트 가지 맵. 허브. 원을 골라 퀘스트에 진입한다 | 구현 완료 |
| **컷신** | 스토리 전개 | 미착수 |
| **작업대** | 그림 복원 | 픽셀 표현 계층 구현 완료, 복원 엔진 연결 전 |

### 7.0 통일된 프레임 — 세 화면이 공유한다

**화면은 640×384 `PixelScreen` 한 장이다.** 세 화면 모두 이 프레임 안에서 그려진다.
배경용 저해상도 캔버스와 글씨용 3배 해상도 투명 캔버스가 겹쳐지지만, 별도 HTML
패널은 섞지 않는다. HTML 패널을 섞는 순간 화면이 "게임 + 웹사이트"로 쪼개진다.

기반은 `src/screen.js`(`PixelScreen`)이며 다음을 제공한다.

- **정수배 확대**(1·2·3배). 소수 배율은 픽셀을 들쭉날쭉하게 만든다
- **고해상도 한글 텍스트** — 배경의 픽셀 밀도는 유지하고 글씨만 3배 해상도 투명
  레이어에 그린다. 작은 한글을 1비트로 이진화할 때 생기던 획 뭉침을 막는다
- **`fade` / `glow`** — 음영은 한 색을 넓게 디더로 깔면 체커보드로 보인다.
  가까운 톤을 여러 겹 쌓아 계조를 만든다
- **`panel`** — HUD·대화창이 공유하는 모서리 깎은 패널(참고 목업의 UI 언어)
- **`PAL`** — 전 화면 공용 팔레트. 즉흥으로 색을 만들지 않는다
- **핫스팟** — 보이는 것은 캔버스, 누르는 것은 그 위의 투명한 DOM 버튼.
  키보드·스크린 리더가 그대로 동작하고 포커스는 캔버스에 도트로 다시 그린다

화면 분할(y 좌표)은 `src/office.js`가 정한다.

| 구간 | 내용 |
| --- | --- |
| 0 ─ 292 | 벽. 왼쪽에 창과 아날로그 시계, 나머지가 증거판 |
| 292 ─ 300 | 걸레받이 몰딩 |
| 300 ─ 384 | 책상 상판. 스탠드와 필기도구 |

광원은 왼쪽 위(9.1). **창의 찬 빛**이 벽 왼쪽을, **스탠드의 더운 빛**이 책상 왼쪽을
비추고 오른쪽으로 갈수록 어두워진다.

### 7.1 증거판

탐정 사무소 벽의 코르크 증거판이다. 별도 UI 화면이 아니라 게임 세계 안의 물건이다.

- 원 = 압정에 꽂힌 종이. 통과한 노드는 **실제 복원 결과의 축소본**이 걸린다
- 간선 = 실. **본선은 붉은 실**, 가지는 어두운 갈색 실. 중력을 받아 처진다
- 레이어는 왼쪽에서 오른쪽으로, 고정 피치 7열
- **레이어는 순차 공개된다.** 잠긴 노드는 아예 그리지 않는다(`QUEST_BRANCH.md` 2장)
- 배경은 사무소 벽. **창밖 안개가 본선 진행도에 따라 걷힌다**

이 화면은 엔딩 이미지와 같은 물건이다. 게임 전체가 「증거판을 채워 붉은 실을 잇는 일」이
되고, `Q6_FINALE`에서 마지막 실이 이어지는 순간이 곧 엔딩 컷이다.

### 7.2 표시하지 않는 것

- 어느 원이 본선인지 (실 색은 통과 후에만 칠해지므로 선택 시점의 단서가 되지 않는다)
- 점수, 진행률, 남은 원 개수
- 잠긴 노드의 존재 자체

## 8. 복원 시스템

**변경 없음.** 이 게임의 유일한 플레이이며, 개정으로 오히려 비중이 커졌다.

### 8.1 화면 구성

- 작업대를 바라보는 1인칭 화면
- 중앙에 캔버스. 크기는 노드별로 다르다(8.6 참조)
- 왼쪽에 증언 카드, 오른쪽에 제한형 팔레트와 도구
- 위쪽에 복원 목표(목격담 인용)와 제출 버튼
- 아래쪽에 실행 취소·다시 실행·확대·축소·격자·초기화

### 8.2 도구

- 연필, 지우개, 채우기, 직선, 사각형, 색상 추출, 선택 영역 이동
- 1·2·3픽셀 도구 크기 / 마우스 휠 확대·축소 / 스페이스 드래그로 화면 이동
- 최소 50단계 실행 취소·다시 실행
- 작업 화면을 나가도 캔버스와 실행 기록을 임시 저장
- 초기화 전 확인창(`UI.confirm()`, 네이티브 `confirm` 금지)

구현상 확정된 동작:

- 채우기 도구는 영역 데이터가 없어도 런타임 flood fill로 동작한다
- 색을 골라도 도구가 바뀌지 않는다(지우개·스포이드였을 때만 채우기로 복귀)
- 격자는 칸이 6px 미만이면 자동으로 숨는다. 격자선은 CSS 오버레이로 그린다
- 256²에서는 기본 도구가 채우기, 그 이하에서는 연필

### 8.3 복원 방식

노드에 맞춰 조합한다.

1. 희미한 윤곽 수정형 — 얼굴 복원 (`Q1A`, `Q2A`)
2. 부분 채색형 — 문신·전단·크레용 그림 (`Q0`, `Q2B`, `Q2C`, `Q3B`)
3. 조각 조립형 — 훼손 문서·봉인 (`Q3A`, `Q4A`, `Q4B`)
4. 빈 캔버스 배치형 — 현장의 인물·사물 위치 관계 (`Q3C`, `Q5A`, `Q5B`)

### 8.4 숨은 점수와 피드백

내부에서 색상·윤곽·구조·팔레트 유사도와 필수 특징 반영 여부를 계산한다.
**CLIP은 사용하지 않는다**(외부 네트워크 의존 0).

정확한 점수, 가중치, 통과선과 정답 오버레이는 **끝까지 공개하지 않는다.**

| 내부 상태 | 플레이어에게 보이는 표현 |
| --- | --- |
| 차이가 큼 | 「증언 카드를 다시 살펴보자.」 + 핵심 부위 관련 증언 힌트 |
| 방향은 맞지만 부족 | 「전체 인상은 가까워지고 있다.」 + 색·형태·배치 중 부족한 범주만 |
| 통과선에 근접 | 연필 소리, 캔버스 가장자리의 짧은 빛, 「거의 완성됐다」 |
| 통과 | 숫자 없이 「증거로 사용할 수 있을 만큼 복원됐다」 |

피드백은 정답 좌표나 색상값을 알려주지 않는다. 반복 실패 시 힌트 강도를 단계적으로
높이며, **증언자의 말을 인용하는 형태**로 제공한다.

### 8.5 제출

- 제출 전 확인창. 제출 횟수 무제한
- 제출 후 짧은 종이 넘김 연출 → 정성적 결과
- 통과하지 못해도 그림을 보존한 채 작업 화면으로 복귀
- 통과한 복원물은 증거판의 해당 압정에 걸린다

### 8.6 노드별 캔버스 크기 — **신규 확정**

모든 복원이 256²일 필요는 없다. 시간 예산을 맞추는 주된 수단이다.

| 크기 | 노드 | 1회 소요 |
| ---: | --- | ---: |
| 16² | `Q2B` 고양이 | 3분 |
| 64² | `Q0` 튜토리얼 | 3분 |
| 96² | `Q1B`, `Q4C` | 3분 |
| 128² | `Q2C`, `Q3A`, `Q3B`, `Q3C`, `Q4A`, `Q4B`, `Q5B` | 3~5분 |
| 256² | `Q1A`, `Q2A`, `Q5A` | 5~6분 |

- 256² 노드만 **인물 전체 채색**이다. 그 이하는 핵심 영역만 칠하도록 선화 밀도를 높인다
- 팔레트는 노드당 5~8색으로 제한한다

### 8.7 복원 타깃 아트 — 미결

`assets/`의 회화풍 초상은 채우기식 복원에 쓸 수 없다는 것이 실측으로 확인됐다
(상위 10색이 전부 미세하게 다른 갈색, 최대 영역 16,381px). 밀랍 봉인처럼 평면적인
자산만 정상 분해된다.

**절차 생성으로 평면 초상을 그리는 방향**이 유력하다. `source`가
`(ctx, size, {loadImage}) => void` 계약만 지키면 `artwork.js`·`restoration.js`는
손대지 않아도 된다. 최종 결정은 사용자 확인이 필요하다.

## 10. HUD와 메뉴

월드 HUD·미니맵·인벤토리·지도 탭은 **전부 폐기**한다. 남는 것은 다음뿐이다.

### 아날로그 시계

상단 HUD와 디지털 시간은 쓰지 않는다. 경과 시간은 사무소 왼쪽 창 아래, 책상 위쪽
벽에 걸린 아날로그 시계로만 표현한다. `Office.drawRoom(ctx, { clock })`이
`HH:MM:SS` 값을 시침·분침·초침으로 변환한다.

### 증거판 화면

- 원의 이름은 카드 하단의 무늬 없는 라벨 띠 안에 중앙 정렬한다
- 설정은 아직 미구현

### 작업대 화면

- 화면 전체는 내려다본 목재 작업대이며 떠 있는 HTML 패널을 쓰지 않는다
- 중앙: 가장 밝고 큰 캔버스. 외부 그림은 실제 작업면 안에 contain+clip한다
- 왼쪽: 목격자별 메모지 두 장을 책상 위에 어긋나게 직접 붙여, 목격담을 동시에 읽는다
- 오른쪽 위: 손에 드는 나무 팔레트와 5~8개 물감 덩어리
- 오른쪽 아래: 연필(1px), 가는 붓(2px), 넓은 붓(3px), 채우기 병, 지우개
- 화면 위 반투명 광량 레이어가 중앙 캔버스를 넓은 타원형 황색광으로 은은하게 강조한다
- 실행 취소·다시 실행·새 종이는 이젤 받침의 금속 부품, 제출은 별도 봉투와 밀랍 인장
- 왼쪽 아래의 작은 코르크 표찰을 누르면 메인 증거판으로 돌아간다
- 모든 행동물은 투명 DOM 핫스팟과 aria-label을 가지며 포커스·선택은 캔버스에 재현한다
- 표현 계층은 `src/workbench.js`, 확인 화면은 `workbench.html`. 실제 그리기·채점 연결은 후속

### 메뉴

목표·단서·설정의 **3개 탭**으로 줄인다.

- 목표: 지금 열려 있는 원 목록
- 단서: 지금까지 자동 수집된 증언·증거 카드와 복원물
- 설정: 음량, 화면, 대화 속도, 접근성

메뉴를 열면 플레이 시간이 멈춘다.

## 15. 완료 조건

1. 인트로 컷신이 재생되고 튜토리얼 복원이 가능하다.
2. 증거판에서 열린 원을 골라 진입하고, 통과하면 컷신이 자동 재생된다.
3. 컷신이 끝나면 자식 원이 열리고 증언·증거가 자동 수집된다.
4. 본선 6개를 통과하면 종점이 열린다. 가지만으로는 열리지 않는다.
5. 세 그림을 복원하고 숫자가 아닌 피드백으로 수정 방향을 알 수 있다.
6. `Q3A`와 `Q5A`의 복원 결과 대조로 배후가 지목된다.
7. 단일 엔딩이 재생되고, 완료한 가지에 따라 후일담이 달라진다.
8. 엔딩 후 증거판으로 돌아가 남은 가지를 플레이할 수 있다.

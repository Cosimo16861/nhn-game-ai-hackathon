# 《안개항의 상속자》 통합 자산 명세

> 상태: **1단계 확정본 — 생성·구현 전 명세**
> 작성 기준일: 2026-08-09
> 범위: 프롤로그, 컷신, 복원 퀘스트, 증언 포스트잇, 증거판 카드, 엔딩의 이미지 자산
> 이 단계에서는 이미지를 생성하거나 코드에 연결하지 않는다.

## 0. 문서 역할과 정본 우선순위

이 문서는 다음 제작 단계에서 사용할 **파일 단위 자산 계약**이다. 장면을 새로 쓰는 문서가
아니며, 이야기와 대사는 아래 정본을 그대로 따른다.

1. `docs/QUEST_BRANCH.md` — 노드, 해금, 순서
2. `docs/STORY_OUTLINE.md` — 사건의 진실, 퀘스트 결과
3. `docs/script/07_CUTSCENES.md` — 컷신 대사와 조건부 비트
4. `docs/CUTSCENE_DIRECTION_GUIDE.md` — 컷신 화면 문법
5. 이 문서 — 자산 ID, 파일, 최초 공개 시점, 금지 정보

기존 `docs/CUTSCENE_IMAGE_PLAN.md`의 컷신 분해 원칙은 유지한다. 이 문서는 그 범위를
프롤로그 재제작, 복원 퀘스트, 증언 포스트잇, 증거판, 엔딩까지 확장한다.

### 이번 단계에 포함되지 않는 일

- 이미지 생성 및 후보 선정
- 컷신 재생기 구현
- 복원 퀘스트 코드 등록
- 유사도 계산 코드 구현과 fixture 보정
- 증거판 버튼 구현

복원 목표·증언 메모·캔버스 크기·채점 수치와 하드 게이트의 정본은
`docs/RESTORATION_QUEST_SPEC.md`다. 실제 마스크와 fixture 제작은 후속 구현 단계에서 한다.

## 1. 이야기 안전장치

### 1.1 절대 바뀌면 안 되는 추리 정보

| 정보 | 최초로 명확히 보이는 시점 | 금지 시점 |
| --- | --- | --- |
| 카버가 그린 문양 = 초승달 + 파도 **네 줄** | `C3A_THE_SEAL_HE_DREW` | C3A 이전 모든 자산 |
| 본가 진품 봉인 = 초승달 + 파도 **세 줄** | `Q3A_SEAL` 결과 / `C4A_WET_LEDGER` | Q3A 이전 모든 자산 |
| 검은 마차 문양 = 초승달 + 파도 **네 줄** | `Q5A_DOCK` 결과 / `C6_EVIDENCE_WALL` | C5A의 기억 마차와 모든 가지 |
| 마차 주인 = 줄리언 아셔튼 | `Q6_FINALE` 뒤 `CE_ENDING` 1단계 | C6 및 그 이전 모든 자산 |
| `T.C.` 지급 = 카버에게 간 넉 달 치 비용 | `Q4A_LEDGER` 결과 / `C5A` | Q4A 이전 장부·종이 자산 |

3줄·4줄 문양은 생성 이미지에 맡기지 않는다. 아래 정본 레이어를 한 번만 만들고,
칠판·봉인·마차·비교 컷이 같은 도형을 확대·회전·재색상해 사용한다.

- `SYM_CREST_MAIN_3` — 본가, 파도 3줄
- `SYM_CREST_BRANCH_4` — 방계, 파도 4줄
- `SYM_ANCHOR_OLD` — 에드먼드의 오래된 닻 도안

### 1.2 정확한 문자는 별도 레이어다

생성 이미지에는 읽을 수 있는 글자를 넣지 않는다. 종이·잉크·도장 질감만 생성하고 다음
문자는 코드 또는 수동 픽셀 레이어로 합성한다.

- `검거`
- `아셔튼 가의 상속자, 12년 만에 귀환?`
- `지우지 말 것 — R`
- `T.C.` 지급 줄
- `자정 / 검은 마차 / 가스등 두 번째 기둥 옆 / 토마스가 탔다`
- `우리`
- `줄리언 아셔튼`
- 사망 신고서의 제목·서명란

### 1.3 가지 자산의 스포일러 금지

`Q1B → Q2B → Q3C → Q4B → Q5B`는 본선을 하나도 하지 않고 도달할 수 있다.
따라서 가지 자산에는 다음을 넣지 않는다.

- 파도 줄 수
- 줄리언의 이름·이니셜·얼굴을 배후로 읽게 하는 배치
- 아셔튼 문장
- 마차 주인의 단서
- `T.C.`와 줄리언을 연결하는 단서

`Q4B_LOGBOOK`이 알려 주는 것은 **마차가 선 위치**까지다.

## 2. 디자인 기준

### 2.1 기준 화면

튜토리얼 컷신 `C0B_THE_JOB`을 이후 모든 컷신과 프롤로그의 디자인 기준으로 삼는다.

- 기준 배경: `assets/cutscenes/c0b/backgrounds/office-night.png`
- 기준 인물: `assets/cutscenes/c0b/portraits/*.png`
- 기준 구현: `src/cutscene-c0b.js`
- 기준 평가: `docs/C0B_EVALUATION_LOG.md` 최종 9/10 판

현재 `C0_INTRO`의 코드 도형 중심 화면은 내용만 유지하고, C0B와 같은 **이미지 배경 + 인물
레이어 + 사건 삽입 컷 + 고정 대사창** 문법으로 재제작한다.

### 2.2 공통 아트 규칙

- 19세기 후반풍 가상 항구 도시
- 저채도 갈색·청록·테라코타·크림·먹청색
- 순수 검정 대신 `#2E241E` 계열 외곽선
- 왼쪽 위 광원, 오른쪽 아래 그림자
- 하이라이트 / 기본 / 그림자 / 깊은 그림자의 4단계 명암
- 굵고 의도적인 픽셀 군집, 읽기 쉬운 실루엣
- 블러, 에어브러시, 반투명 회화 브러시, 부드러운 안티앨리어싱 금지
- 현대 물건, 로고, 워터마크, 생성 모델의 임의 문자 금지
- 배경에는 대화 인물을 굽지 않는다. 인물은 초상 레이어로 분리한다

### 2.3 규격

| 유형 | 최종 규격 | 비고 |
| --- | --- | --- |
| 컷신 배경 | 640×384 PNG, 불투명 | 하단 112px 대사창 안전 영역 |
| 배경 상태 | 640×384 RGBA PNG | 비·안개·문·조명 변화 |
| 인물 초상 | 64×64 또는 C0B와 동일 비율 RGBA PNG | 표정 간 정체성 고정 |
| 큰 삽입 컷 | 최대 384×216 PNG | 대화창 위 중앙 안전 영역 |
| 사건 소품 | 32~192px RGBA PNG | 정확한 문자·문양 제외 |
| 복원 목표 | 노드 `gridSize`와 같은 정사각 PNG | 팔레트 양자화 완료본 |
| 복원 선화 | 목표와 같은 정사각 PNG | 닫힌 영역, 1px 정본 외곽선 |
| 채점 마스크 | 목표와 같은 정사각 무손실 PNG 또는 데이터 | 영역 ID가 겹치지 않음 |
| 증거판 썸네일 | 54×26 PNG 또는 런타임 축소 | 실제 복원 결과 우선 |

## 3. 폴더와 파일 이름

```text
assets/
  cutscenes/
    prologue/
      source/
      backgrounds/
      inserts/
      prologue-assets.json
    backgrounds/<place>/
    portraits/<character>/
    inserts/<group>/
    symbols/
      crest-main-3.png
      crest-branch-4.png
      anchor-old.png
    cutscene-assets.json
  quests/
    <quest-id-lowercase>/
      source/
      target.png
      line.png
      masks/<region-id>.png
      board-fallback.png
      manifest.json
  ending/
    inserts/
    states/
    ending-assets.json
```

생성 원본은 `source/`에 보존한다. 게임은 `source/`를 직접 참조하지 않는다.

## 5. 프롤로그 재제작 명세

프롤로그의 대사와 순서는 `C0_INTRO`를 그대로 사용한다. 이미지 문법만 C0B에 맞춘다.

| ID | 베이스 플레이트 | 사용 숏 | 필수 내용 | 금지 |
| --- | --- | --- | --- | --- |
| `P01_OFFICE_WINDOW` | 비 오는 사무소 창 | 1, 7 | 항구 실루엣, 비, 안개, 가스등 | 경찰·사건 단서 |
| `P02_DESK_RENT` | 책상 정물 | 2 | 임대료 고지서, 깎인 연필, 부스러기 | 읽히는 고지서 글자 |
| `P03_LOST_PORTRAITS` | 벽 초상 3장 | 3, 4 | 잃어버린 개, 이사 간 딸, 죽은 남편 | 본 사건 인물과 닮은 얼굴 |
| `P04_PLAYER_AT_WORK` | 플레이어 작업 자세 | 5, 6 | C0B와 같은 플레이어, 긴장 표정 변주 | 다른 의상·연령·얼굴 |

7개 숏은 `창 → 책상 → 초상 → 초상 점등 → 작업 → 위험 강조 → 창/타이틀` 순서다.
새 완성 일러스트 7장을 만들지 않고 4개 플레이트에 크롭·조명·삽입 컷을 달리한다.

프롤로그 마지막의 문 두드림은 C0B 첫 숏의 열린 문으로 연속되어야 한다.

### 7.1 채점 마스크 산출물

영역 비중, 점수 프로필, 통과선, 하드 게이트는
`docs/RESTORATION_QUEST_SPEC.md` 3~4장을 따른다. 마스크의 의미는 자산 제작 때 고정한다.

- 인물형: 얼굴 윤곽 / 머리 / 의상 / 고유 특징
- 문서형: 종이·배경 / 구조선 / 복원 문자 / 결정 행
- 소품형: 외곽 / 재질 / 핵심 문양
- 현장형: 배경 배치 / 주요 물체 / 인물 / 결정 소품
- `Q3C`: 어둠 제거 구역과 실제 사물 구역을 분리
- `Q5A`: 마차 위치와 문양을 분리. 문양은 본선 필수 영역
- 보조 목격담 영역은 표시 도움만 주며 채점 필수로 승격하지 않는다

`manifest.json`에는 다음 필드를 둔다.

```json
{
  "questId": "Q5A_DOCK",
  "gridSize": 256,
  "target": "target.png",
  "line": "line.png",
  "masks": ["layout", "carriage", "figure", "emblem"],
  "palette": [],
  "requiredFeatures": [],
  "optionalHints": [],
  "forbiddenContent": [],
  "sourcePrompt": "source/prompt.txt"
}
```

## 9. 증거판 카드 이미지 명세

카드 상단 54×26 영역에 임의 색 블록을 넣지 않는다.

| 카드 상태 | 표시 이미지 |
| --- | --- |
| `OPEN` | 내용이 보이지 않는 뒤집힌 종이. 퀘스트 정답 미노출 |
| `CLEARED` | 플레이어가 실제로 완성한 복원 결과의 정수배 축소본 |
| 저장 데이터가 없는 과거 세이브 | 해당 퀘스트 `board-fallback.png` |
| `Q6_FINALE` | 붉은 실과 두 개의 빈 연결점을 보여 주는 전용 종점 카드 |

`board-fallback.png`는 별도로 새 장면을 생성하지 않는다. 각 퀘스트 `target.png`에서
중앙 핵심을 수동 크롭해 만든다. 따라서 증거판·작업대·컷신의 그림이 서로 달라지지 않는다.

썸네일 크롭의 핵심 초점:

- Q0 모자와 얼굴 / Q1A 덧칠 관자놀이 / Q1B 페리 얼굴
- Q2A 눈썹과 흉터 / Q2B 흰 귀와 리본 / Q2C 배와 세 사람
- Q3A 3줄 / Q3B 닻과 붉은 피부 / Q3C 상자 틈
- Q4A `T.C.` 행 / Q4B 두 번째 기둥 기록 / Q4C 램 얼굴
- Q5A 마차 문 4줄 / Q5B 기울어진 배

## 11. 생성 기록 규격

각 생성 자산의 `source/`에는 다음을 남긴다.

- 최종 프롬프트 원문
- 사용한 기준 이미지 경로와 역할
- 생성 도구·모델 경로
- 생성일
- 선택한 원본 파일
- 크롭·리사이즈·팔레트 양자화 내역
- 수동 수정 내역
- 스토리 검수자와 결과

프롬프트에는 반드시 다음 제약을 넣는다.

```text
정확한 글자와 문양은 넣지 않는다.
19세기 후반풍 가상 항구 도시, 저채도 갈색·청록·테라코타·크림.
굵은 픽셀 군집과 4단계 명암, 갈색 계열 외곽선.
블러·안티앨리어싱·현대 물건·로고·워터마크 금지.
```

인물 표정 변형은 반드시 `calm` 정체성 원본을 참조해 만든다. 얼굴형, 눈·코 위치,
머리, 의상색을 바꾸지 않는다.

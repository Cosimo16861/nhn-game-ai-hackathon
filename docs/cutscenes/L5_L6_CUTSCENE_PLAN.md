# L5 → L6 컷신 제작 계획

> 상태: 제작 완료 · 사용자 검토 대기
> 게임 연결: 하지 않음
> 기준: `271ffba`, 병렬 계획 확정 `0ee2b32`
> 검토 화면: 640×384 도트 화면, `x=152, y=278, 336×84` 대사창

## 1. 소유 범위와 고정 묶음

이 작업은 `assets/cutscenes/l5-l6/**`, `dev/cutscenes/cutscene-review-l5-l6.html`,
`dev/cutscenes/cutscene-review-l5-l6.js`, `scripts/prepare-l5-l6-cutscene-assets.py`, 이 계획서와
검토 기록만 수정한다. 실제 진행·저장·해금 코드에는 연결하지 않는다.

| 부모 | 순서 | 컷신 | 다음 노드 |
| --- | :--: | --- | --- |
| Q5A 완료 | 1/1 | `C6_EVIDENCE_WALL` 《세 줄과 네 줄》 | Q6 증거의 방 |
| Q5B 완료 | 1/1 | `C5B_THAT_NIGHT_CLOSING` 《그 밤》 | 없음 |

Q5B 검토에는 Q5A 상태만 바꾸는 두 fixture를 둔다. 기본값은 `q5a=incomplete`, 보조값은
`q5a=complete`다. 두 fixture 모두 같은 closing을 재생하고 마지막 복귀 문구만 달라진다.

## 2. 장면 계약 체크리스트

### C6_EVIDENCE_WALL — Q5A → Q6

- [x] 경찰서에서 Q5A 결과의 마차 문을 확대한다.
- [x] 플레이어가 초승달 아래 파도 네 줄을 화면과 대사로 직접 센다.
- [x] Q3A 진품 봉인의 초승달 아래 파도 세 줄을 같은 배율로 나란히 놓는다.
- [x] 카버가 외운 네 줄은 진품 봉인이 아니라 마차 문에서 배운 것이라는 관계까지만 결론 낸다.
- [x] `방계 문장`, 마차 소유자 이름, 마차 소유자=줄리언을 말하거나 그리지 않는다.
- [x] 리드는 소유자를 등록부로 확인하겠다고 하되 아직 이름을 단정하지 않는다.
- [x] 개별 그림 하나만으로는 우연이라는 반론이 가능하므로 모든 그림을 벽에 걸 이유를 말한다.
- [x] 사무소 벽 준비로 이동하고 Q6이 복원이 아니라 마지막 실을 잇는 작업임을 예고한다.
- [x] 대사 앵커의 의미를 모두 보존한다.

증언·근거 출처는 Q5A에서 복원한 뱅크스의 기억 속 마차 문, Q3A에서 편지 눌림과 밀랍
조각으로 복원한 진품 봉인, 그리고 C3A에서 카버가 직접 그린 네 줄이다. Q6의 작업 대상은
본선 그림 전체가 걸린 증거판이며, 작업 이유는 독립 그림 사이의 관계를 마지막 실로 연결해
우연이라는 반론을 막는 것이다.

### C5B_THAT_NIGHT_CLOSING — Q5B closing

- [x] 폭풍 소리가 사라진 뒤 Q5B 결과의 기울어진 배·난간·두 손으로 매달린 에드먼드를 오래 보여 준다.
- [x] 뱅크스가 선체 각도와 자세가 자신의 기억과 맞다고 확인한다.
- [x] 에드먼드는 영웅이 아니라 두려운 열여덟 살이었고 어머니를 끝까지 불렀다고 말한다.
- [x] 엘리너에게 말하지 못한 까닭은 그녀가 듣고 싶은 이야기가 아니었기 때문이라고 고백한다.
- [x] 사건 해결 증거와 새 노드를 주지 않는다.
- [x] Q5A 미완료면 `이제 선생이 쫓던 사람 일로 돌아가시오` 의미의 사건 복귀 문구를 쓴다.
- [x] Q5A 완료면 `증거판의 마지막 연결까지 끝내시오` 의미의 중립 문구를 쓴다.
- [x] 두 fixture 모두 줄리언, 아셔튼, 카버의 정체, 봉인, 마차 문양, 장부를 언급하지 않는다.

이 closing의 출처는 뱅크스의 직접 목격과 Q5B에서 완성한 그림이다. 복원이나 다음 작업을
열지 않으며, 가지 단독으로 재생해도 본선 사실을 전제하지 않는다.

## 3. 시각·애니메이션 설계

| 장면 | 화면 | 핵심 연출 |
| --- | --- | --- |
| C6 전반 | 야간 경찰서 비교 책상 | 마차 문 네 줄을 한 획씩 밝힌 뒤 진품 봉인 세 줄과 동일 배율 병치, 정확한 선 수는 런타임 픽셀 도형으로 고정 |
| C6 후반 | 사무소 증거 벽 | 기존 본선 그림을 추상 증거 카드로 걸고 붉은 실의 열린 끝을 남김, 먼지·램프 맥동·카메라 이동 |
| C5B closing | 폭풍 뒤 선술집과 기억 정지화 | 기억 속 기울어진 선체와 두 손 자세를 오래 홀드, 비·번개가 멎고 난로빛만 남는 전환 |

인물 정체성은 새로 생성하지 않는다. 플레이어·리드는 승인된 C0B 초상을 재사용하고, 홀트는
승인된 L1→L2 초상을 재사용한다. 뱅크스는 L4→L5와 같은 공용 원본 표정 시트
`11-homeless-portraits.png`의 0/1/3 프레임을 `portrait-crop-v1`로 준비한다.

## 4. 이미지 자산과 프롬프트 기록

필요한 신규 래스터 자산은 인물 없는 배경 2종과 얼굴을 식별할 수 없는 기억 삽입컷 1종이다.
정확한 프롬프트는 `assets/cutscenes/l5-l6/source/PROMPTS.md`에 먼저 기록한다.

- `police-evidence-room-generated.png`: 경찰서 비교 책상과 벽, 문양·이름·읽히는 글자 없음
- `office-evidence-wall-generated.png`: 사무소의 비어 있는 증거 벽, 결정적 연결과 이름 없음
- `siren-memory-generated.png`: 기울어진 세이렌 호와 난간, 매달린 인물은 얼굴을 식별할 수 없는 실루엣

생성본은 source에 보존하고 준비 스크립트에서 640×384 도트 팔레트로 후처리한다. 세 줄,
네 줄, 증거 카드 글자, 붉은 실의 정확한 연결은 모두 캔버스에서 결정론적으로 그린다.

## 5. 검토·QA 계획

1. 이야기 논리·증언 출처·스포일러·시각 연속성을 동일 피드백 관점으로 검토한다.
2. 지적을 수정한 뒤 같은 체크리스트로 재검토하는 과정을 총 3회 기록한다.
3. JS 문법, 파일/PNG 규격, 초상 소스 SHA256과 크롭 규칙을 검사한다.
4. 전용 포트 8133에서 `bundle=q5a`, `bundle=q5b&q5a=incomplete`,
   `bundle=q5b&q5a=complete`를 브라우저로 검토한다.
5. SPACE 문장 완성/다음, ESC 현재 편 스킵, R 현재 부모 묶음 처음부터 다시 보기를 확인한다.
6. 콘솔 오류, 한글 3줄 초과·끝 글자 누락, localStorage 변경이 없음을 확인한다.

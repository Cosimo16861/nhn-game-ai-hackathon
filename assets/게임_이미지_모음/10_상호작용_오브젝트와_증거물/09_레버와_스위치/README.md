# 레버·스위치 상태 세트

사람이 없는 투명 PNG 환경 퍼즐 오브젝트입니다. 32×32 타일 맵에서 바닥 중앙(`bottom-center`)을 기준으로 배치합니다.

## 구성

- 황동 벽 레버: 꺼짐, 전환 중, 켜짐, 자물쇠 잠김, 파손
- 철도식 바닥 레버: 꺼짐, 전환 중, 켜짐, 숨겨진 토큰 조사, 고장
- 도자기 칼날 스위치: 꺼짐, 전환 중, 켜짐, 의심스러운 추가 배선, 파손
- 배관 회전 밸브: 닫힘, 일부 열림, 열림, 숨겨진 열쇠, 파손
- 호박색 작동 표시등 3프레임

## 게임 적용

- 개별 오브젝트 20개는 `objects/`에 있습니다.
- 전환 애니메이션은 첫 세 상태를 `off → transition → on` 순서로 사용합니다.
- `manifest.json`의 `active`, `transition`, `search_reveal`, `usable`, `requires_unlock` 값으로 퍼즐을 제어합니다.
- 벽 부착식 장치는 자체 충돌이 없고 벽 충돌을 사용하며, 바닥 장치는 고정 충돌을 사용합니다.
- 작동 표시등은 `effects/`의 3프레임을 스위치 위에 반복해서 표시합니다.

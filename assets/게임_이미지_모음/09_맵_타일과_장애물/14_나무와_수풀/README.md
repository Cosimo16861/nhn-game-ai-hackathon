# 14. 나무와 수풀

영국풍 마을과 외곽 숲에 사용하는 투명 배경 식생 오브젝트 20종입니다.

- 큰 나무 8종: 64×96 PNG
- 그루터기·수풀: 32×32 또는 64×48 PNG
- 쓰러진 통나무·긴 생울타리: 64×32 PNG
- `objects/`: 완성 오브젝트 20개
- `tree-layers/`: 큰 나무의 밑동 레이어와 전경 나뭇잎 레이어
- `vegetation-spritesheet-5x4.png`: 전체 스프라이트 시트
- `vegetation-map-sample.png`: 마을 배치 예시
- `manifest.json`: 크기, 충돌 영역, 레이어 정보

큰 나무는 밑동을 플레이어 아래에, 나뭇잎 전경을 플레이어 위에 표시합니다. 충돌은 나무 전체가 아니라 밑동 주변만 막아야 나무 뒤로 걸어가는 모습이 자연스럽습니다. 빽빽한 수풀·가시덤불·생울타리는 전체를 막고, 생울타리 입구 중앙만 이동 가능하게 설정하세요.

# L2 → L3 컷신 제작 계획

> 상태: 제작·QA 완료, 사용자 검토 대기
> 기준: `271ffba` + 병렬 계획 `0ee2b32`
> 게임 연결: 하지 않음
> 검토 화면: 640×384, 336×84 대사창, 텍스트 레이어 1920×1152

## 1. 제작 범위와 실제 재생 묶음

| 부모 트리거 | 순서 | 컷신 | 다음 노드 |
| --- | :--: | --- | --- |
| Q2A 완료 | 1/2 | `C3A_CARVERS_CREST` 《카버가 그린 네 줄》 | Q3A 봉인의 세 줄 |
| Q2A 완료 | 2/2 | `C3B_FRESH_ANCHOR` 《소매 아래의 닻》 | Q3B 너무 새것인 닻 |
| Q2B 완료 | 1/1 | `C3C_FOLLOW_THE_FLYER` 《전단이 찾은 창고》 | Q3C 창고의 불빛 |
| Q2C 완료 | 1/1 | `C2C_OPEN_DOOR_CLOSING` 《열린 문간》 | 없음 |

Q2A의 두 편은 같은 경찰서에서 장소 소개 없이 이어진다. 첫 편 종료 뒤 카버가 곧바로
소매를 걷으며 두 번째 편을 시작한다. `ESC`는 현재 편만 끝내 다음 편으로 넘기고, `R`은
현재 부모 묶음의 첫 편으로 돌아간다. Q2C는 `q2a=incomplete|complete` 검토 fixture를
제공하되 새 노드를 열지 않는다.

## 2. 장면 계약 체크리스트

### C3A_CARVERS_CREST → Q3A

- [x] 학교 완료 뒤 홀트를 모시고 카버를 경찰서로 소집한 이동을 밝힌 뒤, 경찰서 와이드에서 Q2A 복원 얼굴과 카버를 같은 배율로 비교한다.
- [x] 리드가 각진/둥근 턱, 올라간 왼눈썹/대칭 눈썹, 관자놀이 흉터/흉터 없음의 세 차이를 확인한다.
- [x] 카버는 열두 해와 난파로 얼굴이 달라질 수 있다고 반박하고, 가짜로 확정되지 않는다.
- [x] 줄리언은 난입 직후 엘리너의 조카이자 지난 12년 재산 관리인으로 소개된 뒤 사기꾼이라 공격하지만 범행 증거로 해설하지 않는다.
- [x] 카버가 칠판에 초승달과 파도 네 줄을 한 줄씩 그리며 “어릴 때부터 봤다”고 말한다.
- [x] 엘리너는 “익숙한 문양”이라고만 반응하고 진품의 줄 수는 말하지 않는다.
- [x] 엘리너가 에드먼드의 아버지가 남긴 편지를 갈라진 봉인 밀랍과 함께 보관했다고 밝힌다.
- [x] 조각과 편지의 불완전한 눌림을 맞춰 원래 문양을 복원해야 함을 명시한다.
- [x] 금지: 진품 세 줄의 말/그림, 카버가 법적으로 가짜라는 결론, 줄리언이 가르쳤다는 결론.

### C3B_FRESH_ANCHOR → Q3B

- [x] 인장 대화 직후 카버가 자신이 열여덟 살 때 새겼다고 주장하는 닻을 중앙 손목 증거 패널로 보인다.
- [x] 손목 닻을 증거 모드로 확대한다.
- [x] 기존 닻 도안, 선명한 먹색, 바늘 주변 붉은 피부를 관찰한다.
- [x] 내일 소매를 감추면 기록 기회가 사라짐을 리드가 말한다.
- [x] 플레이어가 날짜를 단정하지 않고 지금 조서용 그림으로 남긴다.
- [x] 금지: 정확한 시술 날짜, 줄리언의 지시, “최근 문신”이라는 완료 결론.

### C3C_FOLLOW_THE_FLYER → Q3C

- [x] 코라가 완성 전단의 흰 귀 하나와 붉은 리본을 확인하며 붙인다.
- [x] 부두 인부가 회색 고양이가 붉은 것을 매고 부두 창고로 드나들었다고 직접 증언한다.
- [x] 코라가 창문 없는 창고와 등불 하나로 발밑만 보이는 조건을 설명한다.
- [x] 좌우 높이가 다른 상자 더미, 젖은 바닥, 등불 동선을 이어 고양이 틈을 찾을 당위를 말한다.
- [x] 금지: 젖은 종이 내용, 뱅크스 이름, 검은 마차, 아셔튼, 파도 문양.

### C2C_OPEN_DOOR_CLOSING

- [x] 열린 아이 방 문과 종이에 옮겨진 크레용 그림을 보여 준다.

- [x] 엘리너는 아이가 없음을 확인하게 될까 두려워 12년 동안 문을 피했다고 고백한다.
- [x] Q2A 미완료: 아이의 아주 짙은 머리 관찰을 홀트의 기존 증언에 보태 얼굴을 복원하겠다고 말한다.
- [x] Q2A 완료: 짙은 머리가 홀트 증언과 일치한다고만 말하며 완료 조사를 반복 안내하지 않는다.
- [x] 새 퀘스트·결정적 증거·본선 해금은 없다.

## 3. 증언 출처와 복원 당위

| 목적지 | 출처 | 대상·상태 | 복원 이유 |

## 4. 자산 및 이미지 프롬프트 계획

정확한 프롬프트는 `assets/cutscenes/l2-l3/source/PROMPTS.md`에 먼저 기록한다.

- 환경 플레이트: 경찰서(기존 승인 자산을 로컬 후처리), 해질녘 부두·창문 없는 창고 외부,
  열린 아이 방 문간.
- 정체성 잠금 초상: 카버·줄리언·부두 인부는 정본 4프레임 시트를
  `portrait-crop-v1`로 크롭한다. 플레이어·리드·엘리너·홀트·코라는 승인 자산을 그대로 참조한다.
- 증거 삽입컷: Q2A 복원 얼굴, Q2B 전단, Q2C 완성 그림은 실제 퀘스트 목표 자산을 재사용한다.
- 편지·갈라진 밀랍 조각은 전용 삽입컷으로 제작한다. 닻 손목은 L3→L4의
  `fresh-anchor-record.png`를 시각 정본으로 삼아 로컬 참조본으로 고정한다.
- 칠판의 초승달+파도 네 줄은 런타임에서 한 줄씩 그린다. 진품의 정확한 세 줄 이미지는
  이 레이어의 어떤 생성 원본·후처리 자산·런타임에도 넣지 않는다.

## 6. 제작·검토 절차

1. 본 계획과 이미지 프롬프트를 잠근다.
2. 환경 원화를 생성하고 640×384 도트 밀도로 후처리한다.
3. 초상·삽입컷을 준비하고 크기·SHA256·스포일러를 검사한다.
4. 네 컷신과 부모별 묶음·fixture를 검토 런타임에 구현한다.
5. 동일 피드백 에이전트가 이야기 논리·증언·스포일러·시각 연속성을 3회 검토하며, 매회 수정 후 다시 전달한다.
6. 문법, 자산 규격, 3줄 대사, 묶음 연속 재생, `SPACE`/`ESC`/`R`, 저장 무변경을 브라우저로 검사한다.
7. 게임 진행·저장·해금에는 사용자 승인 전 연결하지 않는다.

자산 준비는 현재 Worktree에서 Pillow가 포함된 번들 Python으로 재현한다.

```sh
/opt/homebrew/Caskroom/miniforge/base/bin/python3 scripts/prepare-l2-l3-cutscene-assets.py
```

시스템 기본 `python3`에는 Pillow가 없을 수 있으므로 위 런타임을 검토 기준으로 사용한다.

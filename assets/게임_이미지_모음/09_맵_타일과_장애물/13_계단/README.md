# 13. 계단 타일

32×32 픽셀 기준의 탑다운 계단 세트입니다. 야외 돌계단 10종과 나무·실내 계단 10종으로 구성됩니다.

- `stairs-tileset-5x4-32px.png`: 게임용 5×4 아틀라스
- `tiles-32px/`: 개별 PNG 20개
- `stairs-preview-6x.png`: 투명 영역 확인용 확대 미리보기
- `stairs-map-sample.png`: 돌계단·나무계단 배치 예시
- `manifest.json`: 타일 순서와 이동·충돌 설정
- `source/`: 생성 원본과 투명 처리 원본

일반 계단과 금이 간 계단은 이동 가능, 붕괴·사슬·파손·가로막힘 계단은 이동 불가능으로 사용합니다. 실제 층 또는 맵 이동은 마지막 계단 칸에 별도의 전환 트리거를 배치하세요. 가까운 쪽 난간은 플레이어보다 위에 표시하는 전경 레이어로 분리하면 자연스럽습니다.

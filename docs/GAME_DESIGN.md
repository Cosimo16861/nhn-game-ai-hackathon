# 《안개항의 상속자》 통합 게임 계획서

> 상태: 통합 기준 문서
>
> 목표 플레이 시간: 15~20분
>
> 플랫폼: 웹 브라우저
>
> 장르: 픽셀 아트 탐정 어드벤처

이 문서는 `STORY_OUTLINE.md`의 이야기와 분기를 정본으로 삼고,
`game_asset_uimaking.txt`의 그래픽·월드·UI·복원 시스템 명세를 통합한 개발 기준이다.
세 문서 사이에 내용이 다를 경우 이 문서의 확정 사항을 우선한다.

---

## 1. 확정된 제작 원칙

- 전체 이야기는 `STORY_OUTLINE.md`를 따른다.
- 엔딩은 **좋은 엔딩 A**와 **불완전 해결 엔딩 B**의 두 개다.
- LLM 연결과 자유 입력 대화는 사용하지 않는다. 모든 대사는 사전 작성한다.
- 일반 대화는 반복 가능한 질문과 스몰 토크, 핵심 판단은 최대 4개의 고정 선택지로 구성한다.
- 복원 점수와 통과 기준의 정확한 숫자는 플레이어에게 공개하지 않는다.
- 내부 점수에 따라 증언형 힌트, 시각·음향 신호와 정성적 피드백을 제공한다.
- 메인 경로의 목표 플레이 시간은 15~20분이다.
- 전체 NPC는 15~18명으로 구성하되, 스토리의 중심 인물과 주변 인물의 역할을 분명히 나눈다.
- 전투, 시간제한과 일반적인 게임오버는 없다.
- 잘못된 선택이나 낮은 복원 결과가 필수 진행을 영구적으로 막지 않는다.

## 2. 게임 개요

| 항목 | 내용 |
| --- | --- |
| 제목 | 《안개항의 상속자》 |
| 영문명 | The Heir of Haven |
| 핵심 콘셉트 | 사진 기술이 보편화되기 전, 증언을 그림으로 복원해 사건의 진실을 밝힌다. |
| 배경 | 안개 낀 항구 도시 헤이번, 19세기 후반풍 가상 세계 |
| 플레이어 | 그림 복원을 전문으로 하는 젊은 사설 탐정 |
| 메인 콘텐츠 | 탐색, 고정 선택지 대화, 단서 수집, 그림 복원, 증거 연결 |
| 메인 퀘스트 | 얼굴·인장과 문신·부두 현장 복원 3개 |
| 서브 퀘스트 | 고양이 찾기, 항해일지 찾기 2개 |
| 엔딩 | A `안개 너머의 진실`, B `반쪽짜리 정의` |

게임의 핵심은 범인을 감으로 고르는 것이 아니라 여러 사람의 기억에서
색상·형태·문양·위치 관계를 추출해 그림으로 복원하는 데 있다. 완성한 복원물은
미니게임 보상이 아니라 이후 대화, 조사 가능 장소, 증거판과 엔딩 조건에 영향을
주는 실제 사건 증거다.

## 3. 핵심 게임 흐름

```text
마을 탐색
→ NPC 대화와 사물 조사
→ 증언·단서 카드 획득
→ 탐정 사무소 작업대에서 그림 복원
→ 숨은 유사도 판정과 정성적 피드백
→ 복원물 및 다음 사건 단계 해금
→ 세 사건의 증거를 경찰서에서 연결
→ 최종 결론 선택
→ 엔딩 A 또는 엔딩 B
```

메인 사건 순서는 고정한다. 공간은 자유롭게 탐색할 수 있지만, 현재 사건 단계에
맞는 인물·사물만 핵심 상호작용을 제공한다. 메인 경로 외 건물과 주민은 세계의
생활감을 만들고 보조 단서나 스몰 토크를 제공한다.

### 시간과 실패

- 누적 플레이 시간은 HUD에 표시하되 성공·엔딩 조건에는 사용하지 않는다.
- 탐색·대화·복원·이벤트 중에는 시간이 흐르고, 메뉴와 일시정지 중에는 멈춘다.
- 복원 제출 횟수에는 제한이 없다.
- 낮은 점수를 받으면 현재 그림을 유지한 채 수정할 수 있다.
- 잘못된 핵심 판단은 좋은 엔딩용 증거를 놓치게 할 수 있지만 메인 진행은 계속된다.
- 놓친 증거는 서브 퀘스트나 다른 인물의 보조 단서로 일부 보완할 수 있다.

## 4. 이야기 정본

### 4.1 사건의 전제

12년 전 아셔튼 가문의 외아들 에드먼드 아셔튼은 무역선 세이렌 호 침몰로
실종됐다. 시신은 발견되지 않았고, 어머니 엘리너는 아들의 사망을 인정하지
않았다.

어느 날 토마스 카버라는 남자가 자신이 에드먼드라고 주장하며 돌아온다.
엘리너는 그를 아들로 받아들이지만, 가문의 조카이자 재산 관리인인 줄리언은
공개적으로 사기꾼이라 비난한다. 경찰은 객관적인 신원 확인 수단이 없어
증언을 그림으로 복원하는 플레이어에게 사건을 의뢰한다.

### 4.2 실제 진실

줄리언은 오랫동안 아셔튼 가문의 재산을 빼돌렸다. 횡령을 감추기 위해
에드먼드와 어느 정도 닮은 카버에게 어린 시절의 기억, 가문 인장, 문신과 습관을
가르쳐 가짜 상속자로 만들었다. 카버가 재산 처분을 승인하면 다시 사라지게 할
계획이었다. 줄리언은 의심을 피하려고 겉으로는 카버를 가장 강하게 비난한다.

### 4.3 프롤로그

게임은 탐정 사무소에서 시작한다. 리드 경위의 호출을 받고 경찰서에서
카버와 아셔튼 가문의 분쟁을 확인한다. 첫 태도 선택은 엔딩을 바꾸지 않지만
리드와 줄리언의 반응 및 이후 대사 어조를 바꾼다.

수사 목적은 다음 세 가지다.

1. 카버의 얼굴이 진짜 에드먼드와 일치하는지 확인한다.
2. 카버가 아는 가문의 표식이 진짜인지 확인한다.
3. 카버가 헤이번에 나타나기 전 누구와 접촉했는지 확인한다.

### 4.4 1막 — 사라진 얼굴

엘리너의 오래된 초상은 아들의 얼굴을 미화한 자료다. 학교에서 만나는 옛
가정교사 홀트는 에드먼드가 웃을 때 왼쪽 눈썹이 올라갔고 관자놀이에 작은
흉터가 있었다고 기억한다.

**메인 복원 1: 에드먼드의 초상**

- 얼굴과 턱의 실제 윤곽
- 왼쪽 눈썹의 비대칭
- 관자놀이의 작은 흉터
- 짙은 머리와 의복 색상

결정적 얼굴 증언을 확보했다면 카버는 전체 인상만 비슷하고 턱·눈썹·흉터가
일치하지 않는다는 점이 드러난다. 증언을 놓쳤다면 윤곽 불일치까지만 확인한다.

**서브 퀘스트 1: 고양이 안개**

선술집 주인의 증언을 바탕으로 회색 털, 한쪽 흰 귀와 붉은 목 리본을 가진
고양이의 작은 초상을 만들어 전단을 게시한다. 복원 시스템 튜토리얼 역할을
하며, 실제 고양이는 3막 부두 창고에서 발견해 코라에게 돌려보내야 퀘스트가
완료된다.

### 4.5 2막 — 지워지지 않는 증거

카버는 에드먼드와 같은 닻 문신과 가문의 봉인 인장을 안다고 주장한다.
플레이어는 아셔튼 저택의 편지 봉인, 항해일지의 닻 그림, 반출 장부와 최근
열린 유품 상자를 조사한다. 카버의 문신은 지나치게 선명하며, 기억대로 인장을
그려 달라고 하자 진품과 다른 네 번째 파도 선을 그린다.

**메인 복원 2: 인장과 문신**

- 초승달 아래 세 줄의 파도
- 인장의 바깥 테두리
- 에드먼드의 닻 문신
- 편지에 남은 불완전한 봉인 자국

리드에게 장부를 비밀리에 대조하도록 요청하면 줄리언의 관리 서명, 유품 반출
기록과 `T.C.` 지급 기록을 확보한다. 다른 판단을 해도 사건은 계속되지만 좋은
엔딩에 필요한 결정적 증거 하나를 놓칠 수 있다.

### 4.6 3막 — 마지막 항해

생존 선원 뱅크스는 카버가 세이렌 호 선원이 아니라 과거 부둣가에서 일하던
토마스였음을 기억한다. 최근 카버가 검은 마차를 타고 온 인물을 만났으며,
마차 문에는 아셔튼 가문의 초승달과 파도 문양이 있었다.

**메인 복원 3: 안개 낀 부두**

- 가스등 아래의 검은 마차
- 부두에 정박한 배
- 카버의 실루엣
- 마차 문의 초승달·파도 문양
- 젖은 돌바닥과 주변 상자

**서브 퀘스트 2: 사라진 항해일지**

부두 창고에서 항해일지 조각을 찾는다. 이 항해일지는 뱅크스가 세이렌 호에서
건진 뒤 최근 부두 기록용 수첩으로 계속 사용한 물건이다. 고양이 전단을
게시했다면 창고에서 안개를 알아보고 따라가 더 쉽게 발견할 수 있다. 항해일지는
앞서 놓친 결정적 증거 하나를 보완하는 안전장치다.

### 4.7 최종 국면

경찰서 증거판에 복원한 얼굴, 잘못 복제된 인장과 최근 문신, 검은 마차가 있는
부두 그림을 배치한다. 플레이어는 다음 결론 중 하나를 선택한다.

1. 카버는 혼자 신분을 속인 사기꾼이다.
2. 카버는 사칭범이며 줄리언이 그를 준비시킨 배후다.
3. 배후 판단은 보류하고 카버의 사칭만 처리한다.

줄리언을 배후로 입증하려면 결정적 증거 세 개 중 두 개 이상이 필요하다.
항해일지는 놓친 결정적 증거 하나를 대신할 수 있다.

### 4.8 엔딩

**엔딩 A — 안개 너머의 진실**

결정적 증거를 두 개 이상 확보하고 줄리언을 배후로 지목하면 카버와 줄리언이
모두 체포된다. 엘리너는 아들이 돌아오지 않았음을 받아들이고, 홀트는 복원된
초상을 학교에 전시한다. 사무소의 세 그림이 붉은 실로 연결되고 안개가 걷힌다.

**엔딩 B — 반쪽짜리 정의**

카버만 지목하거나 줄리언을 입증할 증거가 부족하면 카버만 체포된다. 줄리언은
사건 해결에 협조한 사람처럼 행동한 뒤 헤이번을 떠난다. 사무소 증거판의 붉은
실은 빈 압정 앞에서 끊기고 검은 마차가 안개 속으로 사라진다.

### 4.9 엔딩 후 재시작

엔딩 화면에서 다음 행동을 제공한다.

- 현재 결말의 후일담 보기
- 놓친 분기부터 다시 수사
- 처음부터 새 게임

`놓친 분기부터 다시 수사`는 좋은 엔딩 조건을 놓치게 만든 가장 최근 핵심 판단
직전으로 돌아간다. 이미 확인한 엔딩 기록은 유지하며 타이틀에는 사건 기록
`1/2` 또는 `2/2`를 표시한다.

## 5. 등장인물 구성

전체 NPC는 15~18명으로 구성한다. 모든 NPC가 사건 분기를 갖지는 않는다.

### 5.1 중심 인물

| 인물 | 기능 |
| --- | --- |
| 리드 경위 | 사건 의뢰, 수사 정리, 장부 대조, 최종 체포 |
| 엘리너 아셔튼 | 미화된 얼굴 기억과 감정적 관점 제공 |
| 홀트 | 얼굴의 비대칭·흉터·습관에 관한 정확한 증언 제공 |
| 토마스 카버 | 가짜 상속자이자 복원 결과의 대조 대상 |
| 줄리언 아셔튼 | 재산 관리인이자 사칭 사건의 진짜 배후 |
| 뱅크스 | 카버의 과거와 검은 마차에 관한 부두 증언 제공 |

에드먼드는 현재 시점에 등장하지 않는 복원 대상이며, 플레이어는 NPC 수에
포함하지 않는다.

### 5.2 주변 인물

나머지 9~12명은 다음 역할을 나누어 맡는다.

- 선술집 주인: 고양이 퀘스트와 지역 소문
- 학교 관계자 또는 학생: 홀트와 에드먼드의 과거를 보조
- 저택 하인: 유품 상자와 줄리언의 출입에 관한 작은 단서
- 우체국 직원: 편지·봉인·발송 시점 관련 단서
- 부두 노동자: 카버가 머문 시기와 마차 이동에 관한 단서
- 역무원: 줄리언의 이동 가능성과 외지인 출입 암시
- 상점 주인·주민·행인: 마을 분위기, 사건 반응과 스몰 토크

주변 인물은 메인 진행을 독점하지 않는다. 중요한 사실은 중심 인물이나 다른
경로에서도 얻을 수 있어, 특정 행인을 놓쳐도 진행이 막히지 않는다.

야외를 걷는 NPC는 약 3명으로 제한한다. 이들은 각 구역의 짧은 고정 경로를
반복하며 사건 단계에 따라 위치·속도·대사가 바뀔 수 있다.

## 6. 대화와 단서 시스템

### 6.1 대화 방식

- LLM·외부 대화 API·자유 텍스트 입력은 사용하지 않는다.
- 선택지는 대화창 내부에 최대 4개까지 표시한다.
- 일반 질문은 다시 선택할 수 있고, 이미 물어본 질문에는 체크 표시를 붙인다.
- 한 번만 선택할 수 있는 핵심 판단은 선택 후 잠그거나 목록에서 제거한다.
- 증거가 필요한 선택지는 자물쇠와 필요 조건을 표시한다.
- 중심 인물은 사건 단계별 대사와 핵심 판단을 가진다.
- 주변 인물은 짧은 단서, 소문, 장소 안내 또는 스몰 토크를 제공한다.

### 6.2 대화 화면

- 월드 화면을 유지하되 배경의 밝기와 채도를 낮춘다.
- 플레이어 초상은 왼쪽 아래, NPC 초상은 오른쪽 위에 표시한다.
- 초상 원본은 64×64픽셀, 화면에서는 약 96×96픽셀로 확대한다.
- 주요 인물은 평상·긴장/불쾌·놀람/고조의 3개 표정을 기본으로 한다.
- 대화창은 약 448×112픽셀이며, 최대 3줄과 한 줄당 한글 24~28자를 기준으로 한다.
- 선택지가 4개이면 대화창을 위쪽으로 확장한다.

### 6.3 단서·증언 카드

- 카드에는 증언자, 요약, 전체 내용, 관련 인물·장소·복원 퀘스트를 기록한다.
- 서로 모순되는 증언은 연결 표시로 비교할 수 있다.
- 증언 신뢰도는 내부 데이터로 관리한다.
- 신뢰도 숫자를 직접 공개할지는 플레이 테스트 후 결정하되, 정답 위치는 표시하지 않는다.
- 아직 얻지 않은 단서는 목록에 미리 노출하지 않는다.

## 7. 월드와 장소

### 7.1 월드 구성

야외는 2×2로 연결된 4개 구역을 사용한다.

1. 주거지 북쪽
2. 중앙 광장과 공공시설
3. 주거지 남쪽
4. 상점가·교통·부두

전체 배경 계획은 야외 4개와 내부 최대 16개를 유지한다. 다만 15~20분의 메인
플레이에서는 다음 핵심 장소를 우선 사용한다.

1. 탐정 사무소 — 시작점, 증언 확인과 그림 복원
2. 경찰서 — 사건 브리핑, 장부 대조와 최종 증거판
3. 아셔튼 저택 — 엘리너·카버·줄리언, 유품과 인장 조사
4. 학교 — 홀트의 증언과 에드먼드의 과거
5. 선술집 — 뱅크스, 고양이 퀘스트와 지역 소문
6. 부두·창고 — 마지막 현장, 항해일지와 검은 마차 단서

그 밖의 건물은 선택 탐색 공간으로 사용한다. 처음부터 지도와 출입구를 보여줄
수 있지만, 메인 사건과 무관한 내부는 짧은 대사·환경 조사 중심으로 제한한다.
메인 사건의 상호작용과 NPC 상태는 진행 순서에 따라 해금한다.

### 7.2 전체 장소 후보

- 경찰서, 마을회관, 우체국, 진료소
- 학교, 도서관, 탐정 사무소, 집 1
- 약방, 아셔튼 저택, 집 2
- 빵집, 선술집, 잡화점, 기차역, 부두 창고

메인 경로를 벗어난 장소는 제작 일정에 따라 외관만 제공하거나 내부를 축소할 수
있다. 메인 동선은 사무소→경찰서→저택/학교→선술집→부두→경찰서 흐름을
기준으로 15~20분 안에 끝나도록 한다.

### 7.3 사건에 따른 변화

- 평상시는 A 팔레트, 사건 진행 중은 차갑고 저채도인 B 팔레트, 해결 후는 더
  밝고 따뜻한 C 팔레트를 사용한다.
- 사건 단계에 따라 안개·조명·배경음·NPC 위치와 대사가 바뀐다.
- 해결 후에도 사무소의 복원 그림, 경찰서 게시판과 주민 대사에 사건 흔적이 남는다.

## 8. 복원 시스템

### 8.1 화면 구성

- 탐정 사무소의 작업대를 바라보는 1인칭 화면이다.
- 중앙에 약 320×256픽셀 캔버스를 크게 배치한다.
- 왼쪽에는 증언 카드, 오른쪽에는 제한형 팔레트와 작업 도구를 배치한다.
- 위쪽에는 복원 목표와 제출 버튼을 표시한다.
- 아래쪽에는 실행 취소·다시 실행·확대·축소·격자·초기화를 배치한다.

### 8.2 도구

- 연필, 지우개, 채우기, 직선, 사각형, 색상 추출, 선택 영역 이동
- 1·2·3픽셀 도구 크기
- 마우스 휠 확대·축소
- 가운데 버튼 또는 스페이스 드래그로 화면 이동
- 최소 50단계 실행 취소·다시 실행
- 작업 화면을 나가도 캔버스와 실행 기록 임시 저장
- 초기화 전 확인창 표시

### 8.3 복원 방식

퀘스트 대상에 맞춰 다음 방식을 조합한다.

1. 희미한 윤곽 수정형 — 얼굴 복원
2. 부분 채색형 — 의상·인장·문신
3. 조각 조립형 — 훼손 문서·봉인
4. 빈 캔버스 배치형 — 부두 현장의 인물·사물 위치 관계

### 8.4 숨은 점수와 피드백

내부에서는 다음 요소를 계산한다.

- 색상 유사도
- 윤곽 유사도
- 구조 유사도
- 팔레트 일치도
- CLIP 기반 의미 일치 보조값
- 필수 특징 반영 여부

정확한 점수, 가중치, 통과선과 정답 오버레이는 플레이어에게 공개하지 않는다.
결과 화면과 작업 중 피드백은 다음처럼 정성적으로 제공한다.

| 내부 상태 | 플레이어에게 보이는 표현 |
| --- | --- |
| 차이가 큼 | “증언 카드를 다시 살펴보자.” 핵심 부위에 관한 추가 증언 힌트 제공 |
| 방향은 맞지만 부족함 | “전체 인상은 가까워지고 있다.” 색·형태·배치 중 부족한 범주만 안내 |
| 통과선에 근접 | 연필 소리, 캔버스 가장자리의 짧은 빛, “거의 완성됐다”는 문장 |
| 통과 | 숫자 없이 “증거로 사용할 수 있을 만큼 복원됐다” 표시 |

피드백은 정답 좌표나 정확한 색상값을 알려주지 않는다. 반복 실패 시 힌트 강도를
단계적으로 높이며, 플레이어가 명시적으로 힌트를 요청하거나 여러 번 제출했을 때
더 구체적인 증언을 공개한다. 힌트 사용은 엔딩을 막지 않는다.

### 8.5 제출

- 제출 전 확인창을 표시한다.
- 제출 횟수에는 제한이 없다.
- 제출 후 짧은 종이 넘김 연출을 거쳐 정성적 결과를 보여준다.
- 통과하지 못해도 그림을 보존한 채 작업 화면으로 돌아간다.
- 통과한 복원물은 단서·증언 메뉴와 경찰서 증거판에 추가한다.

## 10. 탐색 HUD와 메뉴

### 10.1 탐색 HUD

- 왼쪽 위: 현재 목표 버튼과 펼침 패널
- 오른쪽 위: `02:14:37` 형식의 누적 플레이 시간
- 오른쪽 아래: 약 128×96픽셀 미니맵
- 위쪽 중앙: 목표·단서·아이템·복원 가능·자동 저장 알림
- 대상 근처: 말풍선·돋보기·문·손·붓·문서 상호작용 아이콘

미니맵은 플레이어, 건물 출입구, 현재 목표 장소와 중요한 퀘스트 NPC를 표시하되
숨은 단서와 정답 위치는 표시하지 않는다.

### 10.2 메뉴

메뉴는 목표, 단서·증언, 인벤토리, 지도, 설정의 5개 탭으로 구성한다.

- 목표: 현재 메인·서브·완료 퀘스트와 진행 단계
- 단서·증언: 단서·증언·복원물 카드
- 인벤토리: 무게와 전체 개수 제한 없는 격자형 아이템 목록
- 지도: 야외 4개 구역, 현재 위치와 목표 장소
- 설정: 음량, 화면, 조작, 대화 속도와 접근성

메뉴를 열면 게임과 플레이 시간이 멈춘다. 새 정보가 있는 탭에는 느낌표를,
현재 선택한 항목에는 황금색 강조를 사용한다.

- 장소 이동, 단서 획득, 퀘스트 완료, 막 전환과 엔딩 도달 시 자동 저장한다.

- 세 핵심 판단과 최종 증거 제시 직전에 분기 체크포인트를 만든다.
- 확인한 엔딩 기록은 분기 재시작 후에도 유지한다.
- 저장 데이터는 브라우저 로컬 저장소를 기본으로 한다.

## 12. 기술 활용

### 12.1 이미지 유사도

현재 보존된 다음 스크립트를 복원 판정의 기반으로 사용한다.

- `scoring.js`: 색상·윤곽·구조·팔레트 유사도
- `score-manager.js`: 결과 결합과 판정
- `clip-analyzer.js`: 이미지 의미 분석
- `clip-region-preparer.js`: 비교 구역 준비
- `clip-score-normalizer.js`: CLIP 결과 정규화
- `clip-score-manager.js`: 시각 점수와 CLIP 보조값 결합

정확한 계산 결과는 내부 판정과 피드백 단계 선택에만 사용한다.

### 12.2 생성 AI

얼굴·현장·사물의 원본 에셋 제작에 생성 AI를 사용할 수 있다. 사용 도구의
상업·2차 이용 조건을 확인하고 실존 인물, 브랜드와 특정 작가 화풍을 피한다.
도구·프롬프트·출처·라이선스를 기록한 뒤 픽셀화와 수작업 보정을 거친다.

### 12.3 폐기된 기능

- LLM 증인 대화
- 자유 텍스트 질문 입력
- 외부 대화 API와 서버리스 대화 프록시
- LLM 사용료와 연동된 힌트 경제

대화와 힌트는 모두 로컬에 포함된 사전 작성 데이터로 처리한다.

## 13. 15~20분 플레이 구성

| 구간 | 목표 시간 | 내용 |
| --- | ---: | --- |
| 프롤로그 | 2분 | 사무소 시작, 경찰서 의뢰와 첫 태도 선택 |
| 1막 | 4분 | 엘리너·홀트 조사와 얼굴 복원 |
| 2막 | 4분 | 저택 조사와 인장·문신 복원 |
| 3막 | 4분 | 뱅크스 조사, 부두 현장 복원 |
| 최종 국면 | 2분 | 증거 배치, 결론 선택과 엔딩 |
| 선택 콘텐츠 | 1~4분 | 고양이·항해일지·주변 NPC 대화 |

튜토리얼과 이동 시간을 포함해 메인 경로는 약 15분, 선택 콘텐츠를 일부
진행하면 약 20분이 되도록 조정한다. 주변 NPC의 대화는 한 번에 1~3문장으로
제한하고 메인 동선에서 멀리 벗어나지 않게 배치한다.

## 14. 제작 우선순위

### 필수

- 4개 야외 구역의 축약 월드와 6개 핵심 장소
- 중심 인물 6명과 주변 NPC를 포함한 총 15~18명
- 고정 선택지 대화와 사건 단계별 대사
- 얼굴·인장/문신·부두 현장 복원 3개
- 숨은 점수 기반 정성적 피드백과 단계형 힌트
- 경찰서 증거판과 엔딩 A/B
- 자동 저장, 분기 체크포인트와 엔딩 기록

### 선택

- 고양이와 항해일지 서브 퀘스트의 추가 연출
- 비핵심 건물 내부 확장
- 사건 전후 마을 팔레트·NPC 동선 변화 고도화
- 사운드, 컷씬과 접근성 설정의 추가 폴리시

### 범위 제외

- LLM 대화와 자유 텍스트 입력
- 전투와 시간제한
- 다중 사건·챕터 구조
- 아케이드 모드
- 빠른 이동

## 15. 완료 조건

통합 계획의 최소 완성 상태는 다음과 같다.

1. 플레이어가 사무소에서 시작해 경찰서의 의뢰를 받는다.
2. 중심 인물과의 고정 선택지 대화로 세 복원 퀘스트의 단서를 얻는다.
3. 세 그림을 복원하고 숫자가 아닌 피드백으로 수정 방향을 알 수 있다.
4. 낮은 점수나 잘못된 선택에도 플레이가 중단되지 않는다.
5. 확보한 결정적 증거 수와 최종 결론에 따라 엔딩 A 또는 B가 재생된다.
6. 15~20분 안에 한 번의 결말을 확인할 수 있다.
7. 엔딩 후 놓친 핵심 판단부터 다시 시작해 다른 결말을 확인할 수 있다.

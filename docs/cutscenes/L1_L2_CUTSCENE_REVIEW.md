# L1 → L2 컷신 검토 기록

> 상태: 사용자 승인 완료(2026-08-10)
> 게임 연결: 하지 않음
> 검토 기준: L0 → L1 전체 화면 컷신, 640×384, 336×84 공통 대사창

## 사용자 검토 화면

- Q1A 완료 묶음: `cutscene-review-l1-l2.html?bundle=q1a`
  - 1/2 《문 뒤의 빗물》 → Q2C 《닫힌 방》
  - 2/2 《홀트가 기억한 얼굴》 → Q2A 《기억되지 않은 얼굴》
  - 약 97초, 두 컷신 자동 연속 재생
- Q1B 완료 묶음: `cutscene-review-l1-l2.html?bundle=q1b`
  - 1/1 《안개를 찾습니다》 → Q2B 《고양이 전단》
  - 약 39초

두 화면 모두 `SPACE`로 대사를 진행하고, `ESC`로 현재 컷신만 건너뛰며, `R`로 현재
묶음의 처음부터 다시 본다. Q1A에서 첫 컷신을 건너뛰면 두 번째 컷신이 바로 이어진다.

## 제작 결과

- 신규 장소 배경 4종: 아셔튼 응접실, 서쪽 복도, 방과 후 학교, 부둣가 선술집
- 등장인물 4명: 엘리너, 베스, 홀트, 코라
- 삽입 단서 4종: 미화 초상, 젖은 벽 흔적, 복원된 선술집 벽, 코라의 고양이 기억
- 주요 효과: 비·번개, 누수·물웅덩이, 문 개방과 열린 상태 지속, 이동 페이드,
  난로 불빛, 고양이 리본 강조, 홀트의 기억 도식과 얼굴 클로즈업
- 다음 퀘스트 Q2A·Q2B·Q2C 각각에 필요한 증언의 출처와 복원 당위를 컷신 안에 명시
- 후속 퀘스트의 봉인·문신·창고 및 카버 대조 결론은 공개하지 않음

## 피드백 에이전트 3회 반복

### 1차 — 미승인 후 수정

1. 잠긴 방을 열기 전에 내부 단서를 관찰하던 공간 논리를 `열쇠 전달 → 문 개방 → 현장
   관찰` 순서로 고쳤다.
2. 서쪽 복도에서 응접실로 돌아오는 이동 페이드와 연결 대사를 추가하고, 초상 물감 겹에
   관한 반복 설명을 줄였다.
3. 한글 자동 줄바꿈에서 끝 글자가 누락될 수 있던 잔여 글자 차감식을 수정했다.
4. 홀트의 기억 도식에 얼굴 클로즈업을 더해 장면의 극성을 보강했다.

### 2차 — 조건부 미승인 후 수정

1. 문을 여는 순간 뒤 장면에서 다시 닫혀 보이던 문제를 고쳐 C2C가 끝날 때까지 열린 문
   상태를 유지했다.
2. 젖은 벽을 발견하고 곧바로 다른 장소로 이동하는 보존 공백을 없애기 위해, 베스가
   방수천을 대고 옮길 종이를 준비한다는 조치를 명시했다.

### 3차 — 최종 승인

- 치명·중요 문제 없음.
- Q2A·Q2B·Q2C의 증언, 출처, 복원 당위와 스포일러 제한을 모두 충족했다.
- Q1A 두 편의 연속 재생, 스킵, 묶음 다시 보기와 공통 대사창 가독성을 통과했다.
- 네 장소·네 NPC 및 날씨·조명·누수·문·기억 연출로 시각적 다양성을 충족했다.

## 이미지 생성 및 후처리

내장 이미지 생성 도구로 인물이 없는 환경 원화를 만든 뒤 640×384 도트 배경으로
후처리했다. 원본은 `assets/cutscenes/l1-l2/source/`, 실제 검토용 배경은
`assets/cutscenes/l1-l2/backgrounds/`, 정확한 프롬프트는
`assets/cutscenes/l1-l2/source/PROMPTS.md`에 보존했다. 첫 응접실·복도 시안에 섞인 UI는
편집 생성으로 제거하고 바닥과 공간을 자연스럽게 연장한 수정본만 채택했다.

## 통합 보류

이 단계에서는 게임 상태, 퀘스트 그래프, 해금 로직을 수정하지 않았다. 전체 컷신 검토가
끝난 뒤 각 부모 퀘스트의 클리어 지점에 묶음 단위로 연결한다.

## 전체 최종 QA 1차 반영

- 최초 플레이어 시각 검토에서 밝은 고양이 기억 인서트 위 흰색 캡션의 대비가 낮은 문제를 확인했다.
- `catMemory` 캡션 뒤에 반투명 암색 바를 추가해 옅은 회색 털·흰 귀·붉은 리본 증언을 가리지 않으면서 640×384 화면에서 읽히도록 수정했다.
- 승인된 대사, 묶음 순서, 증언 계약과 대사창 규격은 변경하지 않았다.

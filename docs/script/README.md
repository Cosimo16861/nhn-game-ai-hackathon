### 레거시를 그대로 쓰면 안 되는 지점

`03_ACT2.md`의 「줄리언이 불완전한 모사를 보고 가르쳤다」는 설명은 **폐기됐다.**
개정된 설정은 다음과 같다.

- 본가 인장 = 파도 **세 줄**, 줄리언의 **방계** 문장 = 파도 **네 줄**
- 줄리언은 본가 인장 실물을 본 적이 없어, 카버에게 자기 마차 문의 문양을 가르쳤다
- 그래서 `Q3A_SEAL`(세 줄)과 `Q5A_DOCK`(네 줄) **두 복원물의 대조가 배후를 지목한다**

자세한 것은 `../STORY_OUTLINE.md` 2.1절.

## 빌드로 옮길 때

- 컷신 비트는 `{ who, face, text, ms }` 배열이다. 스키마는 `../QUEST_BRANCH.md` 4.3절
- `grants`는 컷신 **종료 시점에 일괄 적용**한다. 중간 스킵해도 유실되지 않는다
- `unlocks`는 `src/data/quest-graph.js`의 `UNLOCKS` 표와 일치해야 한다.
  `QuestGraph.validate()`가 부팅 시 교차 검증한다
- 복원 목표는 설계 용어가 아니라 **목격담 그대로** 표시한다

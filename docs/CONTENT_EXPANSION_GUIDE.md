# 사건 콘텐츠 확장 가이드

이 프로젝트의 한 대형 사건은 연속된 정사각형 원본 이미지 한 장과 2×2 세부 사건 네 개로 구성됩니다. 새 사건은 아래 순서로 추가합니다.

1. 네 구역이 하나의 장면으로 이어지는 정사각형 원본 이미지를 준비합니다.
   - 권장 크기: 1024×1024 이상
   - 가로와 세로는 2로 나누어져야 합니다.
   - 이미지 출처와 라이선스는 `docs/ASSET_SOURCES.md`에 기록합니다.
2. 이미지를 `assets/cases`에 저장합니다.
3. `scripts/case-data.js`의 `chapters`에 대형 사건을 추가합니다.
4. 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래 순서로 세부 사건 네 개를 작성합니다.
5. 각 세부 사건에 다음 내용을 넣습니다.
   - 서로 다른 가림 구역 3개
   - 가림 구역 A·B·C와 같은 순서로 연결되는 목격담 3개
   - 같은 순서로 연결되는 서로 다른 영문 CLIP 문장 3개
   - 난이도, 통과 점수, 초심자용 힌트 1개 이상
6. 네 조각을 모두 복원한 뒤 풀 수 있는 최종 추리 문제를 작성합니다.
7. 완성 전에는 `masterImageStatus: "placeholder"`를 유지하고, 아래 검사를 모두 통과한 뒤 `"ready"`로 바꿉니다.

## 현재 콘텐츠 준비 상태

- 박물관 절도 사건: 준비 완료, 2×2 조각 4/4, 최종 추리 문제 포함
- 심야 편의점 절도 사건: 임시 콘텐츠, 조각 1/4
  - 연속된 전체 사건 이미지
  - 나머지 세부 사건 3개
  - 각 세부 사건의 목격담·CLIP 문장·힌트
  - 최종 추리 문제
  가 추가되어야 선택 가능한 사건이 됩니다.

## 검증

```powershell
node --test tests/*.test.cjs
```

`scripts/content-readiness.js`는 준비 상태, 조각 누락, 단서 수, 가림 구역, 난이도, 통과 점수, 힌트와 최종 추리 문제를 자동 검사합니다.

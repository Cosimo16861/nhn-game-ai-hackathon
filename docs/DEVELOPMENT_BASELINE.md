## 현재 게임 설정

- 분석 해상도: 256×256
- 색칠판 해상도: 128×128
- 팔레트: 8색
- 이미지 구역: 4×4
- 현재 손상 구역: 3개
- 시각 복원 점수: 최종 점수의 80%
- CLIP 사건 단서 점수: 최종 점수의 20%
- 시각 점수 내부 가중치: 색상 50%, 윤곽선 30%, 주변 구조 15%, 팔레트 5%

## 현재 구현 기능

- 사건 선택과 미션 카드
- 단서가 포함된 고정 사건 데이터
- 256×256 분석과 128×128 색칠의 이중 해상도 처리
- 가림 마스크와 픽셀 편집
- 실행 취소, 지우개, 초기화
- 색상·윤곽선·주변 구조·팔레트 채점
- CLIP 구역 분석과 종합 점수
- 사건 선택부터 결과까지 단계별 화면 전환
- 4단계 게임 진행 표시
- 모바일 레이아웃과 기본 접근성 규칙

# 밀 수 있는 상자와 가구 세트

사람이 없는 투명 PNG 이동·수색 퍼즐 오브젝트입니다. 32×32 타일 맵에서 바닥 중앙(`bottom-center`)을 기준으로 배치합니다.

## 구성

- 철제 보강 나무 상자: 닫힘, 빈 상자 열림, 짚 포장, 숨겨진 토큰, 파손
- 여행용 트렁크: 닫힘, 빈 트렁크 열림, 의류, 숨겨진 편지, 파손
- 작은 서랍장: 닫힘, 위 서랍, 아래 서랍, 뒤쪽 비밀 열쇠, 파손
- 좁은 책장: 정면, 왼쪽으로 당김, 측면 회전, 뒤쪽 숨겨진 소포, 붕괴
- 밀기 방향 화살표 4개와 이동 먼지 3프레임

## 게임 적용

- 개별 오브젝트 20개는 `objects/`에 있습니다.
- `manifest.json`의 `pushable`, `rotatable`, `weight`, `collision_footprint_tiles` 값으로 이동 퍼즐을 제어합니다.
- 한 번 밀 때 32픽셀, 즉 기본 타일 한 칸을 이동하도록 설정했습니다.
- 이동 전에는 목표 타일 전체가 비어 있는지 검사하고, 이동 중에는 플레이어 입력을 잠시 막는 것이 안전합니다.
- 단서 상태에서는 `search_reveal`을 확인해 증거 아이템을 별도 오브젝트로 생성합니다.
- 파손·붕괴 상태는 이동시킬 수 없고 통로를 막는 고정 장애물로 사용합니다.

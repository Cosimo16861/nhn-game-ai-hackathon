# 08 강과 물 애니메이션

- 기준 크기: `32×32px`
- 애니메이션: 5종
- 각 동작: 8프레임
- 권장 재생 속도: 프레임당 `120ms`
- 반복 재생: 켜짐

## 구성

1. 잔잔한 낮 물
2. 가로 방향 강물
3. 세로 방향 강물
4. 동심원 물결
5. 가로등 반사가 있는 저녁 물

`water-animation-sheet-8x5-32px.png`는 가로 8칸이 프레임이고 세로 5줄이 물 종류입니다. 개별 프레임은 `frames-32px` 폴더에 있습니다.

레이어 순서는 `물 애니메이션 → 물가 경계 → 다리·캐릭터 → 전경 → 조명`을 권장합니다. `river-with-bank-preview.gif`에서 잔디, 움직이는 물, 투명 둑을 합친 모습을 볼 수 있습니다.

# C0B_THE_JOB 제작 계획

> 대본: `docs/script/07_CUTSCENES.md`
> 연출 기준: `docs/CUTSCENE_DIRECTION_GUIDE.md`
> 목표: 인트로 애니메이션과 `Q0_MONTAGE` 튜토리얼 사이를 잇는 약 29초 기준 컷신

## 1. 서사 기능

C0B는 네 가지 질문에 답해야 한다.

1. 경찰이 왜 복원 탐정을 찾아왔는가?
2. 말로 된 인상착의만으로는 왜 범인을 잡을 수 없는가?
3. 플레이어는 왜 목격자를 여러 번 확인하며 그려야 하는가?
4. 다음 화면이 왜 얼굴 복원 튜토리얼이어야 하는가?

대사는 `07_CUTSCENES.md`의 10비트를 순서와 의미를 바꾸지 않고 사용한다.

## 2. 화면 흐름

| 숏 | 길이 | 모드 | 핵심 화면 |
| --- | ---: | --- | --- |
| S1 | 2.5초 | world | 인트로의 닫힌 문이 열리고 젖은 리드가 들어온다 |
| S2 | 5.0초 | third-person | 책상 왼쪽 플레이어, 오른쪽 리드. 사건과 목격자를 설명한다 |
| S3 | 6.0초 | third-person | 같은 구도를 유지하며 말뿐인 인상착의의 한계를 밝힌다 |
| S4 | 4.0초 | first-person | 리드 정면 클로즈업. “얼굴을 주시오”를 정점으로 둔다 |
| S5 | 4.0초 | evidence | 진술서가 책상에 놓인다. 종이 충돌 뒤 잠시 침묵한다 |
| S6 | 5.5초 | third-person | 원래 구도로 복귀. 반복 질문의 이유를 말하고 작업대로 연결한다 |

총 목표 시간은 약 27초다. 사용자가 입력하면 현재 글자를 즉시 완성하고, 다시 입력하면
다음 비트로 진행한다. 입력하지 않아도 자동 재생된다.

## 3. 이미지 자산

| 자산 | 방식 | 규칙 |
| --- | --- | --- |
| 밤의 복원 탐정 사무소 | 이미지 생성 후 640×384 크롭 | 인물·글자 없음, 하단 112px 대사창 안전 영역 확보 |
| 리드 경위 3포즈 | 동일 정체성의 도트 캐릭터 시트 생성 후 분리 | calm / tense / high, 젖은 외투와 콧수염 유지 |
| 플레이어 3포즈 | 동일 정체성의 도트 캐릭터 시트 생성 후 분리 | calm / thinking / ready, 연필과 청록 조끼로 직업 표시 |
| 마르타 진술서 | 코드 합성 | 종이 질감만 이미지/도형, 정확한 글자는 고해상도 텍스트 레이어 |

이미지 생성 결과는 `assets/cutscenes/c0b/source/`에 보존하고, 최종 게임용 이미지는
`assets/cutscenes/c0b/` 아래에 둔다.

## 4. 구현 산출물

- `src/cutscene-c0b.js`: 숏·비트·타이핑·자동 진행·이미지 합성
- `src/intro.css`: C0B 대사창과 조작 안내
- `index.html`: 인트로 → C0B → `Q0_MONTAGE` 직접 연결. 역할 카드는 QA용 `stay=1`에서만 표시
- `video/c0b-the-job.webm`: 브라우저 컷신과 동일한 640×384, 약 28.8초 기준 영상
- `docs/C0B_EVALUATION_LOG.md`: 3회 평가 결과와 수정 기록

## 5. 평가 루프

각 회차마다 별도 평가 에이전트가 다음을 0~2점으로 평가한다.

- 게임 전체의 도트 분위기와 시각적 통일성
- 대본·퀘스트 순서와 텍스트의 정확성
- 타이핑·표정·카메라·소품 움직임의 타이밍
- 인트로에서 의뢰, 의뢰에서 Q0 튜토리얼로 이어지는 당위
- 한글 판독성, 조작 가능성, 스킵·재생 안정성

치명 항목 0점 없음, 총점 8/10 이상을 통과 기준으로 삼는다. 평가 결과를 반영해 세 차례
수정하며, 마지막 회차에는 기능 검증과 시각 검증을 함께 수행한다.

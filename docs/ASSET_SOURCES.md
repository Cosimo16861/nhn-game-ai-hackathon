# 이미지 자산 출처

## 박물관 절도 사건 전체 이미지

- 프로젝트 파일: `assets/cases/museum-robbery-master-dark-color.png`
- 크기: 1254×1254 PNG
- 제작일: 2026-07-30
- 제작 방식: Codex의 기본 이미지 생성 도구로 생성한 뒤 단순화 편집
- 용도: 박물관 대형 사건의 2×2 세부 사건 조각 원본
- 외부 이미지 입력: 없음

### 최종 생성 방향

하나의 연속된 박물관 전시실을 넓은 시점에서 보여주고, 깨진 창문·빈 전시대·
발자국·넘어진 안내판·깨진 보석함·범인의 그림자를 큰 형태와 제한된 색상으로
표현했다. 2×2 조각으로 나눠도 각 구역이 독립된 사물 그림처럼 보이지 않도록
바닥, 조명과 증거의 흐름을 이어 구성했다.

### 사용 전 확인

제출 전 대회의 생성형 이미지 사용 및 출처 표기 규정을 다시 확인한다. 이 문서는
제작 이력을 보존하기 위한 것으로 대회 이용 허가를 대신하지 않는다.

## 편의점 절도 사건

현재 `convenience-store-theft.png`를 임시 전체 이미지로 사용한다. 2×2 연속 장면
원본을 새로 준비하면 `masterImageStatus`를 `placeholder`에서 `ready`로 변경한다.

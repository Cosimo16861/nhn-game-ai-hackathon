# UI 단순화 기준

이 문서는 화면을 단순화할 때 플레이에 필요한 정보와 제거할 정보를 구분한다.
채점 계산, 사건 데이터, 128×128 색칠판, 화면 전환 로직은 변경하지 않는다.

## 공통 원칙

- 한 화면에서 가장 중요한 행동 버튼은 하나만 강조한다.
- 제목 아래 설명은 한 문장까지만 표시한다.
- 민트색은 행동, 노란색은 목격담, 코랄색은 경고와 실패에만 사용한다.
- 같은 뜻의 라벨, 상태 문구, 장식 아이콘은 반복하지 않는다.
- 기술적인 수치와 세부 채점값은 기본 화면에서 숨기고 필요할 때만 펼친다.

## 화면별 우선순위

| 화면 | 항상 표시 | 접어서 표시 | 제거 |
| --- | --- | --- | --- |
| 공통 상단 | 게임명, 한 줄 소개, 현재 상태 | 없음 | 영문 실험실 문구, 긴 소개 |
| 사건 선택 | 사건 이미지, 사건명, 한 줄 설명, 수사 버튼 | 난이도와 통과 점수 | 카드 번호, 선택 안내 중복, 해상도·팔레트·가림 비율 |
| 사건 준비 | 가려진 이미지, 목격담 3개, 복원 시작 버튼 | 사용 팔레트 | 증거 번호, 마스크 범례, 분석 픽셀 수 |
| 복원 | 사건명, 진행률, 색칠판, 목격담, 팔레트, 채점 버튼 | 도움말 | 단계 영문 라벨, 작업대 규격 문구, 중복 안내 |
| 결과 | 최종 점수, 해결 판정, 핵심 피드백, 다음 행동 | 시각·CLIP·색상·윤곽선·구조·팔레트 세부 점수 | 화면 하단 점수 기준표, 반복되는 기술 수치 |

## 기능 보호 대상

다음 요소의 ID는 스크립트와 연결되어 있으므로 제거하지 않는다. 화면에서 숨기거나
접을 때에도 DOM에는 유지한다.

- 사건: `caseGrid`, `caseSelectionMessage`, `loadCaseButton`
- 준비: `puzzlePreview`, `resultMeta`, `paletteList`, `startPuzzleButton`
- 복원: `editorCanvas`, `editorProgress`, `editorTimer`, `caseTitleDisplay`,
  `witnessList`, `editorPalette`, `eraserButton`, `undoButton`, `resetButton`,
  `scoreButton`
- 결과: `finalScoreValue`, `caseOutcome`, `scoreMessage`, 모든 세부 점수 ID,
  `answerPreview`, `playerPreview`, 결과 행동 버튼

## 완료 기준

- 사건 선택부터 결과까지 기존 기능이 그대로 작동한다.
- 각 화면의 강조 버튼은 한눈에 구분된다.
- 기본 결과 화면에는 최종 점수와 판정이 먼저 보인다.
- 세부 정보가 핵심 행동보다 먼저 시선을 끌지 않는다.

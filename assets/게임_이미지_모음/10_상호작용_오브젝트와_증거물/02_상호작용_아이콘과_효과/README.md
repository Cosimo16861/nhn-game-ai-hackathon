# 02. 상호작용 아이콘과 효과

플레이어에게 가능한 행동과 조사 결과를 알려 주는 투명 배경 그래픽입니다.

- `icons-32px/`: 행동·상태 아이콘 15종
- `effects-64px/`: 조사 원과 증거 반짝임 5프레임
- `interaction-ring-animation.gif`: 조사 위치 맥박 애니메이션
- `evidence-glint-animation.gif`: 숨은 증거 반짝임 애니메이션
- `in-game-indicator-sample.png`: 실제 게임 배치 예시
- `manifest.json`: 프레임 속도와 표시 위치

행동 아이콘은 대상 오브젝트의 위쪽 36픽셀 위치에 표시합니다. 조사 원은 대상의 바닥 아래에 두고 150ms 간격으로 반복합니다. 증거 반짝임은 플레이어가 관찰 모드를 켰거나 충분히 가까이 접근했을 때만 보여 주면 추리의 난도를 조절할 수 있습니다. 비교 아이콘의 붉은 흔적은 게임의 비폭력 사건 설정에 맞춰 푸른 잉크 흔적으로 변경했습니다.

# 벽난로·난로 상태 세트

사람이 없는 투명 PNG 상호작용 오브젝트입니다. 32×32 타일 맵에서 바닥 중앙(`bottom-center`) 기준으로 배치합니다.

## 구성

- 붉은 벽돌 벽난로: 꺼짐, 장작불 점화, 연소, 재 조사, 파손
- 석조 벽난로: 꺼짐, 잔불, 연소, 숨겨진 토큰 조사, 파손
- 주철 배불뚝이 난로: 꺼짐, 점화, 작동, 숨겨진 쪽지 조사, 파손
- 주철 부엌 레인지: 꺼짐, 예열, 조리, 오븐 조사, 파손
- 작은 불꽃 3프레임, 큰 불꽃 3프레임, 따뜻한 빛 3프레임

## 게임 적용

- 개별 오브젝트 20개는 `objects/`에 있습니다.
- 불꽃과 조명은 `effects/`에 있으며 `오브젝트 → 불꽃 → 따뜻한 빛` 순으로 겹칩니다.
- `manifest.json`의 `emits_light`, `hazard`, `search_reveal`, `usable` 값으로 상태를 제어합니다.
- 파손 상태에서는 사용할 수 없고, 조사 상태에서는 증거 아이템을 별도 오브젝트로 생성합니다.
- 미리보기 GIF는 상태 비교용이며 게임에서는 개별 PNG를 사건 진행에 맞춰 교체합니다.

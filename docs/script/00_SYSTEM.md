# 00 · 시스템 정의 (스크립트 공통 규약)

이 문서는 모든 대사 스크립트가 공유하는 **플래그, 노드 규약, 엔딩 분기 로직,
복원 데이터 스키마**를 정의한다. 다른 스크립트 문서는 여기서 정의한 플래그와
노드 형식만 사용한다.

---

## 1. 대사 노드 규약

### 1.1 노드 ID

```
<막코드>_<장면>_<번호><분기>
```

- 막코드: `PRO`(프롤로그) `A1` `A2` `A3` `FIN`(최종국면) `END` `SIDE`
- 예: `A1_HOLT_03b` = 1막 · 홀트 장면 · 3번 노드 · b 분기

노드 ID는 문서 전체에서 고유하며, 빌드 시 대화 데이터의 기본 키로 사용한다.

### 1.2 노드 표기 형식

각 대사 노드는 아래 형식으로 적는다.

```
### EXAMPLE_HOLT_02 · 홀트 [긴장]
> (본문 대사. 최대 3줄, 한 줄 24~28자 기준.)

- 진입조건: FLAG_X == true      (없으면 생략)
- 진입효과: SET CLUE_HOLT_FACE  (없으면 생략)
- 다음: → A1_HOLT_03            (선택지가 없을 때만)
```

선택지가 있는 노드는 본문 아래에 **선택지 표**를 붙인다.

| # | 플레이어 대사 | 조건 | 결과(플래그) | 다음 |
|---|---|---|---|---|
| A | "..." | — | `SET X` | → 노드ID |
| B | "..." | 잠금: `EV_LEDGER` 필요 | — | → 노드ID |

- **조건**: 선택지가 보이거나 선택 가능해지는 요구 조건. `잠금:`은 조건 미충족 시
  회색 처리하고 필요 조건을 함께 표시한다(GAME_DESIGN 6.1).
- **결과**: 선택 시 조작되는 플래그. 여러 개면 `;`로 구분.
- **핵심 판단** 선택지는 표의 # 앞에 `★`를 붙이고, 선택 후 잠긴다(1회성).

### 1.3 표정 코드

주요 인물은 3표정을 가진다(GAME_DESIGN 6.2). 노드 헤더의 `[ ]`에 표기.

| 코드 | 의미 |
| --- | --- |
| 평상 | 기본 |
| 긴장 | 긴장·불쾌 |
| 고조 | 놀람·감정 고조 |

주변 NPC는 표정 없이 `평상` 하나만 써도 된다.

### 1.4 질문 재선택 규약

- 일반 질문 노드는 대화를 나간 뒤 다시 선택 가능. 이미 고른 질문에는 `✔` 표시.
- 핵심 판단(★)은 1회성. 선택 후 목록에서 제거하거나 잠근다.
- 모든 필수 질문을 마치면 `대화를 마친다` 선택지가 나타난다.

## 2. 플래그·변수 정의

플래그 이름은 대문자 스네이크. 값은 별도 표기 없으면 boolean(기본 false).

### 2.1 결정적 증거 (Decisive Evidence) — 엔딩 조건의 핵심

| 플래그 | 이름(카드) | 획득 위치 | 획득 방법 |
| --- | --- | --- | --- |
| `EV_FACE` | 미화되지 않은 얼굴의 특징 | 1막 · 홀트 | 핵심 판단 KD1에서 "표정" 질문 선택 |
| `EV_LEDGER` | 줄리언의 장부와 내부 정보 유출 | 2막 · 리드 | 핵심 판단 KD2에서 "리드 비밀 대조" 선택 |
| `EV_CARRIAGE` | 줄리언의 마차 목격담 | 3막 · 뱅크스 | 핵심 판단 KD3에서 "행적(시간순)" 질문 선택 |

- 세 증거는 각각 해당 막의 **핵심 판단(★)** 을 올바르게 선택해야 얻는다.
- 잘못 선택해도 메인 진행은 계속되지만 그 막의 결정적 증거를 놓친다.

### 2.2 안전장치 — 항해일지

| 플래그 | 의미 |
| --- | --- |
| `SUB_LOGBOOK` | 3막 부두 창고에서 항해일지 조각을 찾음 |

- 항해일지는 **놓친 결정적 증거 1개를 대신**한다(아래 3장 엔딩 로직 참조).
- 이 물건은 세이렌 호에서 건진 반쪽짜리 항해일지이며, 뱅크스가 남은 페이지를
  최근 부두 야간 기록용 수첩으로 계속 사용했다. 따라서 12년 전 기록과 최근
  카버의 행적이 같은 물건에 함께 남아 있다.

### 2.3 핵심 판단 상태 (분기 체크포인트 대상)

| 플래그 | 값 | 의미 |
| --- | --- | --- |
| `KD1` | face / detail / doubt | 1막 홀트 질문 선택 |
| `KD2` | ledger / julian / eleanor | 2막 인장·장부 처리 선택 |
| `KD3` | carriage / weather / sailor | 3막 뱅크스 질문 선택 |

- 정답 값: `KD1=face`, `KD2=ledger`, `KD3=carriage` → 각각 결정적 증거를 얻는다.
- 오답 값은 보조 단서만 준다(각 막 스크립트에 명시). 진행은 막히지 않는다.
- 세 판단 직전에 **분기 체크포인트**를 만든다(GAME_DESIGN 11).

### 2.4 프롤로그 태도 (어조 전용, 엔딩 무관)

| 플래그 | 값 | 의미 |
| --- | --- | --- |
| `ATT` | carver / family / neutral | 첫 태도 선택. 리드·줄리언의 첫 반응과 이후 일부 어조만 바꾼다. |

### 2.5 서브 퀘스트

| 플래그 | 의미 |
| --- | --- |
| `CAT_POSTER` | 고양이 '안개' 전단 그림 완성·게시. 3막 창고에서 안개를 알아볼 수 있음 |
| `CAT_FOUND` | 3막 창고에서 고양이 '안개' 발견. 코라에게 돌려보내기 전 상태 |
| `SUB_CAT` | 고양이 '안개'를 코라에게 돌려보내 서브 퀘스트 완료. 엔딩 후일담에 영향 |
| `SUB_LOGBOOK` | 항해일지 발견(2.2) |

### 2.6 복원 통과 플래그

| 플래그 | 의미 |
| --- | --- |
| `REST_CAT` | 고양이 초상 복원 통과 |
| `REST1` | 메인1 에드먼드의 초상 통과 |
| `REST2` | 메인2 인장과 문신 통과 |
| `REST3` | 메인3 안개 낀 부두 통과 |

- 메인 복원 통과는 다음 막 진입의 전제다. 통과 못 하면 사무소에서 재작업(제출 무제한).

### 2.7 진행 단계

| 플래그 | 값 | 의미 |
| --- | --- | --- |
| `STAGE` | prologue / act1 / act2 / act3 / finale / ending | 현재 막. 장소별 상호작용·NPC 대사·팔레트 해금에 사용 |

- 팔레트: 평상 A / 사건 진행 B(저채도·차가움) / 해결 후 C(GAME_DESIGN 7.3).
  `STAGE`가 act1~act3이면 B, ending이면 C.

### 2.8 장면 상태 플래그

| 플래그 | 의미 |
| --- | --- |
| `E_PRESSED` | 1막에서 엘리너를 강하게 추궁해 대화가 일시 중단됨 |
| `CARVER_SEAL_HINT` | 1막에서 카버가 가문 인장과 문신을 안다고 먼저 주장함 |
| `JULIAN_ALERTED` | 2막에서 줄리언이 조사를 눈치채 장부를 치울 시간을 얻음 |

`CLUE_*` 카드 ID는 해당 카드를 획득했는지를 나타내는 boolean 플래그로도
동시에 사용한다. 카드 획득 시 같은 이름의 플래그를 `true`로 설정한다.

## 3. 엔딩 분기 로직

### 3.1 유효 증거 수 계산

```
결정적증거수 = count(EV_FACE, EV_LEDGER, EV_CARRIAGE)   // 0~3
항해일지보정 = (SUB_LOGBOOK == true AND 결정적증거수 < 3) ? 1 : 0
유효증거수   = 결정적증거수 + 항해일지보정               // 상한 3
```

- 항해일지는 **부족분을 1개 보충**한다. 이미 3개면 보정 없음.
- 즉 항해일지가 실질적으로 의미 있는 경우: 결정적 증거를 딱 1개만 얻은 상태
  (1 → 2로 올라 배후 입증 가능선에 도달).

### 3.2 최종 결론 선택 (FIN 장면)

플레이어는 증거판 배치 후 결론을 고른다(핵심 판단 아님, 재선택 가능하나 확정 시 엔딩).

| 선택 | 코드 | 의미 |
| --- | --- | --- |
| 1 | `carver_alone` | 카버는 혼자 신분을 속인 사기꾼이다 |
| 2 | `mastermind` | 카버는 사칭범이며 줄리언이 배후다 |
| 3 | `hold` | 배후 판단은 보류하고 카버의 사칭만 처리한다 |

### 3.3 엔딩 판정

```
IF 결론 == mastermind AND 유효증거수 >= 2:
    → 엔딩 A (안개 너머의 진실)
ELSE:
    → 엔딩 B (반쪽짜리 정의)
```

세부 처리:

- `mastermind`인데 `유효증거수 < 2`: 리드가 "심증은 가지만 이 증거로는 줄리언을
  세울 수 없다"고 반려 → 플레이어는 다시 배치하거나 다른 결론을 고를 수 있다.
  그대로 밀어붙이면 **엔딩 B**로 진행(배후 입증 실패).
- `carver_alone`: 항상 **엔딩 B**. 카버만 체포.
- `hold`: 리드가 한 번 재고를 권함. 유지하면 카버의 사칭만 처리하고
  **엔딩 B**로 진행한다.

### 3.4 결론 선택지 잠금

- `mastermind` 선택지는 결정적 증거를 **1개 이상** 확보해야 목록에 나타난다
  (0개면 아직 배후를 지목할 근거가 없음 → 회색+조건 표시).
- `유효증거수 >= 2`가 아니면 선택은 되지만 3.3의 반려 로직을 탄다.

### 3.5 엔딩 후 재시작 (GAME_DESIGN 4.9)

엔딩 화면 선택지:

1. 현재 결말의 후일담 보기
2. 놓친 분기부터 다시 수사
3. 처음부터 새 게임

- `놓친 분기부터`: 현재 `유효증거수 >= 2`라면 증거는 이미 충분하므로
  **최종 증거판 직전**으로 복귀한다. `유효증거수 < 2`라면 KD3 → KD2 → KD1
  순으로 확인해, 오답이었던 가장 최근 핵심 판단 직전으로 되돌린다.
- 항해일지가 특정 핵심 판단 하나와 직접 대응한다고 가정하지 않는다. 항해일지는
  유효 증거 수만 1 보충하며, 복귀 지점은 위의 유효 증거 수로 결정한다.
- 확인한 엔딩은 `SEEN_END_A`, `SEEN_END_B` 플래그로 유지. 타이틀에 `1/2` `2/2` 표시.

## 4. 복원 퀘스트 데이터 스키마

각 복원 퀘스트는 다음 구조로 정의한다(각 막 스크립트에 채워짐).

```
복원 퀘스트: <이름>
- 방식: 윤곽수정형 | 부분채색형 | 조각조립형 | 빈캔버스배치형
- 캔버스: 시작 상태(빈/희미한 윤곽/조각) 설명
- 팔레트: 제공 색상군
- 필수 특징: [F1, F2, ...]  // 숨은 채점의 '필수 특징 반영 여부'에 해당
- 그림 근거 표
- 통과 시: SET REST_n ; 증거판/단서 메뉴에 복원물 추가
```

### 4.1 "그림 근거" 표의 의미

플레이어가 캔버스에 무엇을 그릴 수 있는지는 **수집한 증언·단서로만 해금**된다
(game_asset_uimaking: 복원 목표에는 이미 아는 정보만 표시). 표의 각 행은:

| 그리는 요소 | 근거(증언/단서) | 근거 없을 때 |
| --- | --- | --- |
| 캔버스에 표현할 특징 | 이 특징을 알게 해 주는 증언 카드/조사 | 근거를 못 얻으면 그 특징은 복원 목표에 안 뜨고 채점 필수에서 빠지거나 감점 |

- **근거를 얻은 특징만 복원 목표(HUD)에 표시**되고, 숨은 채점의 필수 특징이 된다.
- 근거를 놓치면 그 특징은 "추가 증언 힌트" 대상이 되거나, 통과선이 낮아진 채
  대략적 형태만 요구된다(진행은 가능, 좋은 엔딩 증거로서의 질은 낮음).

### 4.2 숨은 피드백 단계 (GAME_DESIGN 8.4 표 준수)

내부 점수(색상·윤곽·구조·팔레트·CLIP·필수특징)를 4단계 정성 피드백으로만 노출.
숫자·정답 좌표·오버레이는 공개하지 않는다.

| 내부 상태 | 표현 |
| --- | --- |
| 차이 큼 | "증언 카드를 다시 살펴보자." + 핵심 부위 추가 증언 힌트 |
| 방향 맞으나 부족 | "전체 인상은 가까워지고 있다." + 부족 범주(색/형태/배치)만 안내 |
| 통과선 근접 | 연필 소리·가장자리 짧은 빛·"거의 완성됐다" |
| 통과 | "증거로 사용할 수 있을 만큼 복원됐다" (숫자 없음) |

> 주의: game_asset_uimaking.txt에는 결과 화면에서 총점·유사도%·신뢰도%를 공개한다는
> 서술이 있으나, 상위 정본 GAME_DESIGN 8.4가 "숫자 비공개"로 확정했으므로 **비공개**를
> 따른다. 증언 카드 신뢰도도 내부 데이터로만 관리한다(GAME_DESIGN 6.3).

## 5. 단서·증언 카드 규약

- 카드 필드: 증언자 / 요약 1줄 / 전체 내용 / 관련 인물·장소 / 관련 복원 퀘스트 / 신뢰도(내부).
- 아직 얻지 않은 카드는 목록에 미리 노출하지 않는다.
- 결정적 증거 카드는 붉은 테두리로 강조.
- 서로 모순되는 증언은 연결 표시로 비교 가능(예: 엘리너의 미화된 얼굴 ↔ 홀트의 정확한 특징).

카드 ID 규약: `CLUE_<주제>` / 결정적 증거는 `EV_<주제>`(플래그와 동명).

주요 카드 목록(막별 상세는 각 문서):

| 카드 ID | 요약 | 획득 |
| --- | --- | --- |
| `CLUE_ELEANOR_PORTRAIT` | 엘리너의 미화된 옛 초상 | 1막 저택 |
| `CLUE_ELEANOR_SLEEVE` | 긴장하면 왼손 소매를 만짐 | 1막 엘리너(공감 질문) |
| `CLUE_CARVER_TOO_PERFECT` | 카버의 기억이 지나치게 정확함 | 1막 카버·엘리너 대조 |
| `CLUE_FACE_OUTLINE` | 에드먼드의 대략적인 얼굴 윤곽 | 1막 홀트(KD1=detail) |

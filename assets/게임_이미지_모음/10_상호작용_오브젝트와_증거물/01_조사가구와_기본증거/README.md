# 01. 조사 가능한 가구와 기본 증거물

탑다운 추리 어드벤처용 상호작용 오브젝트 20종입니다.

- 조사 전·후 가구 상태 5쌍: 책상, 장식장, 상자, 책장, 마룻바닥
- 휴대·현장 증거 10종: 편지, 쪽지, 열쇠, 손수건, 시계, 발자국, 유리, 단추, 천 조각, 밀랍
- `objects/`: 투명 배경 완성 PNG
- `interaction-highlights/`: 조사 가능 표시용 2프레임 윤곽선
- `furniture-state-comparison.png`: 조사 전후 비교
- `evidence-on-floor-sample.png`: 증거물 배치 예시
- `manifest.json`: 상태 연결, 충돌, 상호작용 설정

플레이어가 한 칸 이내로 접근하면 노란 윤곽선 두 프레임을 220ms 간격으로 반복해 조사 가능 상태를 표시합니다. 조사 완료 후에는 닫힘 이미지를 열림·발견 이미지로 교체하고 저장 데이터에 상태를 기록하세요. 증거물은 습득 전에는 월드 오브젝트, 습득 후에는 증거 수첩 아이콘으로 사용합니다.

## Phase별 체크리스트

### Phase 0 · 준비
- [ ] 역할 확정, 마감 역산 일정 합의
- [ ] AI 도구 선정 + **ToS(상업/2차 사용) 확인**
- [ ] 저장소 정리, `.gitignore`로 키/비밀 제외

### Phase 1 · 프리프로덕션
- [ ] (B) 스토리·퀘스트 확정, **정답 이미지 스펙 3종**, 증언 트리 초안
- [ ] (B) B엔딩 시각 단서(줄리언 문양) 디자인
- [ ] (A) 이동+NPC 스파이크, **LLM 프록시+폴백 스파이크**
- [ ] (A) `case-data.js` 기반 **데이터 구조 설계**

### Phase 2 · 콘텐츠·에셋 (주로 B)
- [ ] AI 생성→픽셀화로 정답 이미지 3종 + 손상 마스크
- [ ] 5장소 배경·캐릭터 픽셀 에셋
- [ ] **폴백 증언 스크립트** + 증인 성격/말투
- [ ] **에셋 출처·프롬프트·라이선스 기록 표** (제작과 동시에)

### Phase 3 · 코어 개발 (주로 A)
- [ ] 5장소 자유 이동 + 장소 해금 + NPC 상호작용
- [ ] 증언 → 복원 캔버스 연결
- [ ] 채점·마스크·힌트 통합 → **M1: 폴백으로 완주 가능**

### Phase 4 · 대화형 증인(LLM) 통합
- [ ] 서버리스 프록시(키 환경변수)+레이트리밋+graceful degradation
- [ ] 증인별 system prompt(그라운딩·점진공개·가드레일)
- [ ] 힌트 구매 ↔ 증인 점진 공개 연동
- [ ] LLM↔폴백 매끄러운 전환

### Phase 5 · 통합·엔딩·저장
- [ ] 최종국면(복원=지목 + 증거제시, `deduction-manager` 용도변경) + B엔딩 컷씬
- [ ] `localStorage` 저장/이어하기, 인트로·Skip
- [ ] 밸런싱 → **M2: 완결 플레이 + 기능 프리즈**

### Phase 6 · 배포 & QA
- [ ] GitHub Pages + 프록시 배포, 링크 점검
- [ ] 심사자 관점 QA(키 없이 완주, 모바일/접근성, 저장)

### Phase 7 · 제출물
- [ ] 플레이 영상 30~60초 (탐문→그림완성→범인 드러남 훅) YouTube
- [ ] 게임 소개 문서(PDF)
- [ ] AI 활용 기술 문서(PDF) — 3중 AI + 에셋 출처/라이선스
- [ ] 팀원 롤 기술서(PDF) → **M3: 5종 완비**

### Phase 8 · 최종 점검·제출

# 03. 문 열림 애니메이션과 잠금 상태

빅토리아풍 문 4종의 상태 및 애니메이션 세트입니다.

- 문 종류: 주택 참나무문, 실내 패널문, 경찰서 강화문, 낡은 지하실문
- 각 문 상태: 닫힘, 25도 열림, 60도 열림, 완전 열림, 잠김
- `doors/`: 게임용 64×64 투명 PNG 20개
- `door-states-5x4-64px.png`: 전체 스프라이트 시트
- `*-open-close-preview.gif`: 문별 애니메이션 확인 GIF
- `manifest.json`: 프레임 시간과 충돌 전환 설정

문이 완전히 열린 마지막 프레임에서만 출입 충돌을 해제하세요. 잠긴 문은 닫힘 상태와 같은 충돌을 사용하고, 열쇠 또는 사건 진행 조건을 만족한 뒤에만 열림 애니메이션을 재생합니다. 닫기 애니메이션은 열기 프레임을 역순으로 사용합니다.

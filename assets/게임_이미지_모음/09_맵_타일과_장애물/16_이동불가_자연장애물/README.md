# 16. 이동 불가능 지역용 자연 장애물

보이지 않는 벽 대신 사용할 64×64 자연 장애물 20종입니다. 절벽·숲·가시덤불·습지·산사태가 플레이어에게 통행 불가 이유를 명확하게 보여 줍니다.

- `objects-64px/`: 투명 배경 장애물 20개
- `collision-masks/`: 게임 충돌용 흰색 마스크 20개
- `foreground/`: 사용하지 않는 맵 가장자리를 가리는 절벽·숲 전경
- `natural-barriers-tileset-5x4-64px.png`: 전체 타일 시트
- `natural-barriers-map-sample.png`: 마을 외곽 배치 예시
- `manifest.json`: 충돌과 전경 렌더링 설정

이 세트의 모든 오브젝트는 이동 불가능입니다. 충돌 영역만 단독으로 배치하지 말고 반드시 대응하는 장애물 그래픽과 함께 사용하세요. 플레이어가 이동 가능한 구역에는 장애물을 겹쳐 놓지 않으며, 절벽과 숲 벽 뒤쪽에는 사용하지 않는 맵 공간을 숨길 수 있습니다.

# 진흙·먼지·물자국 증거 세트

사건 현장의 이동 경로와 물건이 있었던 위치를 추리할 수 있는 투명 PNG 증거입니다.

## 증거 종류

- 젖은 진흙 얼룩: 부채꼴 물방울 세 개와 끌린 가장자리
- 마른 진흙 부스러기: 초승달 모양의 갈라진 덩어리와 끊긴 이동 경로
- 먼지의 빈자리: 사각 물건 윤곽과 두 줄의 손가락 닦임
- 물방울 이동 흔적: 크기가 줄어드는 다섯 방울과 불완전한 원형 자국

## 증거별 파일

- `map.png`: 맵에 놓는 기본 흔적
- `map-faded.png`: 흐려지거나 일부 지워진 변형
- `closeup.png`: 확대 조사 화면
- `notebook-icon.png`: 사건 수첩 아이콘
- `discovered-highlight.png`: 발견·선택 강조 상태

## 게임 적용

- 흔적은 바닥 타일 위의 투명 레이어로 배치하며 충돌을 적용하지 않습니다.
- 비가 오거나 청소 사건이 발생하면 기본 상태를 흐려진 상태로 교체할 수 있습니다.
- 먼지 흔적은 사라진 물건의 밑면 크기와 비교하고, 물방울은 크기가 작아지는 방향으로 이동 방향을 추리합니다.
- 수집 후 맵 표시를 숨기고 수첩 아이콘과 확대 조사 이미지를 활성화합니다.

# C0B_THE_JOB 평가·수정 기록

## 평가 기준

각 항목 0~2점, 총 10점이다.

1. 게임 분위기·도트 통일감·자연스러움
2. `07_CUTSCENES.md`의 텍스트와 순서 정확성
3. 텍스트·이미지·동작 타이밍의 일치
4. `C0_INTRO → C0B → Q0_MONTAGE` 연결 당위
5. 한글 판독성·입력·스킵 안정성

치명 항목 0점 없음, 총점 8점 이상을 통과 기준으로 삼는다.

## 1차 평가 — 5/10, 실패

| 항목 | 점수 | 평가 |
| --- | :--: | --- |
| 분위기·통일감 | 1 | 팔레트·초상·UI는 통일됐으나 첫 숏의 청색 사각 조명이 리드를 덮음 |
| 대본 정확성 | 2 | C0B 10비트의 문구와 순서가 정본과 일치 |
| 타이밍 | 1 | 핵심 대사 강조는 좋으나 진술서 정착 후 여백이 짧고 타이핑 중 줄이 이동함 |
| 퀘스트 연결 | 0 | 역할 카드가 흐름을 끊고 Q0 작업대가 다른 사건·증언자로 열림 |
| 판독·조작 | 1 | 읽기는 좋으나 빠른 SPACE 경합과 첫 관람 스킵 허용이 남음 |

### 1차 수정

- C0B 종료 후 역할 카드를 거치지 않고 `Q0_MONTAGE` 작업대로 직접 이동
- Q0 작업대 제목을 《골목의 손 · 수배 몽타주》로 변경
- 증언자를 마르타로 통일하고 회색 모자·왼뺨 점·해진 초록 목도리의 정본 3문장을 연결
- 첫 숏의 청색 직사각형 제거. 문과 창의 기존 냉광·빗줄기만 사용
- 진술서 낙하 520ms + 정착 후 820ms 침묵을 확보하도록 `textDelay`를 1340ms로 변경
- 전체 문장을 먼저 줄바꿈한 뒤 보이는 글자만 잘라 타이핑 중 재배치 제거
- SPACE 입력 시 현재 비트를 다시 동기화하고 120ms 잠금 후 정확히 한 비트만 전진
- 첫 관람에는 ESC·건너뛰기 버튼과 안내를 숨기고, 완주 기록이 있을 때만 활성화

### 유지 항목

- 동일 팔레트·스캔라인·고정 대사창으로 묶인 다중 카메라 문법
- “얼굴을 주시오”의 정면 포즈, 단계 줌, 금색 강조
- 마지막 플레이어 작업 포즈와 반복 확인의 의미

## 2차 평가 — 9/10, 통과

| 항목 | 점수 | 평가 |
| --- | :--: | --- |
| 분위기·통일감 | 2 | 청색 사각형이 제거되고 세 카메라 모드가 같은 게임으로 유지됨 |
| 대본 정확성 | 2 | 10비트 문구·순서 일치 |
| 타이밍 | 1 | 자동 재생은 자연스럽지만 SPACE로 진술서 관찰 시간을 우회할 수 있음 |
| 퀘스트 연결 | 2 | 역할 카드 없이 Q0 직행, 마르타의 정본 3개 메모 표시 |
| 판독·조작 | 2 | 줄바꿈·연타·첫 관람 스킵 문제가 해결됨 |

### 2차 수정

- 진술서 비트에 `visualLock: 1340`을 추가
- 종이 낙하 520ms와 정착 후 침묵 820ms가 모두 끝나기 전에는 SPACE가 대사를
  완성하거나 다음 비트로 이동하지 못하게 함
- 조작 안내를 “SPACE 문장 완성 / 다음”으로 바꿔 두 단계 입력 규칙을 명시

| 퀘스트 연결 | 2 | 중간 역할 카드나 증거판 없이 `Q0_MONTAGE`로 직접 이동 |
| 판독·조작 | 2 | 한글 판독성, 첫 관람 스킵 제한, 120ms 연타 잠금이 정상 동작 |

### 최종 영상 검증

- VP9 WebM, 640×384, 약 3.5MB
- 866프레임, 약 28.827초. 최초 요구한 20~30초 범위 충족
- 처음부터 EOF까지 정상 디코딩
- 치명 결함과 필수 수정 없음

### 후속 선택 개선

- 빗소리·문 열림·진술서 충돌음을 별도 오디오 트랙으로 추가할 수 있음
- 24~28초 내부 가이드를 엄격히 적용할 때는 약 0.8초를 단축할 수 있음
